# D01 — 방송 편성형 리그 일정 · 상호 가용 스크림

기준: 2026-09-29. 기존 실제 일일 시계와 스크림 훈련/세이브/국제대회 규칙을 보존하면서, 정규리그의 **경기일 배분**과 실제 스크림 예약 조건을 확장한다.

## 정규리그: 주 6일 생중계와 팀당 주 2시리즈

- 방송일은 **화요일~일요일(월요일 비편성)**이고 첫 라운드는 직전 단계로부터 정해진 개막일 이상인 첫 화요일에 시작한다.
- 같은 주에 라운드로빈 대진 2개를 소화한다. 팀당 공식 시리즈 **최대 2회/주**, 두 시리즈 사이 **적어도 하루 온전한 휴식일**을 보장한다. 각 팀이 2개 라운드 모두 참여하는 일반 짝수팀 리그에서는 정확히 2회다.
- 앞 라운드는 화~목, 뒤 라운드는 금~일에 배분하되, 목요일 출전 팀을 금요일에 다시 배치하지 않는다.
- 하루 개최 시리즈 수는 해당 참가 규모로 결정한다. **10·12팀은 최대 2시리즈/일, 16·18팀은 최대 3시리즈/일, 20팀은 최대 4시리즈/일**을 목표로 배분한다(상황에 따라 일부 날은 적게 개최).
- 각 시리즈에 `time`(예상 방송 시작 시각)과 `broadcastSlot`(당일 중계 순서)을 보관하고 일정 탭에서 노출한다. 기존 결과/밴픽/First Selection/Fearless/정규순위/플레이오프·국제대회 편성은 유지한다.
- 플레이오프·국제대회는 별도의 포맷과 휴식일을 따르며, 그 대회에 위 국내 정규 6일 방송 규칙을 강제하지 않는다.
- 기존 `cfg.legs`의 왕복 라운드 횟수는 변경하지 않는다. 장기 커리어에서 **1년 내 전대회 종료 가능성은 별도 시즌 길이 밸런스 검증**이 필요하다. 이 PR은 정규 시즌 경기 **수량**을 건드리지 않는다.

## 스크림: 반드시 양 팀 일정 모두 확인

1. `officialBookedTeams(db,date)`가 현재 월드에 만들어진 **전체 공식 대회 일정**에서 지정 날짜의 출장 팀을 추출한다. 결과 처리가 끝난 공식 경기도 여전히 해당 날의 일정이므로 이용 불가다. 저장된 세계의 날짜별 편성표를 읽으며 별도 영속 캐시를 만들지 않는다.
2. 각 구단은 `scrimReadiness`에서 공식전 여부, 다른 스크림 예약, 선수단 피로/컨디션, 가장 가까운 공식전까지의 휴식 시간을 판정한다. 공식전 당일은 0세트, 전날 최대 2세트, 이틀 전 최대 4세트, 일반 연습일 최대 6세트(추가 체력 조정).
3. 하루에는 **오후 · 저녁** 두 세션 블록이 있다. 양 구단에서 **동시에 같은 블록이 비어 있고**, 각자 남은 게임 수가 충분할 때만 스크림을 만든다. 한 팀이 그 슬롯에 먼저 예약되었다면 두 번째 스크림은 거부한다.
4. `simulateBackgroundScrim`는 **두 구단의 가용성을 커밋 직전에도 다시 검사**하고 양쪽 스크림 로그에 같은 `date`/`slot`/상대/경기 수/승패를 기록한다. 스크림 선수별 챔피언 학습·피로·컨디션·전향 훈련과 팀 분석 정보를 종전과 같이 적용한다. 실전 통계·상대 공개 메타에는 포함시키지 않는다.
5. 예전 저장 데이터에는 스크림 `slot` 필드가 없을 수 있다. 그날의 기존 기록을 기록 순으로 오후·저녁 예약으로 해석하여 이중 예약을 막는다. 새 필드 도입으로 월드 **v15 / 저장 포맷 2**는 변하지 않는다.
6. 선수단 화면에는 오늘의 공식전 충돌 여부·스크림 가용 블록·최근 스크림 세션을, 대회 일정에는 공식 방송 시작 시각을 표시한다.

**범위:** 스크림 상대는 기존과 같이 같은 지역으로 제한된다. 국제대회 공동 개최지에서 다른 지역 팀을 부르는 기능, 매니저가 직접 초대하는 스크림 상대 및 세션 선택, 시즌 간 달력 겹침 방지와 장기적인 방송 시간대/원격 중계 관리는 후속 D09·D11·대회 사무국 단계의 과제다. 현재 기재된 범위 외 기능을 구현 완료라고 표시하지 않는다.

## 지역 시차·서머타임·절대 시간대 (추가 보완)

- 기존 방송용 `time`(17:00, 20:00 등)은 **각 개최 지역의 현지 시각**이다. 날짜만 전세계에 공통으로 표시하지 않는다. 지역별 개최지는 IANA 타임존(`Asia/Seoul`, `Asia/Shanghai`, `Europe/Berlin`, `America/Los_Angeles`, `America/Sao_Paulo` 등 총 기본 14개 권역)을 따른다. 지역 세계 설정에서 유효한 `timeZone`을 별도로 지정하면 이를 우선한다.
- `match.localDate`, `match.time`, `match.timeZone`은 **중계 개최지 일자/시각**이고, `match.utcAt`은 **절대 UTC 개시시각**이다. 실제 시뮬레이션의 공식 경기 날짜인 `s.days[].date`에는 UTC 일자를 사용한다. 예를 들어 LA의 1월 화요일 20:00(PST)은 **UTC 수요일 04:00**이지만, 서울의 화요일 20:00(KST)은 **UTC 화요일 11:00**이다. `Intl.DateTimeFormat`의 해당 연도 실제 시간대 데이터를 통해 미국/유럽 서머타임도 자동 반영한다.
- 국제대회는 참가 지역 중 개최지를 하나 선정해 `venueRegion`과 `venueTimeZone`을 고정한다. 참가팀의 **출신 국가 시간으로 경기 시간을 따로 해석하지 않는다**. 모든 대회는 중계 개최지 시각과 **한국 시청 기준 날짜·시간(KST)**을 UI에서 나란히 표시한다. 중계 시간은 실제 절대시각 기준으로 일정이 실행된다.
- 공식전 일정 예약은 개최지 현지 **경기일**과 UTC **경기일**을 모두 차단하며 이미 끝난 경기에도 적용된다. 현지 북미 화요일 저녁 공식전이 UTC 수요일 새벽이라고 해서 화요일 오후 스크림을 허용하거나, UTC 수요일 새벽에 같은 팀의 훈련 일정을 중복 배치하지 않는다. 기존 저장 파일에 `localDate`가 없으면 이전 날짜 규칙으로 처리한다.
- 스크림 오후/저녁 3시간 블록은 각 팀 **훈련 개최지 현지 시각**으로 계산한다. `scrimTimeOverlap`이 양측 블록의 실시간 UTC 교집합 **90분 이상**인지 확인한 뒤 편성한다. 현지 시간대의 이름만 같다고 먼 지역에서 실제 시간이 겹치지 않는다면 거절한다. 성립된 비공식 스크림의 양측 로그에 동일한 `startsAt`/`endsAt` ISO UTC 시각을 저장한다.
- 기존 월드 스키마 v15·저장 포맷 2를 변경하지 않는다. 옛 일정에서 `utcAt` 등이 없을 때 UI의 현지 시각 표시로 폴백하고, `startsAt` 없는 기존 스크림 이력도 정상적으로 열람·복원한다.

**한계:** 실제 공항 이동시간·비자·경기장 시설 예약·시차 적응(제트래그), 다중 국가 소속 구단의 홈베이스 구체화, 해외 원격 스크림 계약과 국제대회 현지 훈련 캠프는 별도 단계다. 시간대 변환과 양팀 UTC 중복 예약 방지를 구현했다고 이들까지 완료 처리하지 않는다.

## 스크림 상대 탐색·상호 수락 엔진 (추가 구현)

- 기존 일일 시간표를 **통과한 팀** 사이에서도 실제 연습 목적을 고려해 초대·수락 여부를 판단한다. 모든 구단과 매니저 구단의 자동 스크림에 같은 엔진을 사용하며, 무조건 매칭되는 보장된 계약이 아니다.
- **공식 맞대결 보호:** 두 팀 사이에 최근 3일 이내 치른 공식전이나 **앞으로 7일 이내 열릴 공식전**이 있으면 전력/연습 시간과 무관하게 스크림 금지. 8~14일 내 대결 예정인 상대와는 전술 노출 우려를 반영하여 상호 수락 확률이 낮아진다. 이미 끝난 같은 날 경기의 양 팀은 기본 공식전 예약 체크에도 걸린다.
- **강팀의 선택적 수락:** 상대보다 전력이 많이 높은 팀일수록 하위권 팀의 요청을 수락할 확률을 낮춘다. 약팀은 강팀과의 압박 연습을 선호해도 **강팀의 수락이 있어야만** 연습이 성립한다. 가까운 전력대의 상대를 자연스럽게 우선한다.
- **부진 구단의 자신감 재건:** 실제 완료한 공식전 최근 5개에서 **3연패**, 또는 2연패+주전 평균 사기 저하, 또는 독립적인 사기 저하가 있는 팀은 훈련 목표를 '자신감 회복'으로 전환한다. 이 구단이 더 약한 팀을 상대로 자신감을 회복할 필요가 있으면, 평소보다 수락 의사와 연습 선호도가 높아진다. 저전력 상대를 **강제 배정하지는 않는다**. 상대 구단 또한 자율적으로 수락한다.
- **반복 방지:** 직전 6일간 같은 상대와 반복 연습했으면 그 상대의 검색 가중치를 낮춘다. 훈련 관계를 강제로 끊는 고정 쿨다운이 아니라, 새로운 훈련 상대를 찾아보는 경향이다.
- **양방향 절차:** 초대 팀의 목적과 수락할 팀의 목적/승인 의향을 각각 계산한 뒤 훈련 상대 탐색 가중치를 지정한다. 선택된 상대가 거절하면 같은 시간대에 다른 후보를 최대 4회 탐색한다. 전원이 거절하거나 일정 충돌이면 해당 시간에 스크림은 열리지 않는다. 후보/상대 모두 같은 날짜/오후·저녁 슬롯이 비어 있어야 한다는 기존 **이중 예약 방지 조건이 먼저** 적용된다.
- 실제 성사된 각 스크림 세션의 양측 로그에 **각 구단이 스크림을 선택한 목적**을 독립 기록한다. 선수단 화면의 최근 스크림에 해당 목적을 표시한다. 이것은 공식 경기 내역이나 공개 메타에 합쳐지지 않는다.
- 실제 프로팀의 비공개 스크림 계약/거절 데이터를 재현한다고 주장하지 않는다. 이 시스템은 사용자의 현실성 목표를 모델링한 합리적인 게임플레이 휴리스틱이며, 특정 팀의 실제 운영 방침을 뜻하지 않는다.

**남은 범위:** 해외 국제대회 현지 팀과의 이동/훈련 캠프, 매니저의 수동 상대 초대·협상·거절 선택, 전술 유출의 장기적 누적 피해와 관전자에게 공개되는 관계 소문, 수년 단위 장기 매칭 균형/성능은 별도 D09·D11 작업이다.
