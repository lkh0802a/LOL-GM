# 40. 선수·육성·통합 세계 랭크·정보

### PLAYER-001 · 육성 원본은 실제 활동
선수 성장의 원인은 **실제 공식 경기 출전**, 실제 상대가 있는 **스크림**, 실제 **전 세계 통합 랭크 경기**의 서로 다른 경험과 피드백이다. 별도 **훈련 포인트의 수동 배분 및 훈련 강도 수치에 따른 운영**은 폐지되었다. 실제 경기가 실시되지 않았음에도 선수 성장을 위한 허위 실전 기록을 생성하거나 같은 활동·피로·성장을 중복 반영하지 않는다. [근거 #251](https://github.com/lkh0802a/LOL-GM/issues/251), [#236](https://github.com/lkh0802a/LOL-GM/issues/236) [#251 수동 훈련 철회 확인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245007620)

베테랑의 멘토링은 실제 활동·관계와 배움의 기회에 근거하며, 멘토로 지정했다는 사실만으로 선수 능력을 즉시 높이지 않는다. 멘토링은 별도의 주장 직책이나 임명에 따른 사기 보너스가 아니다. [#251 74B 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244712136), [#236 분야별 기록](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6244726542)

### PLAYER-002 · 세계 단일 5:5 랭크 큐
프로·아마추어·무소속·일반 참가자가 동일한 세계 랭크 생태계의 **5대5 팀 경기**에 참여한다. **1~5인 사전 파티를 모두 허용**하고, 고정 파티의 남은 자리만 실제 참가자로 매칭한다. 파티 결성이 곧 공식 프로 스크림/경기나 확정 팀워크 보너스는 아니다. [근거 #251 사용자 확정 #11C](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968), [#232](https://github.com/lkh0802a/LOL-GM/issues/232)

### PLAYER-003 · 합법적 랭크 매칭
주/부 역할 선호·제한적 자동 배정, 비공개 **MMR** 기반 탐색, 대기시간에 따른 합리적 탐색 확대, 팀 실력과 파티 규모 균형, 반복 자동 배정 완화 및 최상위 대기 관리가 적용된다. 직전 일반 매칭의 같은 팀원을 다시 만나는 것을 별도로 우대하거나 회피하지 않으며, 직접 구성한 파티의 구성원은 유지한다. 챔피언 선택 단계에서 매칭으로 배정된 역할은 별도로 교환하지 않지만 경기 중 적법한 라인 이동·전술은 금지하지 않는다. **국가별 핑 차이 보정은 없다.** [근거 #251 #12B·#13B·#32B·#33B·#36B·#44 수정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968), [#251 138A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798), [#251 172A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246141985)

### PLAYER-004 · 랭크 RP와 세계 순위
공개 랭크는 **RP 점수·세계 순위** 중심이며 별도의 티어 승급·강등 체계는 두지 않는다. RP 변화는 실제 승패를 기본으로 경기 전 팀 MMR 격차와 파티 구성의 매칭 불균형을 고려하되 같은 불균형을 이중 보정하지 않는다. **같은 RP의 선수는 공동 세계 순위**로 표시하며 안정적인 표시 순서가 서로 다른 공식 순위를 뜻하지 않는다. 공개 RP·순위와 함께 합법적으로 관측 가능한 솔로·부분 파티·5인 파티 비중과 역할·실제 경기 표본을 제공하되 비공개 MMR이나 미관측 개인 기량은 노출하지 않는다. 시즌 시작 때 공개 RP는 소프트 리셋하고, 내부 비공개 MMR은 일부 연속성을 가진다. RP 변화를 실제 선수 능력·프로 성적으로 동일시하지 않는다. [근거 #251 #31B 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968), [#251 #139B·#140 최종 수정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798), [#251 171C·174A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246141985), [#236 분야별 기록](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6246150224), [#232](https://github.com/lkh0802a/LOL-GM/issues/232)

### PLAYER-005 · 랭크 닷지·항복 선택 금지
랭크의 유효한 매칭·픽을 선택적으로 회피해 경기를 무효화하는 **닷지 기능을 도입하지 않는다**. 세계 통합 랭크에는 정상적인 항복 선택이나 투표를 두지 않고 정식 종료 조건까지 진행한다. 유효한 중단·탈주·불완전 경기 등은 기존 별도 처리 대상이며, 이를 항복으로 오인하거나 미실시 경기를 정상 완료로 날조하지 않는다. 이러한 실제 중단은 닷지 벌점 시스템을 신설하는 근거가 아니다. [근거 #251 #34 최종 수정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968), [#251 137A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798), [#236 랭크 적용 기록](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6245269539)

### PLAYER-006 · 세계 랭크 1인 1계정·닉네임 불변 (후속 정정)
전 세계 랭크 참가자는 **세계 인물 한 명당 고유 랭크 계정 하나**를 가지며 **닉네임 변경·부계정 생성은 허용하지 않는다**. 공개 계정의 소유자를 식별할 수 있으며 선수·구단 기록/검색과 동일한 안정적 인물 ID로 연결하지만, **별도의 실명 필드 생성·실명과 닉네임 병행 공개는 요구하지 않는다**. 비공개 MMR·실제 능력·잠재력·의료·다른 구단 조사 자료는 그대로 보호한다. [근거 #251 #190 최종 명시적 재정정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246200434) (이전 [#190A 실명 병행안](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246187723)은 **철회**)

### PLAYER-007 · 선수 자원과 정보의 경계
공식전·스크림·랭크·휴식·이동·의료·계약 의무는 유효한 세계 시간과 자원을 소비한다. 스카우팅은 적법한 관측 근거·표본·전문성에 따라 추정하며 다른 구단의 조사 결과나 미래 사실을 정답처럼 공개하지 않는다. 프로구단 소속 스카우트는 서로 다른 독립 프로구단에 동시에 고용될 수 없다. 모구단과 적법한 산하 2군·Academy의 조직 내부 공유는 허용하며, 합법적인 이직이나 공개 자료 분석까지 금지하지 않는다. 실제 고용·보고서 이력과 구단 소유 비공개 자료의 권한을 보존한다. [근거 #236](https://github.com/lkh0802a/LOL-GM/issues/236), [#238 192A 분야별 승인](https://github.com/lkh0802a/LOL-GM/issues/238#issuecomment-6246161393), [#251 192A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246141985)

관측이 없거나 표본이 적은 유망주의 능력·성장 평가는 **미관측 또는 불확실**로 표시하고, 숨은 실제 능력·잠재력이나 미래 사실을 확정된 평가로 제시하지 않는다. AI도 권한 없이 비공개 실제 능력·잠재력에 직접 접근하지 않으며 사용자와 같은 관측·정보 권한의 제약을 따른다. 관측 부족은 능력 부족이나 자동 계약을 뜻하지 않는다. [#251 M164B·M176B 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6312524720)

선수의 실제 개인 사정에 따른 정당한 휴가는 유효한 세계 시간과 기존 선수단 등록·대체 자격·일정을 함께 확인한다. 휴가를 이유로 실재하지 않은 사건이나 출전 기록을 만들지 않는다. [#251 73B 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244712136), [#236 분야별 기록](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6244726542)

선수의 숙소·합숙 시설 이용은 실제 활동 지역·상황과 시설 용량을 따르고 정상적인 이동·소통·회복에 반영한다. 매일 숙소를 수동 배치하도록 강제하거나 방송·기술 장비 관리 업무를 다시 도입하지 않는다. [#251 126B 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798)

모구단 1·2군의 코칭스태프 일부 공유는 실제 계약·업무시간·겸직 자격과 업무량을 충족할 때 가능하다. 같은 시간에 중복 점유하거나 같은 활동의 선수 성장 효과를 이중으로 부여하지 않는다. 1·2군이 같은 시설을 사용할 수 있으나 실제 이용 시간이 충돌하면 1군이 우선하며, 2군은 가능한 다른 시간과 자원을 이용한다. 시설 용량을 초과해 중복 예약하거나 우선권을 이유로 공식 경기 일정을 임의 변경하지 않고, 실제 이용 불가와 대체 가능성을 반영한다. [#251 134B·135A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798), [#237 분야별 기록](https://github.com/lkh0802a/LOL-GM/issues/237)

### PLAYER-008 · 은퇴 후 경력의 연속성
선수는 은퇴 후에도 실제 경력·역량·의사·자격에 따라 코치·분석가·스카우트 등 다른 직무를 택할 수 있다. 은퇴를 이유로 최고 수준의 전문성을 자동 부여하거나 취업을 일률적으로 보장하지 않는다. [근거 #251 #53B](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### PLAYER-009 · 국가와 공식 리그는 독립적인 생태계
게임 세계의 **국가별 선수·랭크/게임 인구·팬덤·인프라**와 공식 프로리그 소속은 서로 다른 상태다. 프로리그 없는 국가도 선수·랭크 활동과 인재 공급이 가능하며, 해당 국가에 **공식 리그가 실제로 생길 때** 해당 사무국을 생성한다. 모든 나라의 리그 출범을 강제하지 않는다. [근거 #251 국가 생태계 확정](https://github.com/lkh0802a/LOL-GM/issues/251) [#251 전 국가 공통 생태계](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6247901670)

### PLAYER-010 · 국적별 고정 잠재력 상한 금지
국가/출신 지역에 선천적인 선수 재능·성장 상한 또는 고정 특혜를 부여하지 않는다. 실제 국가별 선수 인구·참가 환경·연습 기회와 역사적 성과가 실질적 공급·스카우팅 기회 차이의 원인이 된다. [근거 #251 국가 생태계 확정](https://github.com/lkh0802a/LOL-GM/issues/251) [#251 국가별 재능 상한 금지](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6247901670)

### PLAYER-011 · 공식 결과 없는 아마추어 배경
아마추어 출신 선수는 적법한 **선수 배경·연고 및 성장 과정에 관한 서사적 설정**을 가질 수 있지만, 실제 아마추어 경기를 시뮬레이션하지 않는 영역에서 허위 세트·대진·전적을 공식 실경기 통계로 생성하지 않는다. 정식 3부 이상의 실제 리그는 별개로 공식 경기·순위·승강을 실행한다. [근거 #251 국가 생태계](https://github.com/lkh0802a/LOL-GM/issues/251), [#311](https://github.com/lkh0802a/LOL-GM/issues/311)

### PLAYER-012 · 국가별 다중 시즌 인구·신인 공급
게임 세계에서 국가별 게임·랭크 활동 인구와 구단·선수 공급은 경제·팬덤·노출·육성에 따라 장기적으로 변화한다. 리그가 없다는 이유로 선수 잠재력이 0이 되지 않으며 **필요성이 입증되지 않은 대규모의 완전한 선수 엔터티를 일괄 생성**하지 않는다. [근거 #251](https://github.com/lkh0802a/LOL-GM/issues/251), [#239](https://github.com/lkh0802a/LOL-GM/issues/239)
