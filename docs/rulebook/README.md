# LOL-GM 세계 규정집

**규정집 발행본:** v0.18.1

**2026-11-14 추가 승인:** **확정된 대회 회차의 재량 취소·무기한 연기, 양 팀 동시 실격·동시 기권, 공식 결승의 무우승**을 게임이 생성하는 제도에서 폐지한다. 필수 공식 대회 7개 및 매년 시장 기간 국가대표 주요대회는 **세계/시즌 확정 전** 참가·예비 일정·재정·시설 적격성을 검사한다(COMP-006·010·012·019, NAT-011, CAL-004). 단측의 실제 적법한 기권/실격은 상대 행정승으로만 기록하고 가상의 실경기를 생성하지 않는다. 과거 승인 이력은 효력 변경을 명시해 보존한다.

**대회 표기:** 법적 공식 대회명은 **World Championship**, 일반 약칭·게임 표시명은 **Worlds**로 통일한다. 한글 음역을 대회 표기로 사용하지 않는다.
**적용 범위:** LOL-GM 세계의 기본 규칙, 기관의 권한, 세계 안에서 시행되는 규정의 성립·효력·개정 원칙.

이 문서는 게임 세계의 **상위 헌장**이다. 현재 유효한 세계 상태와 사건, 그리고 실제 기관이 제정한 내부 규정은 이 헌장을 준수한다. 법령의 개정 가능성 자체를 금지하지 않으며, 법령을 제정·변경할 권한과 실제 효력 발생을 구별한다.

## 법규의 두 층

**세계 헌장:** 이 디렉터리의 CORE·COMP·NAT·CAL·TRANS·PLAYER·MATCH·BIZ·GOV 조문. 세계의 공통 사실과 보호된 권리·금지, 기관에 부여된 규정 제정·집행권의 범위를 정한다.

**세계 내부 시행 규정:** 위 헌장에 근거한 적법한 주체가 특정 대회·지역·시즌·회차에 대해 실제로 제정·공표·발효시킨 가변 규정. 규정을 제정할 권한이 있다는 것만으로 특정 규정이 이미 존재한다고 보지 않는다. 계약 체결·라이선스 발급 같은 개별 처분과 실제 경기 결과는 일반 규정의 제정과 구별한다.

세계 외부 헌장의 모든 세부사항이 영원히 고정된 것은 아니다. 변경권을 위임받은 내부 기관은 적법한 절차와 효력 시점에 따라 제도를 바꿀 수 있다. 다만 헌장이 보호하는 권리·금지와 이미 확정된 역사는 내부 개정으로 우회·소급 변경할 수 없다.

## 최초 세계와 장래 발전

최초 시즌은 실제 존재하는 구단·선수·국가협회·대회와 유효 계약을 바탕으로 **사전에 설계·검증된 지역별 초기 규정 체계**에서 시작한다. 권한 있는 기관은 그 초기 규정을 적법하게 제정·공표·발효시켜야 하며, 준비된 규정안이라는 이유만으로 곧바로 효력이 발생하지는 않는다. 각 지역의 합법적인 운영 방식과 규모는 다를 수 있지만 세계 시간·일정·등록·재정·출전권의 상호 충돌은 방지한다. 이후의 제도 개정은 실제 상황과 기관 권한에 따라 장래에 효력을 발생시키며, 초깃값을 영구 불변의 공통 제도로 만들지 않는다. 세부 검증은 [구현 진입점](../GAME_IMPLEMENTATION_ENTRYPOINT.md)의 초기 프리셋 수용 기준을 따른다.

## 규칙을 적용하는 순서

1. **사건 특정:** 실제 행위자, 소속, 장소·대회, 세계 시각, 당사자, 권한 및 영향을 받을 자원을 특정한다.
2. **헌장 적용:** 해당 분야의 상위 조문이 명시한 금지, 권리, 적용 범위와 권한 제약을 확인한다.
3. **내부 규정 확인:** 해당 사건·관할·시즌에 실제로 유효한 내부 시행 규정과 제정권·공표·시행 시각을 확인한다.
4. **실제 사실·계약 확인:** 선수·구단·국가협회·대회 참가 및 계약, 등록, 재정 원장, 의료, 정보권, 시간·시설·인력과 기존 확정 이력을 검증한다.
5. **판정:** 금지 또는 권한 없음은 거부한다. 필수 사실·권한이 검증되지 않으면 확정하지 않는다. 유효한 선택권 범위에 있는 의사결정은 적법한 주체에게 남긴다.
6. **결과 확정:** 적법한 결정과 실제 사건만을 해당 세계의 단일 시간·원장·경기 기록에 한 번 반영한다. 당시 규정을 기록하고 후속 개정이 과거 사건을 임의로 변경하지 않도록 한다.

**새로운 활동의 처리:** 헌장에 활동 명칭이 없다는 이유만으로 자동 허용·금지하지 않는다. 위의 판단 기준을 적용하고, 기존 권한을 벗어난 제도가 필요한 경우에는 정당한 제정 주체와 절차를 통하여 실제로 규정을 신설·개정한다.

**AI 판단:** AI는 실제 관측한 정보·상태·목표를 바탕으로 합법적인 대안을 선택할 수 있다. 정본은 모든 전략적 선택을 획일화하지 않지만, 같은 사실·동일한 행위의 적법성·권리·재정·시간·기록 판정은 일관되게 강제한다.

## 대표적인 적용 범위의 구별

- 네 종류(공식 지역·공식 국제·독립 지역·독립 국제)는 **구단 대회**의 하위 분류다. 국가대표 대회는 별개의 정규 체계다.
- 국가별 국가협회는 복수 대표팀의 운영과 감독·선수 선발을 담당하며, 국제사무국은 국가대표 대회 개최와 참가·일정 규정을 담당한다. 국가대표 귀속과 그 변경 심사, 첫 대회 등록 기본 인원은 NAT-004·NAT-011에 따른다.
- 12월 첫째 화요일 00:00 UTC부터 28일간 세계 통합 선수시장과 코치 FA가 동시에 열린다. 이 기간 **구단 실경기 네 종류만 금지**하며 적법한 국가대표 경기는 개최할 수 있다.
- Worlds D-032에서 기존 지표·승자승으로도 미해결인 8/9위 또는 16/17위 경계의 동률은 **결정전 참가팀 전원에게 최소 한 번의 실제 BO1 출전**을 보장하는 유한 결정전으로 가린다. 결정전 승패는 **해당 경계 진출·상위 시드 판정에만** 반영하고 리그 페이즈 정규 승수·SoS·세트 득실·순위에 합산하지 않는다. 추첨은 대진·부전승 배정에만 사용한다.
- World Championship 결승의 피날레 지위는 **구단 공식 대회 시즌**에 적용한다.
- 실제 선수·계약·대회 출전 명단과 세계 시각은 각각 구별되면서도 하나의 세계 상태에 귀속한다. AI와 사용자에게 같은 정보·권한·재정 제약을 적용한다.

## 구현과 세계 규칙의 구별

**게임 제작 시작점:** [구현 진입·판정 계약](../GAME_IMPLEMENTATION_ENTRYPOINT.md).

UI 조작·표시 방식은 [인터페이스 요구사항](../interface-spec/USER_EXPERIENCE_REQUIREMENTS.md)에, 저장·QA·제품 수용 요구는 [구현 수용 명세](../implementation-spec/WORLD_ENGINE_AND_PRODUCT_ACCEPTANCE.md)에 둔다. **UI와 기술 구현은 세계 헌장 및 세계 내부 시행 규정 어느 쪽에도 속하지 않는다.**

역사적 변경 로그와 자료 추적은 [변경 이력](CHANGELOG.md)에서 별도 관리한다. 그 문서는 규범 본문이나 게임의 실제 시행 규정이 아니다.
