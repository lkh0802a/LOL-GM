# 50. 경기·밴픽·스크림·패치

### MATCH-001 · 실제 5:5 게임과 단일 경기 결과
구단 공식·독립 경기, 국가대표 경기, 스크림·랭크의 실제 결과는 유효한 게임/경기 원본과 규정에서 확정한다. 경기 승패를 고정된 OVR 기반 확률이나 임의로 생성한 경기 결과로 대체하거나 복수의 경기 엔진이 동일한 결과를 독립적으로 확정하도록 해서는 안 된다. 선수 행동·전술·자원·전투·건물/승리조건의 실제 효과를 반영한다. **공식 Bo3는 실제 2승, 공식 Bo5는 실제 3승을 먼저 확보한 팀이 시리즈에서 승리하면 종료**하며, 이기지 못한 남은 세트를 실시한 것으로 기록하지 않는다. 비공식 스크림의 합의된 세트 전부 실시 원칙은 MATCH-005에 따른다.
### MATCH-002 · Fearless Draft 불변
시리즈에 적용되는 **Fearless Draft의 유효 규칙과 이전 세트 챔피언 사용 이력**은 영구 보존한다. 사무국·대회 포맷 AI·패치가 임의 해제하거나 우회할 수 없다.
### MATCH-003 · First Selection 불변
**First Selection**의 유효한 선후 선택권과 밴픽 적용 절차도 일반적인 사무국 변경 대상이 아니다. 당시 시리즈·세트에서 확정된 권리와 드래프트 결과를 보존한다. 실제 밴픽은 해당 시리즈·세트의 세계 시간과 유효한 Fearless Draft·First Selection 및 대회 규정에 따라 확정한다. 적법한 감독의 선택 전에 이를 자동 확정하거나 입력 지연만으로 실제 존재하지 않은 기권·기술 사고를 생성하지 아니한다.

**첫 세트의 First Selection**은 홈팀을 지정한 국내 더블 라운드로빈 경기에서는 홈팀, 명시적 시드가 있는 국내 플레이오프에서는 상위 시드팀, 국제 녹아웃·브래킷에서는 적법하게 기록된 코인 토스 결과로 배분한다. **둘째 세트 이후에는 직전 세트 패자**가 First Selection을 보유한다. 해당 권리자는 진영(블루/레드) 또는 픽 순서(선픽/후픽) 중 한 축을 먼저 선택하고 상대가 남은 축을 선택한다. 대회별 첫 세트 권한의 해당 맥락을 확인하지 않은 채 다른 대회용 배분 방식이나 가상 경기 결과를 대입해서는 아니 된다.
### MATCH-004 · 세트 사이 선수 교체
Bo3·Bo5에서 **세트 사이** 합법적인 등록 선수 교체는 허용하지만, **진행 중인 한 세트에서 선수 교체는 불허**한다.

관리 구단의 각 공식 경기에서 최종 출전·등록의 적법성은 감독이 확인한다. 감독의 유효한 결정 없이 선발을 확정하거나 경기를 실행하지 아니한다. 부상에 따른 긴급 대체 등록은 대회가 해당 예외를 명시적으로 허용한 경우에만 의료 확인과 등록 심사를 거쳐 가능하다. 타 구단의 비공개 진단을 공개하거나 선수를 자동 생성해 무조건 등록하지 않는다.

### MATCH-005 · 스크림의 실재성과 비공개
스크림은 실제 두 팀의 수락·유효 시간·선수 점유·연습 목적과 경기 로그를 기준으로 운영한다. 두 구단의 상호 동의 없는 전략/비공개 스크림 자료 공개는 불가하다. 스크림에서 **Bo3 또는 Bo5로 합의했다면 선착 승수에서 종료하지 않고 실제로 합의한 모든 세트**를 실시한다. 정당한 중단이 발생한 경우에만 완료된 세트의 경기·시간·피로·성장·관측 이력을 보존하고, 미실시 세트를 임의 결과로 채우지 않으며 시리즈 상태를 중단 또는 미완료로 기록한다. 요청·수락·예약 후 합법적인 취소에는 실제 통보 시각과 계약·관계상의 유효한 취소 조건을 적용한다. 세트 간 전술·선수·챔피언의 변경 및 실험은 해당 규정이 허용하는 범위에서 가능하며, 중단 시 이미 완료한 세트의 이력·자원을 지우거나 미실시 세트를 승패로 조작하지 않는다.

### MATCH-006 · 원격 스크림
해외 구단과 원격 스크림을 할 수 있고 **지역 간 네트워크 핑/지연 차이를 게임 내 경기 페널티로 적용하지 않는다**. 다만 시차·팀 수락·선수 일정·회복·실제 이동 점유는 유지한다.

### MATCH-007 · 패치 적용과 과거 경기
패치의 예정안·확정·실제 적용은 구별한다. 글로벌 패치가 실제 적용되면 **통합 랭크도 즉시 해당 패치**를 사용하지만, 공식 대회는 **해당 대회에 사전 지정된 패치 버전(pinned patch)**를 준수한다. 과거 경기·스크림 기록을 나중 패치로 소급 재계산하지 않는다. 신규 챔피언의 실제 출시와 **전 세계 프로 공식 경기 출전 허용일**은 구별한다. 아직 프로 출전 허용일이 도래하지 않은 챔피언은 프로 공식전에 사용할 수 없으나, 당시 게임 패치에서 정상적으로 사용할 수 있는 훈련·스크림에서는 적법한 연구가 가능하다. 출전 허용일 도래만으로 진행 중인 공식 대회의 고정 패치·사전 확정 챔피언 풀을 변경하지 아니한다.
### MATCH-008 · 핫픽스 시각
실제 경기·패치 관측에 근거하여 중대한 밸런스 불균형이 확인된 경우에만 **순수 밸런스 핫픽스**를 시행할 수 있다. 시행 시점은 **발견 당일 전 세계의 해당 일자 공식 대회 경기와 세트가 모두 종료된 이후**이며, 같은 판정에 따른 발효는 **한 번만** 기록한다. 이미 진행 중인 Bo 시리즈의 다음 세트부터 즉시 시행하거나, 당시 대회에 지정된 패치 잠금을 소급 변경해서는 안 된다. 기술·방송 장애 또는 임의의 게임 버그 사건을 핫픽스 사유로 생성하지 않는다.
### MATCH-009 · 실제 정보가 전술·판단에 미치는 효과
감독·AI 구단의 전술·상대 준비·밴픽은 실제 합법 정보, 선수 숙련·활동, 당시 패치와 팀 자원·상대 관측에 근거한다. 사전에 알 수 없는 향후 경기 결과, 타 구단의 비공개 스크림 정보 또는 근거 없이 확정된 승률 보정값을 입력으로 사용하지 않는다. 선수의 게임 중 오더·콜·실제 동선·교전 결정은 당시 선수별 시야·자원·숙련·전술 이해·소통과 신뢰에 따라 이루어진다. **상대가 공개·적법하게 관측할 수 있는 우리 전술을 읽고 대응할 가능성**까지 여러 전략 가설로 비교할 수 있으나, 이는 당시 분석 역량·정보·시간·연산 자원의 범위에서 이루어지는 유한한 판단이며 상대의 비공개 의도나 미래 선택을 정답으로 열람하는 무한 역예측을 뜻하지 않는다. **경기 진행 중 단일 세트에는 감독이 새 명령을 직접 투입하지 않으며**, 세트 사이 적법한 밴픽·출전·전략 조정과 구별한다. 강팀이란 이유만으로 교전의 승리나 패배를 미리 확정하지 않고 실제 전장의 결과에 따른다.
### MATCH-010 · 실제 근거 없는 기술 사고·경기 중단 사건의 금지
세계의 대회 운영·가상 게임 패치와 별개로 **가상 기술/방송 시스템 사고, 핑 장애, 퍼즈/리메이크 및 개인 심판 캐릭터**를 흥미 유발을 목적으로 하는 무작위 사고 이벤트로 생성하지 않는다. 실존 계약·선수/구단 참가·등록 위반과 정당한 규정상 기권 등은 별도 실제 사건으로 처리한다.
### MATCH-011 · 별도 주장 직책 및 가산의 금지
선수의 **독립 주장(captain) 직책·임면 제도·주장 전용 사기/관계/팀워크 보너스·주장 이벤트 시스템은 도입하지 않는다**. 전술 지시, 경기의 실제 커뮤니케이션·주요 오더, 선수 성향·코칭·팀워크의 효과는 기존 시스템의 유효한 사건·상태 정보를 통하여 처리하며 주장 전용 보너스로 중복 계산하지 않는다.
