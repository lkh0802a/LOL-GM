# 50. 경기·밴픽·스크림·패치

### MATCH-001 · 실제 5:5 게임과 단일 경기 결과
공식 경기·독립 대회·스크림·랭크의 실제 결과는 유효한 게임/경기 원본과 규정에서 확정한다. 경기 승패를 고정된 OVR 기반 확률이나 임의로 생성한 경기 결과로 대체하거나 복수의 경기 엔진이 동일한 결과를 독립적으로 확정하도록 해서는 안 된다. 선수 행동·전술·자원·전투·건물/승리조건의 실제 효과를 반영한다. [근거 #233](https://github.com/lkh0802a/LOL-GM/issues/233), [#241](https://github.com/lkh0802a/LOL-GM/issues/241)

### MATCH-002 · Fearless Draft 불변
시리즈에 적용되는 **Fearless Draft의 유효 규칙과 이전 세트 챔피언 사용 이력**은 영구 보존한다. 사무국·대회 포맷 AI·패치가 임의 해제하거나 우회할 수 없다. [근거 #311](https://github.com/lkh0802a/LOL-GM/issues/311), [#234](https://github.com/lkh0802a/LOL-GM/issues/234) [Fearless 고정 범위 사용자 정정](https://github.com/lkh0802a/LOL-GM/issues/232#issuecomment-6456922011)

### MATCH-003 · First Selection 불변
**First Selection**의 유효한 선후 선택권과 밴픽 적용 절차도 일반적인 사무국 변경 대상이 아니다. 당시 시리즈·세트에서 확정된 권리와 드래프트 결과를 보존한다. 실제 사용자 감독의 수동 밴픽 결정에는 현실 시간 카운트다운을 강제하지 않는다. 확정된 밴픽의 게임 세계 내 소요시간·대회 적법성·Fearless·선택권과 기록·저장은 유지하며, 입력 중이라는 이유로 자동 기권이나 허구의 기술 사고를 만들지 않는다. [근거 #311](https://github.com/lkh0802a/LOL-GM/issues/311), [First Selection 고정 범위 사용자 정정](https://github.com/lkh0802a/LOL-GM/issues/232#issuecomment-6456922011), [#251 218A 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246141985)

### MATCH-004 · 세트 사이 선수 교체
Bo3·Bo5에서 **세트 사이** 합법적인 등록 선수 교체는 허용하지만, **진행 중인 한 세트에서 선수 교체는 불허**한다. [근거 #251 #21A 재확인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

이전 선발이나 저장 구성을 불러올 수 있으나 관리 구단의 각 공식 경기에서 최종 출전·등록의 적법성은 감독이 확인한다. 클릭을 줄인다는 이유로 감독의 확인 없이 선발을 확정하거나 경기를 자동 실행하지 않는다. 부상에 따른 긴급 대체 등록은 대회가 해당 예외를 명시적으로 허용한 경우에만 의료 확인과 등록 심사를 거쳐 가능하다. 타 구단의 비공개 진단을 공개하거나 선수를 자동 생성해 무조건 등록하지 않는다. [#251 122B·123B 사용자 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6245258798)

### MATCH-005 · 스크림의 실재성과 비공개
스크림은 실제 두 팀의 수락·유효 시간·선수 점유·연습 목적과 경기 로그를 기준으로 운영한다. 두 구단의 상호 동의 없는 전략/비공개 스크림 자료 공개는 불가하다. 세트 간 전술·선수·챔피언의 변경 및 실험은 해당 규정이 허용하는 범위에서 가능하며, 중단 시 이미 완료한 세트의 이력·자원을 지우거나 미실시 세트를 승패로 조작하지 않는다. [근거 #251 #38~43](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-006 · 원격 스크림
해외 구단과 원격 스크림을 할 수 있고 **지역 간 네트워크 핑/지연 차이를 게임 내 경기 페널티로 적용하지 않는다**. 다만 시차·팀 수락·선수 일정·회복·실제 이동 점유는 유지한다. [근거 #251 #44 수정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-007 · 패치 적용과 과거 경기
패치의 예정안·확정·실제 적용은 구별한다. 글로벌 패치가 실제 적용되면 **통합 랭크도 즉시 해당 패치**를 사용하지만, 공식 대회는 **해당 대회에 사전 지정된 패치 버전(pinned patch)**를 준수한다. 과거 경기·스크림 기록을 나중 패치로 소급 재계산하지 않는다. [근거 #232](https://github.com/lkh0802a/LOL-GM/issues/232), [#251 #35A](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244488968)

### MATCH-008 · 핫픽스 시각
실제 경기·패치 관측에 근거하여 중대한 밸런스 불균형이 확인된 경우에만 **순수 밸런스 핫픽스**를 시행할 수 있다. 시행 시점은 **발견 당일 전 세계의 해당 일자 공식 대회 경기와 세트가 모두 종료된 이후**이며, 같은 판정에 따른 발효는 **한 번만** 기록한다. 이미 진행 중인 Bo 시리즈의 다음 세트부터 즉시 시행하거나, 당시 대회에 지정된 패치 잠금을 소급 변경해서는 안 된다. 기술·방송 장애 또는 임의의 게임 버그 사건을 핫픽스 사유로 생성하지 않는다. [근거 #232 최종 사용자 수정](https://github.com/lkh0802a/LOL-GM/issues/232), [#232 불변 드래프트·핫픽스 적용 정정](https://github.com/lkh0802a/LOL-GM/issues/232#issuecomment-6456922011)

### MATCH-009 · 실제 정보가 전술·판단에 미치는 효과
감독·AI 구단의 전술·상대 준비·밴픽은 실제 합법 정보, 선수 숙련·활동, 당시 패치와 팀 자원·상대 관측에 근거한다. 사전에 알 수 없는 향후 경기 결과, 타 구단의 비공개 스크림 정보 또는 근거 없이 확정된 승률 보정값을 입력으로 사용하지 않는다. [근거 #235](https://github.com/lkh0802a/LOL-GM/issues/235), [#280](https://github.com/lkh0802a/LOL-GM/issues/280)

### MATCH-010 · 가상 시스템/방송 기술 사고 이벤트 배제
세계의 대회 운영·가상 게임 패치와 별개로 **가상 기술/방송 시스템 사고, 핑 장애, 퍼즈/리메이크 및 개인 심판 캐릭터**를 흥미 유발을 목적으로 하는 무작위 사고 이벤트로 생성하지 않는다. 실존 계약·선수/구단 참가·등록 위반과 정당한 규정상 기권 등은 별도 실제 사건으로 처리한다. [근거 #242 2026-10-25 기술 사고 전면 제외](https://github.com/lkh0802a/LOL-GM/issues/242), [#251](https://github.com/lkh0802a/LOL-GM/issues/251) [기술 사고·퍼즈·리메이크 최종 철회](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244903948)

### MATCH-011 · 별도 주장 직책 시스템 제외
선수의 **독립 주장(captain) 직책·임면 UI·주장 전용 사기/관계/팀워크 보너스·주장 이벤트 시스템은 도입하지 않는다**. 전술 지시, 경기의 실제 커뮤니케이션·주요 오더, 선수 성향·코칭·팀워크의 효과는 기존 시스템의 유효한 사건·상태 정보를 통하여 처리하며 주장 전용 보너스로 중복 계산하지 않는다. [근거 #251 주장 시스템 최종 철회](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244600843)
