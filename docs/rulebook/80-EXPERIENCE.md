# UI·UX 요구사항 이전 안내 — 세계관 정본 제외

감독 화면, 메뉴, 알림, 선수 비교, 뉴스 및 저장·복구 인터페이스 등 종전 `UI-001`부터 `UI-010`까지의 **승인된 제품 요구사항은 삭제하지 않고** 별도 [UI·UX 요구사항 원본](../interface-spec/USER_EXPERIENCE_REQUIREMENTS.md)으로 이동하였다.

이 파일은 과거 문서 링크 호환을 위한 **비규범적 경로 안내**다. 게임 세계 외부 헌장과 세계 내부의 시행 규정은 UI 명세와 분리되어 있으며 UI 조작·표시 방식만으로 선수 자격, 계약, 대회, 세계 기록, 재정 의무를 제정·개정할 수 없다.

이전 원본 승인 근거·각 UI 식별자와 기존 규칙의 연결은 위 UI·UX 요구사항에 보존되어 있다.
