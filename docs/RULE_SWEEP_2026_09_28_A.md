# LOL GM — 2026-09-28 최종 규칙 스윕 (1–35)

상태: 확정

1. 선수↔감독은 관계+신뢰 2축.
2. 모든 선수 쌍에 관계 상태 존재.
3. 유명 선수만 실체 에이전트 엔티티 사용.
4. 재계약 제안 거절 뒤 냉각기간 발생.
5. 완전 결렬 협상은 의미 있는 상황 변화가 있어야 재개.
6. 출전시간/역할 약속은 계약 조항+구두 약속 모두 가능.
7. 약속 위반 영향은 중요도/지속/선수 성향을 엔진이 종합.
8. 선수 계약 기간은 고정 범위 대신 상황별 자유 협상.
9. 팀/선수 옵션 행사 가능 기간은 계약에 명시.
10. 바이아웃은 구단 거부 불가형/협상 개시권형 모두 지원.
11. 최종 국제대회 후 14일 우선협상 종료 뒤 타팀은 가계약 가능, 기존 계약 종료 시 발효.
12. 타지역 이적/임대는 영입 지역 이적시장만 열리면 가능.
13. 임대→완전이적 옵션/의무 실행은 추가 이적 횟수로 세지 않음.
14. 이적료는 일시불/분할/성과 조건부 추가금 지원.
15. 모든 완전이적은 선수 동의 필요.
16. 불화의 경기력 영향은 관계 악화 정도에 따라 엔진이 단계 적용.
17. 포지션 전향 완료는 숙련+훈련기간+스크림/실전 경험 종합.
18. 전향 완료 뒤 공식 주포지션 변경은 등록 기간에 선택.
19. 전향 취소 가능하나 기존 포지션 숙련 손실 일부는 유지.
20. 선수는 포지션 전향 제안을 성향/커리어 상황에 따라 수락·거절.
21. 공식 등록 해제/추가는 승인 즉시 효력.
22. Academy 글로벌 연령 제한 없음.
23. Academy 베테랑 등록은 지역 사무국 규정.
24. 국제대회 중 2군 선수의 1군 훈련 합류 금지.
25. 2군이 모구단 때문에 승격 불가하면 다음 자격 독립팀이 승격권 승계.
26. 2군/Academy 국제대회 참가 여부는 대회별 규정.
27. 취득했지만 비활성인 로컬 자격은 유효기간 존재.
28. 로컬 취득 조건은 지역 사무국+국제 사무국 협상 엔진으로 합의.
29. 로컬 조건 변경 시 진행 중 선수는 구규칙, 신규 진행부터 신규칙.
30. 지역 합병/분할 시 선수는 후속 지역 로컬 중 하나 선택.
31. 구조개편으로 비로컬이 된 기존 계약 선수는 계약 종료까지 레거시 로컬 인정.
32. 구조개편 이벤트가 동일 구단 존속 여부를 명시.
33. 구조개편 시 일부 계약은 재협상 가능.
34. 팀 역사 승계는 successor club 관계로 처리.
35. 일반 자발적 타지역 이전은 기존 구단 해체+새 지역 신규 구단 창단만 허용.
