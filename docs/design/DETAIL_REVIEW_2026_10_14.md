# 전 분야 디테일 통합 검토 목록

이 문서는 사용자가 한 번에 검토하도록 모은 참고 목록이다. 단일 개발 지침은 docs/DEVELOPMENT.md이며 이를 대체하지 않는다. 앞서 승인한 항목은 개발 지침12.5.4.13.7–8에 연결했다. 아래의 추가 세부안은 모두 구현됐거나 새 수치/정책까지 승인됐다는 뜻이 아니다. 이미 있는 기능은 실제 연결을 확인해 보강한다. 최신 사용자 정정으로 직원/감독 인수인계는 별도 신규 기능에서 제외한다. 기존 계약·자료·재정·기록 유지 조건만 남긴다. 후보 운용·선발/교체·포지션 전향은 실제 기존 기능이며 신규 구현 항목이 아니다. 나머지 항목도 코드 조사 전 신규로 단정하지 않는다.

## 1. 시작과 구단 선택

- 선택 전에 리그 규칙·구단 목표·재정·선수단 구성·감독의 실제 권한을 확인한다.
- 1군 감독과 산하 선수단 감독이 직접 결정할 수 있는 일을 구분한다.
- 세계 설정을 변경했을 때 영향을 받는 대회·구단·하부리그 연결을 보여준다.
- 시작 직후 해야 할 일과 선수단 확정 조건을 비서가 정리한다.
- 게임 시작·새 게임 생성·다른 저장 불러오기를 구분하고 현재 작업을 보호한다.

## 2. 선수 신원과 개성

- 이름·닉네임·선수ID를 분리하고 화면 갱신으로 이름을 바꾸지 않는다.
- 새 선수 닉네임은 지역별 자연스러움·중복·금칙어·시드 재현성을 검증한다.
- 성격은 피드백 수용·주전 경쟁·계약 요구·적응 등 실제 행동에 연결한다.
- 장점과 약점·선호 역할·플레이 성향을 관측 근거와 함께 설명한다.
- 전성기·성장·부진을 단일 나이/잠재력 숫자로 단정하지 않는다.
- 은퇴 상담과 지도자 전환 희망은 실제 전문성·채용 권한과 연결한다.

## 3. 관계·주장·선수단 분위기

- 주장 선임과 선수단 의견 전달을 구분하며 주장이 감독 결정을 대신하지 않는다.
- 신입 선수의 언어·생활·전술 용어·기존 선수 호흡 적응을 지원한다.
- 같은 포지션 경쟁·출전 기회·역할 변경에 대한 반응을 기록한다.
- 선수와의 출전·역할·휴식·보강 약속을 당시 대화와 이행 기록에 연결한다.
- 문제가 생긴 원인과 감독이 대응할 수 있는 행동을 보여준다.
- 분위기 수치 하나로 승패를 강제하거나 임의 사건을 반복 생성하지 않는다.

## 4. 검색·관측·영입 분석

- 이름/닉네임·포지션·계약 상태 검색과 관심 목록·비교·상세 복귀를 연결한다.
- 검색 조건·선택·스크롤·입력 초안을 이동 뒤 보존한다.
- 보고서의 작성일·관측 경기 수·담당자·관측 범위와 정보 노후화를 표시한다.
- 구단 요구와 선수가 맞는 이유·맞지 않는 이유·모르는 부분을 구분한다.
- 스카우트와 분석가가 다른 의견을 낼 경우 각 근거를 비교한다.
- 관측 과제의 담당·기간·실제 비용·완료 연락을 연결한다.
- 상대 비공개 능력·연습·미래 결과를 추천 근거로 사용하지 않는다.

## 5. 선수·대리인·구단 협상

- 선수 요구·대리인 주장·판매 구단 조건을 구분한다.
- 경쟁 제안·역할 약속·계약 기간·계약금·성과급·옵션·보장 조건을 검토한다.
- 제안→대기/예정 시각→실제 연락→판단 중단→합의→별도 수동 최종 계약을 유지한다.
- 합의만으로 자리·예산·선수를 예약하거나 소속을 바꾸지 않는다.
- 조건 수정은 기존 대기 제안을 수동 취소하고 새 제안을 내며 전체 역사를 보존한다.
- 구단 합의·선수 계약·지급·자격/등록의 막힌 단계와 사유를 보여준다.
- 대여 목적·실제 역할·구매 조건·급여 분담·복귀 자리와 실제 지급을 연결한다.

## 6. 선수단 구성·선발·전향 — 기존 기능 보존·새 화면 연결

- 주전/후보의 역할 약속과 실제 선발을 구분한다.
- 다음 경기 출전 예고·교체 준비·최근 실전 감각을 확인한다.
- 포지션 전향은 선수 동의·코치·연습 과제·시험 출전·중단 판단을 거친다.
- 여러 선수 교체 뒤 역할·소통·조합을 다시 준비한다.
- 1·2군 이동·임대 선수·복귀 자리·비로컬 자격을 현재 규칙으로 검사한다.
- 미완료 선발·중복 배치·이동한 선수·오래된 입력을 적용하지 않는다.

## 7. 연습 일정·스크림·솔로 랭크

- 숫자 배분 화면 대신 스크림·솔로 랭크·피드백/전술 회의·휴식을 일정에서 편성한다.
- 스크림이 팀 연습이므로 별도 팀 연습으로 중복 소비하지 않는다.
- 스크림 상대의 목적·수락/거절·반복 상대·취소 이력·공식전 상대 비밀 유지를 반영한다.
- 연습 목표는 챔피언/조합/운영 등 실제 준비 내용과 연결한다.
- 솔로 랭크는 선수별 챔피언 과제·선호·자율 연습·실제 참가를 구분한다.
- 실제 경기 기록에서 피드백 과제를 만들고 다음 준비에서 재확인한다.
- 경기·방송·행사·이동·회복과 겹치는 일정을 막는다.
- 하루 자원을 중복 지급하지 않고 완료 기록을 다시 소비하지 않는다.

## 8. 의료·휴식·복귀

- 현재 건강 상태·의료진 소견·제한 사항·당시 예상과 현재 상태를 구분한다.
- 제한적 연습 복귀와 공식 경기 출전 가능 여부를 구분한다.
- 선수 출전 희망·코치 판단·의료 조건을 함께 검토한다.
- 단계적 복귀·휴식·재활 계획을 실제 일정과 연습 참가에 연결한다.
- 부상 직전 사용량·의료 처리·복귀 기록을 당시 자료로 확인한다.
- 의료 예측을 보장으로 표시하거나 감독 지시로 출전 불가를 우회하지 않는다.

## 9. 밴픽·전술·경기 준비

- 경기 전 준비 조합·대체안·선수 자신 있는 선택을 정리한다.
- 상대가 예상과 다른 선택을 하면 근거를 보고 대응한다.
- 전술 설정과 선수의 숙지/실제 수행을 구분한다.
- 최근 챔피언 연습·포지션 경험·조합 역할을 숙련 설명에 연결한다.
- 출전 자격·선발·선택권·대회 규칙과 패치 사용 가능 시점을 확인한다.
- 미완료 입력 취소·복귀·옛 밴픽 입력 거절과 수동 감독 결정을 보존한다.

## 10. 경기 판정·결과 설명

- 원래 경기38항목·감사8항목의 전체 조건을 유지한다.
- 실제 넥서스 종료를 확인하며 골드만으로 승자를 정하지 않는다.
- 감독의 사전 계획과 선수들의 실제 현장 판단을 결과에서 구분한다.
- 중요한 교전·귀환·시야·주요 목표 판단을 당시 관측과 사건으로 설명한다.
- 결과와 원인이 불확실한 부분을 구분하고 사후 설명을 사실처럼 발명하지 않는다.
- 같은 입력·시드·저장 복원에서 재현성을 확인한다.

## 11. 직원·시설·구단 조직

- 코치·분석가·스카우트·의료·재정 담당자의 실제 업무와 권한을 구분한다.
- 업무 제안·담당 배정·완료 보고·의견 충돌을 감독 결정에 연결한다.
- 직원 채용·면접·계약·교체·해지 보상과 실제 지원 효과를 연결한다.
- 담당자가 바뀌어도 구단 소유 자료와 업무가 사라지지 않게 한다. 별도 인수인계 기능은 제외한다.
- 시설 증설 중 제한·완공일·유지비·이용 부서를 확인한다.
- 시설 단계 상승을 모든 선수에게 같은 효과로 적용하지 않는다.

## 12. 스폰서·개인 방송·상업 활동

- 구단 대표/유니폼·장비/주변기기·선수 개인·개인 방송·콘텐츠/행사를 구분한다.
- 안정형/성과형/장기형은 후원 대상과 별개인 보수·기간 방식으로 유지한다.
- 계약별 브랜드/업종·권리 범위·독점·이행 활동·기한·보수를 명시한다.
- 개인 방송은 계약별 정액 보수와 선수/구단 귀속 금액을 명시한다.
- 방송·행사 의무와 선수 희망을 경기/연습/휴식 일정과 협의한다.
- 실제 이행 근거가 있어야 정산하며 계약/예약만으로 현금을 지급하지 않는다.
- 구단 수입·선수 개인 수입·대회 중계권 수입을 분리한다.
- 취소·미이행은 계약에 명시된 대체 일정/정산 조건만 적용한다.
- 업종 독점 충돌과 동일 권리/활동/수입의 중복 반영을 막는다.

## 13. 재정·구단주·감독 경력

- 현재 현금·받을 돈·확정 채무·조건부 수입·예상 결산을 구분한다.
- 이적료 분할 지급·성과 조건·미수금·선지급을 실제 정산과 연결한다.
- 후원 종료나 큰 계약 종료 뒤의 수입 공백을 표시한다.
- 구단 목표·운영 방침·지원 요청·보강 약속·평가 면담을 기록한다.
- 감독 평가는 실제 목표/권한/수행과 연결하며 성적 한 줄로 단정하지 않는다.
- 감독 변경 때 기존 계약/일정/재정 의무를 보존한다. 별도 인수인계 기능은 제외한다.
- 개인 기록과 구단 기밀의 소유권/접근 권한을 구분한다.

## 14. 리그·대회·원정·등록

- 통합1부 아래 국가별 복수2부·2군/육성·승격·자격의 원래 전체 연결을 유지한다.
- 구단 연고국/육성 거점/참가 리그·국적/거주/로컬·계약/대여/등록을 구분한다.
- 계약 선수와 대회 출전 가능 선수를 구분하고 마감/교체/불가 사유를 계약 전에 확인한다.
- 국제 참가권·현행/다음 시즌 규칙·시즌 전환을 실제 성적으로 연결한다.
- 개최지 체류·현지 연습 상대·이동/시차·공식 경기 준비의 충돌을 처리한다.
- 같은 중계·팀·장소 점유와 실제 종료 초과의 다음 일정 순연을 저장/역사까지 연결한다.
- 사무국 등록 거절·자료 보완·규정 질의/이의 제기를 기존 규칙에 따라 처리한다.

## 15. 뉴스·역사·비서·받은편지함

- 원래13서사와 선수·직원·구단·라이벌·감독·시즌 회고를 실제 사건에 연결한다.
- 당시 발언·계약·경기 기록을 보존하고 현재 상태로 과거를 재작성하지 않는다.
- 판단할 연락마다 진행을 멈추고 기한·담당 의견·관련 화면을 연결한다.
- 비서는 근거·선택지·현재 부담을 정리하며 감독 결정을 대신하지 않는다.
- 읽음/안 읽음·처리 완료·취소·후속 확인을 구분하고 중복 알림을 막는다.
- 불필요한 반복 연락 대신 실제 새 정보나 결정이 필요한 사건을 전달한다.

## 16. 화면·표시·저장·접근성·성능

- 승인 시안 스타일로 화면/사용 흐름을 전면 재구축하고 기존 UI를 섞지 않는다.
- 모바일 상단 가로 메뉴·하위 탭·현재 위치·뒤로가기·주요 행동 접근을 유지한다.
- 목록→비교/상세→복귀, 검색/선택/스크롤/미완료 입력을 보존한다.
- 거절 사유에서 해결 화면으로 이동하고 적용 전 변경 내용을 명확히 검토한다.
- 금액/기간/비율/시각의 내부 단위를 보존하고 공통 표시 함수로 통일한다.
- 저장/불러오기·현재 슬롯·옛 입력 거절·실패 복구를 실제 게임 흐름으로 검증한다.
- 가로 넘침·터치 크기·글자 확대·대비·색만으로 상태 구분 금지·키보드/읽기 순서를 검증한다.
- 분석실/레이더는 관측 범위·표본·단위·정보 누락을 드러낸다.
- 최적화는 재현 병목의 제한된 전후 측정과 전체 결과 동일성으로 확인한다.
