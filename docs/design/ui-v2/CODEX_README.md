# LOL-GM UI v2 — 코덱스 전달용 참조 프로토타입

## 확인 방법

1. `LOL-GM_UI_v2_interactive.html` 파일을 브라우저에서 엽니다. 빌드/서버/외부 패키지 없이 동작합니다.
2. 상단 메뉴를 좌우로 스크롤하고, 메인 메뉴와 하위 탭을 눌러 화면 전환을 확인합니다.
3. 이적시장 → 선수 검색 → 관심 선수 등록 → 협상 → 계약 제안 → `+1주 진행` → 진행 중인 협상 → 받은편지함을 확인합니다.
4. 우측 상단 버튼으로 다크/라이트 테마를 전환합니다. 설정 → 데모 데이터에서 초기화할 수 있습니다.

## 코덱스 개발 지시

이 HTML을 **LOL-GM UI의 상호작용·스타일·화면 정보 구조에 관한 시각적 명세(reference)**로 삼아 주세요. 현재 코드베이스/라우팅/상태 관리/게임 엔진을 먼저 조사하고, 해당 프로젝트의 기술 스택에 맞게 UI를 **컴포넌트화하여** 이식해 주세요. 프로토타입 전체를 기존 앱 위에 덮어씌우거나 게임 로직을 새 데모 코드로 바꾸지 마세요.

### 반드시 유지할 특징

- 모바일 우선 다크 네이비/차콜/블루 디자인 토큰, 선택 상태, 조밀하지만 명확한 카드 정보 배치
- 상단 메인 메뉴: 아이콘+이름, 가로 스크롤, 터치 스와이프, 현재 선택 메뉴 자동 노출. '더보기' 없이 접근 가능
- 상단 바로 아래 콘텐츠별 하위 탭: 실제 클릭 가능, 현재 선택 탭 강조, 탭 전환시 해당 콘텐츠 갱신
- 모바일 가독성과 데스크톱 반응형, 버튼 터치 영역 및 시각적 일관성
- 선수 검색, 관심 선수, 계약 제안, 협상 상태·주차 진행·받은편지함·선수단 및 재정 갱신의 자연스러운 연계
- 고액 단위의 한국어 표기 (예: 2억 1,000만 원), 연봉 기간 명시, 표시용 포맷터 재사용

### 중요 주의사항

- HTML 속 선수/팀/수치/협상 결정 규칙은 **가상 시연 데이터**입니다. 게임 원본 데이터를 대체하지 마세요.
- 데모는 `fee`/`wage`를 백만 원 단위로 보관하지만, 실제 DB 내부 화폐 단위는 먼저 조사하여 그대로 유지하세요.
- 데모의 로컬 스토리지 저장·주차별 조건 판단은 시연을 위한 축약 구현입니다. 실제 프로젝트의 세이브 데이터, 시간 진행, 계약, 이적 및 예산 시스템과 연결하세요.
- 이미 구현된 메뉴와 기능은 삭제하지 마세요. 시안에 없는 화면도 동일한 디자인 시스템으로 점진적으로 적용하세요.
- 실제 선수 닉네임 생성 엔진 개선은 이 HTML에 들어 있지 않습니다. 별도 원본 엔진 분석 및 테스트가 필요합니다.
- 기존 사용자 저장 기록을 보존하고, 모바일에서 실제로 테스트하며, 접근성·라우팅·성능 회귀를 검증해 주세요.
