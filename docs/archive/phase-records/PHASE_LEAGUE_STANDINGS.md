# 스플릿 기간 수와 성적 집계 규칙 분리

## 원칙

지역별 `splits` (1·2·3, 경기 일정상 독립 기간 수)와 `standingsMode` (순위 산정/국제대회 진출/승강에서 성적을 어떻게 계산하는가)는 **서로 독립된 설정**이다. 예컨대 3스플릿 리그도 정규시즌 승패 누적 또는 챔피언십 포인트 누적을 선택할 수 있으며 2스플릿이라고 반드시 독립 초기화되지 않는다. 이 게임의 실세계 지역별 기본값은 종전과 동일한 `independent`이다. 기존 저장에 `standingsMode`가 없으면 독립 방식으로 해석한다. **스플릿 기간과 성적 집계 방식은 모두 지역 리그 사무국 권한이며, 플레이어/감독이 선택할 수 없다.** 세계 생성·현황 화면에서는 현재 구조와 사무국의 정책을 읽기 전용으로 보여준다.

## 리그 사무국 의사결정

- 기본 시즌 구조는 각 지역 리그의 사전 설정에서 시작한다. `splits`는 이미 존재하는 사무국의 확대·축소 의사결정으로 변하며, `standingsMode`는 **별도 정책 안건**으로 독립 심의한다. 사용자 직접 입력 창을 만들지 않는다.
- `officeDecisions`가 매 시즌 **오프시즌에만** 최신 흥행·경쟁 균형·흥행 추이·리그 기간 수를 평가한다. 리그 사무국은 연간 챔피언십 포인트, 정규 전적 누적, 스플릿별 독립 방식 중 변경 안건을 제안할 수 있다. 기존 사무국 정책 효용·무작위 분산·의결 문턱·**구조 변경 4년 쿨다운**·연간 단일 안건 제한을 동일하게 적용한다.
- 리그가 1스플릿인 동안 별도의 집계 방식 개편 안건은 만들지 않는다. 추가 스플릿이 생겼을 때 독립적으로 제안할 수 있다. 리그 사무국 결정이 없는 기간에는 기존 방침을 그대로 유지한다.
- 사무국 결정은 `R.decisions`와 월드 뉴스에 해당 연도·근거·이전→새 집계 방식을 기록하고 **다음 시즌부터 적용**된다. 이미 진행·종료한 스플릿은 생성 시점에 저장된 `s.standingsMode`을 계속 사용하므로 사후 재채점되지 않는다.
- `worldConfig.changes='none'`은 기존과 같이 사무국의 미래 정책 변경을 비활성화하지만, 시작 구조 설정을 플레이어가 직접 선택할 권한으로 바꾸지는 않는다.

## 세 가지 방식

| `standingsMode` | 정규 스플릿별 새 경기 | 정규 승패/세트 누적 | 스플릿별 플레이오프·우승 | 국제대회 지역별 순위·승강 판단 |
|---|---|---|---|---|
| `independent` (기본값) | 예 | 아니요 | 매 스플릿 독립 | 마지막 완료 스플릿 우승·준우승·정규 순위 |
| `cumulative` | 예 | 예, 같은 연도·지역·디비전의 **완료된 스플릿 정규 경기** | 매 스플릿 독립 | 모든 완료 스플릿을 반영한 최신 누적 정규 순위 |
| `points` | 예 | 아니요 | 매 스플릿 독립 | 완료된 모든 스플릿의 챔피언십 포인트 합계 |

- 누적 정규 전적은 **과거 경기 자체를 현재 스플릿 일정에 다시 삽입하지 않는다**. 새 스플릿 경기는 미진행 상태로 시작하고, 순위 계산에서 과거 실제 완료된 정규 경기 결과와 새 경기 결과를 함께 합산한다. 이전 기간 플레이오프 경기는 누적하지 않는다. 그룹제에서는 현재 팀의 과거 그룹 경기도 합산하되 현재 그룹에 없는 상대를 만난 경기를 버리지 않는다. 전적·세트 득실·상대 전적·최근 폼이 현재 스플릿 순위에 반영된다.
- 포인트 방식은 해당 스플릿 **플레이오프가 끝나야** 점수를 확정한다. 우승 100, 준우승 70, 4강 45, 플레이오프 진출 20, 미진출 0점 (예시 게임 내 공통 포인트 표)으로 합산한다. 동률이면 최근 완료한 스플릿 최종 순위를 기준으로 정렬하고, 아직 경기 전이면 구단 전력으로 순위를 임시 정한다. 현재 진행 중인 스플릿은 완료 전까지 점수를 부여하지 않는다.
- 국제대회 `entry:'slots'` 및 차순위 진출권 `entry:'next'`는 각 리그가 선택한 누적 집계 순서를 사용한다. **국제대회 '직전 스플릿 챔피언' 초대권(`entry:'champions'`)은 연간 포인트 1위와 관계없이 마지막으로 끝난 스플릿 우승팀에게 돌아간다.**
- 승강제/혼합 승강제의 강등권은 연말 `independent`/ `cumulative`에서 최종 정규 순위, `points`에서 연간 포인트 순위를 사용한다. 포인트 방식 하부 리그의 승격 순서에도 누적 포인트를 적용한다. 프랜차이즈 보호 조건은 유지한다.
- `world.year`가 바뀌면 앞선 해의 전적·포인트는 이월하지 않는다. 다른 지역/디비전 결과가 섞이지 않는다. 현재 모드는 저장 데이터와 설정에 보존된다.

## 구현·회귀

- 실제 월드 초기화 → 실제 리그 스케줄 생성 → 각 스플릿의 선택된 경기 결과를 기록하는 결정론적 회귀에서 기본 독립 초기화, 2·3스플릿 정규 전적 누적, 그룹의 그룹 외 과거 상대 전적, 연간 포인트와 포인트 선두≠최근 스플릿 우승, 1스플릿에서도 모드 선택 허용을 검증한다.
- 사용자 설정 UI에 스플릿 수/집계 방식 변경 입력이 없음을 확인하고, **사무국만** 해당 정책을 제안·의결할 수 있는지, 냉각 기간과 과거 스플릿 정책 스냅샷이 지켜지는지 테스트한다. 구 설정/새 설정 검증, 저장 복원 및 오래된 저장 복원, 다음 해 누적 리셋, 기존 구단 5인·스카우팅·의료/달력 및 전체 CI 회귀를 요구한다.
- 주의: 이것은 스플릿 수와 **성적 계산 규칙**의 분리다. 포인트 방식도 스플릿별 플레이오프를 독립 개최한다. '한 번만 열리는 통합 연간 결승'이나 국제대회별 상이한 포인트 배율 등은 별도 리그 포맷 모델의 범위다.
