# LOL-GM 게임 제작 진입점 — 엔진 구현 계약

**이 문서는 법규가 아닌 개발 작업의 출발점**이다. 게임 세계의 규칙 원본은 [세계 규정집](rulebook/README.md)에만 있으며, 화면/저장/개발 계약은 그와 분리된다. 과거 기획·승인·이슈 목록 없이도 구현자가 각 도메인의 정본을 찾아 판정하고 코드를 작성할 수 있어야 한다.

## 1. 단일 진실 원본과 문서 관계

1. **세계관 헌장:** [CORE](rulebook/00-CORE.md) → 해당 도메인 조문 → 당시 유효한 세계 내부 시행 규정 → 해당 사건의 실제 계약·등록·명단·정보·재정 원장 순으로 판정한다.
2. **UI/UX:** [인터페이스 요구사항](interface-spec/USER_EXPERIENCE_REQUIREMENTS.md)에서 감독의 입력·정보 표시·저장/조작 경험을 구현한다. UI는 세계규칙을 개정하거나 경기·현금·계약을 직접 확정하지 못한다.
3. **엔진·제품 수용:** [엔진 및 제품 수용 명세](implementation-spec/WORLD_ENGINE_AND_PRODUCT_ACCEPTANCE.md)에 정한 원자적 저장·재현·장기 검증과 정보경계를 구현·시험한다.
4. **기존 코드 및 개발 접근:** 코드는 Rust 경기/세계 엔진과 TypeScript UI로 이관하되, 이전 구현의 유효 데이터·경기 기록·사용자 저장을 유지하고 모순된 중복 결과 작성자를 제거한다. 기존 코드는 사실의 참고 자료이며 정본과 다르면 정본이 우선한다.

## 2. 구현에 필요한 핵심 세계 객체

다음은 논리적 개념이지 파일명이나 특정 직렬화 구조를 강제하는 스키마가 아니다.

|---|---|---|
| 선수 | 한 명의 사람/고유 계정 | 국적·연령·계약·능력·부상·피로·등록·성장·경력·정보 관측 |

| 국가/국가협회 | 국가와 별개 운영기관 | 국가별 복수 대표팀 구성·감독·선발·실제 소집 |

| 정보·관측 | 보유 주체와 출처·관측 시점 | 공개 가능 범위, 불확실성, 스카우팅 평가, AI의 가용 정보 |

구단 팀과 국가대표팀, 국적과 지역 리그 등록권, 선발 제안과 실제 참가 자격, AI의 예측과 확정된 경기 결과를 하나의 필드·상태로 혼합하지 않는다.

## 3. 모든 사건에 공통으로 적용하는 판정 절차

`evaluate(world, action, actingAuthority, atWorldTime)`의 **의미**는 다음 순서를 따라야 한다. 함수 이름·언어·반환 구조는 구현 선택이다.

1. **입력 검증:** 행위의 종류·당사자·대상 선수/팀·세계 시간·대회·계약 및 실행하는 주체를 확인한다.
2. **규범 선택:** 헌장의 관련 금지/권한과 그 행위 시각에 관할·대상·시행 조건이 충족된 내부 규정 버전을 선택한다.
3. **권한과 사실:** 계약 동의·선수 의사·참가 등록·국적 적격·의료·시설·이동·예산·시간·정보권을 확인한다. 국가대표 출전 때에는 NAT-004에 따라 실제 보유 국적, 최초 공식 출전 국가·시각, 국가 변경 예외 절차의 효력과 실제 경기 출전을 구분한다. 외부 세계의 규정 개정을 세계 내부 기관의 결정으로 기록하지 않는다.
4. **상호 충돌 검사:** 동일 선수 중복 출전·겸직, 구단 4종 경기 금지 기간, 이미 잠긴 선수 명단·대진, 의무 지급과 소득 원장을 충돌 검사한다.
5. **판정 결과:** `PERMITTED`(적법하며 필수 조건 충족), `PROHIBITED`(명시적 금지·권한 없음), `NOT_EFFECTIVE`(규정/계약/승인 시행 전), `NEEDS_FACTS`(필수 사실 미확인), `NEEDS_RULE`(적법한 주체의 구체적 규정 미제정)을 구별한다. 이 상태 구분은 엔진 API의 필수적인 **의미 계약**이다.
6. **확정 단계:** 허용된 행위만 실제 세계 시간·참가·부상·재정·기록에 **원자적으로 한 번** 적용한다. 대기/거부된 행위는 선수·돈·대진·승패를 생성하지 않는다.
7. **이력·재현:** 어떤 규정·계약·관측 정보·결정권을 사용했는지 재검증할 수 있게 보존한다. 사후 규정 변경은 과거 결과를 임의로 다시 쓰지 않는다.

**새로운 제도·행동의 취급:** 행동 이름이 규정에 없더라도 주체·자원·시간·계약·정보·권한을 위 방식으로 판정한다. 기존 권한의 범위를 넘어서면 정당한 시행 주체가 내부 규정을 실제로 제정할 수 있도록 별도 제정 사건을 진행한다. 없는 제정권·보상액·국적·선수 능력·대회를 AI가 창작해서는 안 된다.

## 4. 세계 시간과 이벤트 흐름

- UTC의 단일 세계 시각을 이용하고, 사건 발생 시각·효력 발생 시각·재정 지급 시각을 따로 기록한다.
- 실제 세계가 진행되면 **규정 발효 확인 → 해당 날짜의 유효한 행위·권한·등록 검사 → 일정에 따른 실제 활동/경기 → 계약·지급·부상·회복·성장·평판 → 결과 확정 및 이력 기록**의 인과관계를 유지한다. 구체적 처리 순서는 같은 사건을 중복 확정하지 않도록 일관되게 정한다.
- 새 세계의 최초 시즌과 이후 시즌의 구단·대회 분류, 운영 주체·일정은 실제 유효한 초기 세계 상태와 시행 규정에서 가져온다. 하드코딩된 영구 단일 리그 포맷이나 모든 국가 동일 대표팀 수를 넣지 않는다.
- 세계 통합 선수시장은 매년 12월 첫째 화요일 00:00 UTC 시작, 정확히 28일 지속한다. 이 기간 네 종류 구단 대회 실경기를 편성·실행하지 않으며, 적법한 국가대표 대회는 가능하다. World Championship 결승은 구단 공식 시즌의 최종 공식 경기다.

## 6. AI가 발전할 수 있도록 분리할 판단

- **허용된 재량:** 구단·국가협회·대회 주체의 전략, 합법적인 선수 평가·계약 제안·리그 포맷 개편은 실제 관측·목표·계약 및 권한 안에서 달라질 수 있다. 정본이 모든 기관에게 똑같은 전략을 명령하는 것은 아니다.
- **반드시 동일한 판정:** 동일한 입력 사실과 행위를 두고 동일한 규정 버전을 적용하면 합법성·현금 지급·권리 이전·시간 점유·출전 이중 등록·기록 귀속이 동일하다.
- **새 상황에 대한 발전:** 새 훈련 방식·대회 기획·후원 방식이 등장해도 기존의 행위·권한·계약·시간·시설·경제 인과관계로 우선 판정한다. 필요한 세계 내부 법률은 적법하게 제정·공표되어야 하고, 헌장의 보호·금지와 기존 기록을 존중한다.

## 7. 반드시 통과해야 하는 수용 사례

| 사례 | 필수 판정 |
|---|---|
| 스토브리그 국가대표 경기 vs 같은 기간 구단 독립컵 경기 | 적법한 국가대표 대회는 가능, 구단컵 실경기는 금지 |
| 한 국가의 복수 대표팀 구성 vs 해당 대회 본선 출전권 | 구성은 가능, 본선 진출권 자동 부여는 금지 |
| 국가대표 선발과 구단 계약 이적이 같은 기간 발생 | 대표 명단·실제 기록은 소급 무효화하지 않음; 구단 계약은 별도 유지 |
| 국제사무국이 리그 포맷을 개편하려는 경우 | 권한·적법한 승인과 차기 효력 확인; 상위 금지·과거 기록 우회 금지 |
| 국가협회가 구단 이적시장을 변경하려는 경우 | 권한 없음, 거부 |
| 계약상 지급 기한에 자금이 충분한 경우와 부족한 경우 | 충분하면 실제 지급, 부족하면 실제 미지급 채무; 가상 현금/지급 금지 |
| 같은 선수의 동시 두 경기 참가 | 거부; 실제 선수/시간/기록 한 번만 사용 |
| 서로 다른 AI가 적법한 선수 후보를 다르게 선발 | 각 선택은 달라도 자격·계약·의료·시간 검사는 동일 |
| 새 활동 방식이 정본에 이름 없이 추가된 경우 | 실질적 권한·시간·계약·자원·정보를 적용; 없는 법적 권한·돈·사건 자동 생성 금지 |
| 내부 대회 규정을 제안했으나 미공표·미시행 | 제안만으로 적용 불가; 적법한 제정·발효 후부터 적용 |

## 8. 구현 불능 상태의 처리

위 문서들로 충분히 구체화되지 않은 의사결정(예: 신규 국가대표 대회의 출전팀 정원이 아직 공표되지 않았거나, 유효 규정에서 반드시 요구하는 별도 지급 조건이 아직 제정되지 않은 경우)은 **구체적 시행 규정의 공백**이다. 반면 복수 국적 선택·첫 공식 출전에 따른 귀속·2년 후 생애 1회 국가 변경 심사와 공식 소집 기간의 참가 조건은 NAT-004·NAT-006에 이미 명시된 요건으로 판정한다. 그 공백이 해당 사건의 법적 결과를 바꿀 경우 `NEEDS_RULE`로 판정하여 실제 내부 규정의 적법한 제정을 요구하거나, 세계 헌장의 개정 대상인지 검토한다. 문서에 없는 수치·권한을 조용히 기본값으로 만들어서는 안 된다.

게임 세계의 법률·코드 구현·UI·검증은 별개이며, 문서가 작성되었다는 이유만으로 해당 기능이 실제 엔진에서 구현·검증되었다고 표시하지 않는다.

## 9. 규칙 공백과 사실 미확인의 구별

**`NEEDS_RULE`은 게임에 아무 법도 없다는 뜻이 아니다.** 상위 헌장과 해당 시점에 발효된 내부 규정·계약을 전부 적용해도 특정 행위의 권한이나 필수 적격성을 확정할 기준이 **실제로 제정되지 않았을 때**의 판정이다. 규정이 이름을 직접 열거하지 않더라도 CORE-012 제5항의 일반 원칙으로 판단할 수 있다면 `NEEDS_RULE`이 아니다. 또한 아직 확인하지 못한 선수 국적·계약·부상·공표 증거는 법규 공백이 아니라 `NEEDS_FACTS`다.

| 사례 | 판단에 필요한 상태 | 기대 판정 | 처리 |
|---|---|---|---|
| 새로운 전지훈련 방식 | 적법한 구단·감독, 계약·시설·예산·일정 충족, 상위 금지 없음 | `PERMITTED` | 방식 이름이 규정에 없다는 이유로 별도 입법을 요구하지 않는다. 실제 소요시간·자원·훈련 결과만 기록한다 |
| 국가별 여러 대표팀 구성 | 국가협회가 실제 인력과 운영권을 갖춤 | `PERMITTED` | 국가당 대표팀을 하나로 제한하지 않는다. 본선 출전권은 별도로 심사한다 |
| 복수 국적 선수의 첫 국가대표 공식전 출전 | 실제 보유 국적 중 하나를 본인이 선택, 국가 귀속 이력 없음, 적법한 대회 등록·선수 동의 등 출전 요건 충족 | `PERMITTED` | 실제로 출전하면 해당 국가에 귀속한다. 소집·명단 등록·벤치 대기만으로는 귀속하지 않는다 |
| 첫 공식 국가대표 경기 출전 후 다른 국가로 무단 변경 | 최초 공식 출전 국가가 기록되어 있고 유효한 변경 예외가 없음 | `PROHIBITED` | 기존 국가 귀속을 유지하며, 실제 다른 국가의 공식 경기 출전과 그에 따른 기록 생성을 막는다 |
| 국가대표 국가 변경 승인 | 실제 변경 대상 국적 보유, 마지막 공식 출전 후 2년 경과, 이전 국가 변경 0회, 국제사무국의 적법한 승인 | `PERMITTED` | 첫 국가 귀속은 역사에 보존하고 새 국가 귀속을 승인 효력 시점부터 적용한다 |
| 국가대표 국가 변경 요건 미달 | 다른 국적이 없거나 마지막 공식 출전 후 2년 미만 또는 이미 한 번 국가를 변경한 선수 | `PROHIBITED` | 승인권자가 있어도 상위 NAT-004 예외 요건을 완화할 수 없다 |
| 복수 국적 선수의 국적 정보 | 대회 자격 규정은 이미 발효됐으나 해당 선수의 실제 국적 증거 미확인 | `NEEDS_FACTS` | 규정을 새로 만들지 않고 필요한 사실만 확인한다 |
| 국가대표 합법적 참가 초청 | 실제 초청을 받은 선수의 동의가 아직 없음 | `NEEDS_FACTS` | 동의 없는 실제 출전 확정 금지. 새로운 강제 차출 규칙을 만들어 대체하지 않는다 |
| 국내 지역사무국의 세계 공통 28일 이적시장 날짜 변경 | 세계 공통 일정 변경권이 없는 지역사무국의 제안 | `PROHIBITED` | 해당 기관이 자체 규정을 제정해도 상위 헌장 변경 효과는 발생하지 않는다 |
| 적법한 다음 시즌 지역 리그 개편 | 지역사무국 권한·필요한 승인·사전 공표·발효 조건 충족 | `PERMITTED` 또는 시행 전 `NOT_EFFECTIVE` | 초기 리그 형식을 영구 고정하지 않으며, 완료 경기를 소급 변경하지 않는다 |
| 국가대표 참가비·차출 보상 요청 | 지급자·수령자·계약·실효 규정에 금전 의무 없음 | `PROHIBITED` | 아직 없던 현금·채무를 신설하지 않는다. 장래 제도 신설은 별도 적법한 제정 사건 |
| 국가대표 대회 참가팀 수 | 국제사무국에 대회 참가 규정 제정권은 있으나 실제 대회별 정원 미공표 | `NEEDS_RULE` | 국가협회가 대표팀을 여러 개 만들었어도 본선 자동 진출 불가. 대회 참가 규정의 실효를 기다린다 |

### 엔진 판정 계약

1. 규칙 이름이 없다는 이유로 `NEEDS_RULE`을 반환하지 않는다. **이미 존재하는 상위·내부 규범의 일반 요건**을 먼저 검증한다.
2. 행위 권한이 **명백하게 없는 경우** `PROHIBITED`; 권한이 있으나 필요한 **새 내부 규정이 실제로 제정되지 않은 경우** `NEEDS_RULE`; 규정이 유효하지만 핵심 **증거가 부족하면** `NEEDS_FACTS`; 승인된 규정의 시행일 이전이면 `NOT_EFFECTIVE`로 분리한다.
3. `NEEDS_RULE`을 받은 AI는 기존의 적법한 기관 권한에 따라 새 제도의 제안·심사·공표 절차를 진행할 수 있지만, **제안 자체를 법률이나 현재 허용된 행위로 간주하지 않는다**.
4. 모든 판단 결과에는 적용 규범 버전·해당 세계 시각·권한 주체·검사한 사실·차단 이유를 남겨 재현 가능하게 한다. 현재 유효한 적격성 부족은 자동으로 초과 권한 또는 가짜 경기·지급을 발생시키지 않는다.

이는 [총칙 CORE-012](rulebook/00-CORE.md)의 판정 방식을 **개발자가 시험할 수 있도록 구체화한 수용 사례**이며, 별도 상위 법령이 아니다.

## 11. 초기 지역과 고유 등록·밴픽 경계

이 절은 새 게임의 **초기 세계 데이터·기술 수용 명세**이며, 지역 명칭을 개정할 수 없는 상위 헌장으로 승격시키지 않는다. 기존 초기 리그·정식 1~N부와 당시 실제 소속 구단·계약·기록은 세계 초기 설정에서 가져오고, 허위 참가 구단이나 경기 결과를 보정 목적으로 생성하지 않는다.

| 최초 주요 권역 | 공식 1부 표시명 | 기본 2부 표시명 |
|---|---|---|
| 한국 | LCK | LKC |
| 중국 | LPL | LDL |
| 유럽 | LEC | LEA |
| 북미 | LCS | LNA |
| 아시아태평양 | LCP | LPA |
| 남미 | LSA | LSC |

초기 여섯 주요 지역의 1·2부와 신규 지역의 자율적인 추가 부 운영은 COMP-002·003의 **시점별로 구별된 상태**다. 남미를 오직 브라질 한 나라로 제한하지 않고, 중미·카리브는 당시 유효한 북미 확장/국가 지역 배치를 확인한다. 초기 지역명 또는 리그 약칭은 옛 세계의 모든 실제 기록을 소급 개명하는 권한이 아니다.

### 등록과 출전의 공통 검증

- **구단의 계약 선수 수 → 팀의 공식 등록 명단 → 대회별 잠긴 출전 자격 → 경기 중 실제 5명**은 별개의 관계다. 계약 인원이 10명을 넘는다고 첫 팀의 공식 등록 상한이 늘어나지 않는다. 첫 팀은 공식 등록 5~10명, 활성 로컬 기준 비로컬 최대 2명; 산하 2군 공식 등록 최소 5명이다(TRANS-013).
- 시즌당 계약 중 구단 사이 이적 최대 2회, 임대 출발 1회, 임대 후 원소속 복귀·FA·동일 조직 내부 이동의 제외 여부를 따로 검사한다(TRANS-012). 로컬 출신과 현재 활성 로컬, 국가대표 귀속은 세 개의 서로 다른 기록이다(TRANS-014, NAT-004).
- 공식 BO3는 2승, BO5는 3승 도달 시 종료하지만 스크림은 합의된 모든 세트를 실제 진행한다. **첫 세트 First Selection**은 국내 더블 라운드로빈 홈팀, 국내 시드 플레이오프 상위 시드, 국제 브래킷 코인토스; 이후 세트는 직전 세트 패자에게 귀속하고 진영·픽 순서 선택권을 분리한다(MATCH-001·003·005).
- 공식 대회 전후 패치 버전과 새로운 챔피언의 프로 허용일을 구별하고, 선수의 당시 실제 관측·기여를 결과 원본으로 보존한다(MATCH-007). 전지훈련·멘토링·실제 분석은 별도의 허위 경기나 자동 보정이 아니다(PLAYER-001·013·014).

| 공식 국제대회 Bo5 첫 세트 토스에 승리한 팀 | First Selection 보유자가 진영 또는 픽 순서 중 한 축 선택, 상대가 다른 축 선택; 2세트 권한은 실제 1세트 패자 |
