# LOL-GM 게임 제작 진입점 — 엔진 구현 계약

**이 문서는 법규가 아닌 개발 작업의 출발점**이다. 게임 세계의 규칙 원본은 [세계 규정집](rulebook/README.md)에만 있으며, 화면/저장/개발 계약은 그와 분리된다. 과거 기획·승인·이슈 목록 없이도 구현자가 각 도메인의 정본을 찾아 판정하고 코드를 작성할 수 있어야 한다.

## 1. 단일 진실 원본과 문서 관계

1. **세계관 헌장:** [CORE](rulebook/00-CORE.md) → 해당 도메인 조문 → 당시 유효한 세계 내부 시행 규정 → 해당 사건의 실제 계약·등록·명단·정보·재정 원장 순으로 판정한다.
2. **UI/UX:** [인터페이스 요구사항](interface-spec/USER_EXPERIENCE_REQUIREMENTS.md)에서 감독의 입력·정보 표시·저장/조작 경험을 구현한다. UI는 세계규칙을 개정하거나 경기·현금·계약을 직접 확정하지 못한다.
3. **엔진·제품 수용:** [엔진 및 제품 수용 명세](implementation-spec/WORLD_ENGINE_AND_PRODUCT_ACCEPTANCE.md)에 정한 원자적 저장·재현·장기 검증과 정보경계를 구현·시험한다.
4. **기존 코드 및 개발 접근:** 코드는 Rust 경기/세계 엔진과 TypeScript UI로 이관하되, 이전 구현의 유효 데이터·경기 기록·사용자 저장을 유지하고 모순된 중복 결과 작성자를 제거한다. 기존 코드는 사실의 참고 자료이며 정본과 다르면 정본이 우선한다.

## 2. 구현에 필요한 핵심 세계 객체

다음은 논리적 개념이지 파일명이나 특정 직렬화 구조를 강제하는 스키마가 아니다.

|---|---|---|
| 선수 | 한 명의 사람/고유 계정 | 국적·연령·계약·능력·부상·피로·등록·성장·경력·정보 관측 |
| 구단/팀 | 구단 조직·리그 참가 팀·모/산하 구단 관계 | 프로 라이선스·지역 리그·시즌·선수단·계약·자산·채무 |
| 국가/국가협회 | 국가와 별개 운영기관 | 국가별 복수 대표팀 구성·감독·선발·실제 소집 |
| 국가대표팀 | 국가협회 산하의 독립 참가 단위 | 선수 선발, 대회별 명단·출전 자격, 일정·기록 |

| 규정 | 상위 헌장 또는 적법한 내부 제정·개정 규정 | 권한, 관할, 공표, 발효, 개정·실효, 당시 적용 버전 |

| 세계 사건·원장 | 단일 세계 시각의 실제 발생 사건 | 경기·교체·이적·의료·훈련·지급·재심·규정 개정·역사 |

구단 팀과 국가대표팀, 국적과 지역 리그 등록권, 선발 제안과 실제 참가 자격, AI의 예측과 확정된 경기 결과를 하나의 필드·상태로 혼합하지 않는다.

## 3. 모든 사건에 공통으로 적용하는 판정 절차

`evaluate(world, action, actingAuthority, atWorldTime)`의 **의미**는 다음 순서를 따라야 한다. 함수 이름·언어·반환 구조는 구현 선택이다.

1. **입력 검증:** 행위의 종류·당사자·대상 선수/팀·세계 시간·대회·계약 및 실행하는 주체를 확인한다.
2. **규범 선택:** 헌장의 관련 금지/권한과 그 행위 시각에 관할·대상·시행 조건이 충족된 내부 규정 버전을 선택한다.
3. **권한과 사실:** 계약 동의·선수 의사·참가 등록·국적 적격·의료·시설·이동·예산·시간·정보권을 확인한다. 국가대표 출전 때에는 NAT-004에 따라 실제 보유 국적, 최초 공식 출전 국가·시각, 국가 변경 예외 절차의 효력과 실제 경기 출전을 구분한다. 외부 세계의 규정 개정을 세계 내부 기관의 결정으로 기록하지 않는다.
4. **상호 충돌 검사:** 동일 선수 중복 출전·겸직, 구단 4종 경기 금지 기간, 이미 잠긴 선수 명단·대진, 의무 지급과 소득 원장을 충돌 검사한다.
5. **판정 결과:** `PERMITTED`(적법하며 필수 조건 충족), `PROHIBITED`(명시적 금지·권한 없음), `NOT_EFFECTIVE`(규정/계약/승인 시행 전), `NEEDS_FACTS`(필수 사실 미확인), `NEEDS_RULE`(적법한 주체의 구체적 규정 미제정)을 구별한다. 이 상태 구분은 엔진 API의 필수적인 **의미 계약**이다.
6. **확정 단계:** 허용된 행위만 실제 세계 시간·참가·부상·재정·기록에 **원자적으로 한 번** 적용한다. 대기/거부된 행위는 선수·돈·대진·승패를 생성하지 않는다.
7. **이력·재현:** 어떤 규정·계약·관측 정보·결정권을 사용했는지 재검증할 수 있게 보존한다. 사후 규정 변경은 과거 결과를 임의로 다시 쓰지 않는다.

**새로운 제도·행동의 취급:** 행동 이름이 규정에 없더라도 주체·자원·시간·계약·정보·권한을 위 방식으로 판정한다. 기존 권한의 범위를 넘어서면 정당한 시행 주체가 내부 규정을 실제로 제정할 수 있도록 별도 제정 사건을 진행한다. 없는 제정권·보상액·국적·선수 능력·대회를 AI가 창작해서는 안 된다.

## 4. 세계 시간과 이벤트 흐름

- UTC의 단일 세계 시각을 이용하고, 사건 발생 시각·효력 발생 시각·재정 지급 시각을 따로 기록한다.
- 실제 세계가 진행되면 **규정 발효 확인 → 해당 날짜의 유효한 행위·권한·등록 검사 → 일정에 따른 실제 활동/경기 → 계약·지급·부상·회복·성장·평판 → 결과 확정 및 이력 기록**의 인과관계를 유지한다. 구체적 처리 순서는 같은 사건을 중복 확정하지 않도록 일관되게 정한다.
- 새 세계의 최초 시즌은 **사전에 설계·교차 검증한 초기 세계 프리셋과 적법하게 제정·공표·발효한 관할별 초기 시행 규정**에서 시작한다(CORE-012⑦). AI가 새 세계마다 규정·숫자·권한을 임의로 뽑지 않는다. 지역별 서로 다른 리그·경제·선수 공급은 허용하지만 모든 지역에 영구 단일 포맷이나 동일한 국가대표 수를 강제하지 않는다. 이후 변경은 실제 규정 개정 사건으로 구별한다.
- 세계 통합 선수시장은 매년 12월 첫째 화요일 00:00 UTC 시작, 정확히 28일 지속한다. 이 기간 네 종류 구단 대회 실경기를 편성·실행하지 않으며, 적법한 국가대표 대회는 가능하다. World Championship 결승은 구단 공식 시즌의 최종 공식 경기다.

## 6. AI가 발전할 수 있도록 분리할 판단

- **허용된 재량:** 구단·국가협회·대회 주체의 전략, 합법적인 선수 평가·계약 제안·리그 포맷 개편은 실제 관측·목표·계약 및 권한 안에서 달라질 수 있다. 정본이 모든 기관에게 똑같은 전략을 명령하는 것은 아니다.
- **반드시 동일한 판정:** 동일한 입력 사실과 행위를 두고 동일한 규정 버전을 적용하면 합법성·현금 지급·권리 이전·시간 점유·출전 이중 등록·기록 귀속이 동일하다.
- **새 상황에 대한 발전:** 새 훈련 방식·대회 기획·후원 방식이 등장해도 기존의 행위·권한·계약·시간·시설·경제 인과관계로 우선 판정한다. 필요한 세계 내부 법률은 적법하게 제정·공표되어야 하고, 헌장의 보호·금지와 기존 기록을 존중한다.

## 7. 반드시 통과해야 하는 수용 사례

| 사례 | 필수 판정 |
|---|---|
| 스토브리그 국가대표 경기 vs 같은 기간 구단 독립컵 경기 | 적법한 국가대표 대회는 가능, 구단컵 실경기는 금지 |
| 한 국가의 복수 대표팀 구성 vs 해당 대회 본선 출전권 | 구성은 가능, 본선 진출권 자동 부여는 금지 |
| 국가대표 선발과 구단 계약 이적이 같은 기간 발생 | 대표 명단·실제 기록은 소급 무효화하지 않음; 구단 계약은 별도 유지 |
| 국제사무국이 리그 포맷을 개편하려는 경우 | 권한·적법한 승인과 차기 효력 확인; 상위 금지·과거 기록 우회 금지 |
| 국가협회가 구단 이적시장을 변경하려는 경우 | 권한 없음, 거부 |
| 계약상 지급 기한에 자금이 충분한 경우와 부족한 경우 | 충분하면 실제 지급, 부족하면 실제 미지급 채무; 가상 현금/지급 금지 |
| 같은 선수의 동시 두 경기 참가 | 거부; 실제 선수/시간/기록 한 번만 사용 |
| 서로 다른 AI가 적법한 선수 후보를 다르게 선발 | 각 선택은 달라도 자격·계약·의료·시간 검사는 동일 |
| 새 활동 방식이 정본에 이름 없이 추가된 경우 | 실질적 권한·시간·계약·자원·정보를 적용; 없는 법적 권한·돈·사건 자동 생성 금지 |
| 내부 대회 규정을 제안했으나 미공표·미시행 | 제안만으로 적용 불가; 적법한 제정·발효 후부터 적용 |

## 8. 구현 불능 상태의 처리

위 문서들로 충분히 구체화되지 않은 의사결정(예: 신규 국가대표 대회의 출전팀 정원이 아직 공표되지 않았거나, 유효 규정에서 반드시 요구하는 별도 지급 조건이 아직 제정되지 않은 경우)은 **구체적 시행 규정의 공백**이다. 반면 복수 국적 선택·첫 공식 출전에 따른 귀속·2년 후 생애 1회 국가 변경 심사와 공식 소집 기간의 참가 조건은 NAT-004·NAT-006에 이미 명시된 요건으로 판정한다. 그 공백이 해당 사건의 법적 결과를 바꿀 경우 `NEEDS_RULE`로 판정하여 실제 내부 규정의 적법한 제정을 요구하거나, 세계 헌장의 개정 대상인지 검토한다. 문서에 없는 수치·권한을 조용히 기본값으로 만들어서는 안 된다.

게임 세계의 법률·코드 구현·UI·검증은 별개이며, 문서가 작성되었다는 이유만으로 해당 기능이 실제 엔진에서 구현·검증되었다고 표시하지 않는다.

## 9. 규칙 공백과 사실 미확인의 구별

**`NEEDS_RULE`은 게임에 아무 법도 없다는 뜻이 아니다.** 상위 헌장과 해당 시점에 발효된 내부 규정·계약을 전부 적용해도 특정 행위의 권한이나 필수 적격성을 확정할 기준이 **실제로 제정되지 않았을 때**의 판정이다. 규정이 이름을 직접 열거하지 않더라도 CORE-012 제5항의 일반 원칙으로 판단할 수 있다면 `NEEDS_RULE`이 아니다. 또한 아직 확인하지 못한 선수 국적·계약·부상·공표 증거는 법규 공백이 아니라 `NEEDS_FACTS`다.

| 사례 | 판단에 필요한 상태 | 기대 판정 | 처리 |
|---|---|---|---|
| 새로운 전지훈련 방식 | 적법한 구단·감독, 계약·시설·예산·일정 충족, 상위 금지 없음 | `PERMITTED` | 방식 이름이 규정에 없다는 이유로 별도 입법을 요구하지 않는다. 실제 소요시간·자원·훈련 결과만 기록한다 |
| 국가별 여러 대표팀 구성 | 국가협회가 실제 인력과 운영권을 갖춤 | `PERMITTED` | 국가당 대표팀을 하나로 제한하지 않는다. 본선 출전권은 별도로 심사한다 |
| 복수 국적 선수의 첫 국가대표 공식전 출전 | 실제 보유 국적 중 하나를 본인이 선택, 국가 귀속 이력 없음, 적법한 대회 등록·선수 동의 등 출전 요건 충족 | `PERMITTED` | 실제로 출전하면 해당 국가에 귀속한다. 소집·명단 등록·벤치 대기만으로는 귀속하지 않는다 |
| 첫 공식 국가대표 경기 출전 후 다른 국가로 무단 변경 | 최초 공식 출전 국가가 기록되어 있고 유효한 변경 예외가 없음 | `PROHIBITED` | 기존 국가 귀속을 유지하며, 실제 다른 국가의 공식 경기 출전과 그에 따른 기록 생성을 막는다 |
| 국가대표 국가 변경 승인 | 실제 변경 대상 국적 보유, 마지막 공식 출전 후 2년 경과, 이전 국가 변경 0회, 국제사무국의 적법한 승인 | `PERMITTED` | 첫 국가 귀속은 역사에 보존하고 새 국가 귀속을 승인 효력 시점부터 적용한다 |
| 국가대표 국가 변경 요건 미달 | 다른 국적이 없거나 마지막 공식 출전 후 2년 미만 또는 이미 한 번 국가를 변경한 선수 | `PROHIBITED` | 승인권자가 있어도 상위 NAT-004 예외 요건을 완화할 수 없다 |
| 복수 국적 선수의 국적 정보 | 대회 자격 규정은 이미 발효됐으나 해당 선수의 실제 국적 증거 미확인 | `NEEDS_FACTS` | 규정을 새로 만들지 않고 필요한 사실만 확인한다 |
| 국가대표 합법적 참가 초청 | 실제 초청을 받은 선수의 동의가 아직 없음 | `NEEDS_FACTS` | 동의 없는 실제 출전 확정 금지. 새로운 강제 차출 규칙을 만들어 대체하지 않는다 |
| 국내 지역사무국의 세계 공통 28일 이적시장 날짜 변경 | 세계 공통 일정 변경권이 없는 지역사무국의 제안 | `PROHIBITED` | 해당 기관이 자체 규정을 제정해도 상위 헌장 변경 효과는 발생하지 않는다 |
| 적법한 다음 시즌 지역 리그 개편 | 지역사무국 권한·필요한 승인·사전 공표·발효 조건 충족 | `PERMITTED` 또는 시행 전 `NOT_EFFECTIVE` | 초기 리그 형식을 영구 고정하지 않으며, 완료 경기를 소급 변경하지 않는다 |
| 국가대표 참가비·차출 보상 요청 | 지급자·수령자·계약·실효 규정에 금전 의무 없음 | `PROHIBITED` | 아직 없던 현금·채무를 신설하지 않는다. 장래 제도 신설은 별도 적법한 제정 사건 |
| 국가대표 대회 참가팀 수 | 국제사무국에 대회 참가 규정 제정권은 있으나 실제 대회별 정원 미공표 | `NEEDS_RULE` | 국가협회가 대표팀을 여러 개 만들었어도 본선 자동 진출 불가. 대회 참가 규정의 실효를 기다린다 |

### 엔진 판정 계약

1. 규칙 이름이 없다는 이유로 `NEEDS_RULE`을 반환하지 않는다. **이미 존재하는 상위·내부 규범의 일반 요건**을 먼저 검증한다.
2. 행위 권한이 **명백하게 없는 경우** `PROHIBITED`; 권한이 있으나 필요한 **새 내부 규정이 실제로 제정되지 않은 경우** `NEEDS_RULE`; 규정이 유효하지만 핵심 **증거가 부족하면** `NEEDS_FACTS`; 승인된 규정의 시행일 이전이면 `NOT_EFFECTIVE`로 분리한다.
3. `NEEDS_RULE`을 받은 AI는 기존의 적법한 기관 권한에 따라 새 제도의 제안·심사·공표 절차를 진행할 수 있지만, **제안 자체를 법률이나 현재 허용된 행위로 간주하지 않는다**.
4. 모든 판단 결과에는 적용 규범 버전·해당 세계 시각·권한 주체·검사한 사실·차단 이유를 남겨 재현 가능하게 한다. 현재 유효한 적격성 부족은 자동으로 초과 권한 또는 가짜 경기·지급을 발생시키지 않는다.

이는 [총칙 CORE-012](rulebook/00-CORE.md)의 판정 방식을 **개발자가 시험할 수 있도록 구체화한 수용 사례**이며, 별도 상위 법령이 아니다.

## 11. 초기 지역과 고유 등록·밴픽 경계

이 절은 새 게임의 **초기 세계 데이터·기술 수용 명세**이며, 지역 명칭을 개정할 수 없는 상위 헌장으로 승격시키지 않는다. 기존 초기 리그·정식 1~N부와 당시 실제 소속 구단·계약·기록은 세계 초기 설정에서 가져오고, 허위 참가 구단이나 경기 결과를 보정 목적으로 생성하지 않는다.

| 최초 주요 권역 | 공식 1부 표시명 | 기본 2부 표시명 |
|---|---|---|
| 한국 | LCK | LKC |
| 중국 | LPL | LDL |
| 유럽 | LEC | LEA |
| 북미 | LCS | LNA |
| 아시아태평양 | LCP | LPA |
| 남미 | LSA | LSC |

초기 여섯 주요 지역의 1·2부와 신규 지역의 자율적인 추가 부 운영은 COMP-002·003의 **시점별로 구별된 상태**다. 남미를 오직 브라질 한 나라로 제한하지 않고, 중미·카리브는 당시 유효한 북미 확장/국가 지역 배치를 확인한다. 초기 지역명 또는 리그 약칭은 옛 세계의 모든 실제 기록을 소급 개명하는 권한이 아니다.

### 등록과 출전의 공통 검증

- **구단의 계약 선수 수 → 팀의 공식 등록 명단 → 대회별 잠긴 출전 자격 → 경기 중 실제 5명**은 별개의 관계다. 계약 인원이 10명을 넘는다고 첫 팀의 공식 등록 상한이 늘어나지 않는다. 첫 팀은 공식 등록 5~10명, 활성 로컬 기준 비로컬 최대 2명; 산하 2군 공식 등록 최소 5명이다(TRANS-013).
- 시즌당 계약 중 구단 사이 이적 최대 2회, 임대 출발 1회, 임대 후 원소속 복귀·FA·동일 조직 내부 이동의 제외 여부를 따로 검사한다(TRANS-012). 로컬 출신과 현재 활성 로컬, 국가대표 귀속은 세 개의 서로 다른 기록이다(TRANS-014, NAT-004).
- 공식 BO3는 2승, BO5는 3승 도달 시 종료하지만 스크림은 합의된 모든 세트를 실제 진행한다. **첫 세트 First Selection**은 국내 더블 라운드로빈 홈팀, 국내 시드 플레이오프 상위 시드, 국제 브래킷 코인토스; 이후 세트는 직전 세트 패자에게 귀속하고 진영·픽 순서 선택권을 분리한다(MATCH-001·003·005).
- 공식 대회 전후 패치 버전과 새로운 챔피언의 프로 허용일을 구별하고, 선수의 당시 실제 관측·기여를 결과 원본으로 보존한다(MATCH-007). 전지훈련·멘토링·실제 분석은 별도의 허위 경기나 자동 보정이 아니다(PLAYER-001·013·014).
- 정기 글로벌 패치와 실제 적용 시각·랭크의 현재판·공식 대회의 지정/고정판 및 챔피언 프로 허용일만 사용한다(MATCH-007·008). **긴급 밸런스 핫픽스 이벤트/타이머/AI 트리거·발견 당일 종료 검사·전용 UI/발효 분기는 신설하거나 실행하지 않는다**. 기존 공식 시리즈의 지정판, 과거 경기·밴픽·선수 성장/관측 원본을 새 정기 패치로 덮어쓰지 않는다. 핫픽스 제거는 MATCH-010이 금지한 임의 기술 사고·퍼즈 복구가 아니다.

| 대회 정식 등록 마감 후 1군→2군 소속 이동 가능 기간만 열려 있음 | 내부 이동은 적법 조건에서 가능하나 대회 공식 출전 명단은 변경되지 않음 |

## 12. 국제대회 초기 시행 규정의 기초값

다음 수치는 초기 게임 세계에서 국제사무국이 적법하게 제정·공표하여 사용하는 **세계 내부의 가변 시행 규정 기본값**이다. 향후 국제사무국이 COMP-015와 GOV-002~004의 권한 및 시행 절차에 따라 유효한 새 규정을 제정하면 해당 효력 시점 이후의 시즌에 그 규정을 사용한다. 정본의 상위 불변 규칙으로 고정하지 않는다.

- **국제대회 패치 잠금의 초기 기준:** 개막 7일 전에 적용할 대회 패치를 확정하여 기록하고, 해당 대회의 유효 잠금 규정이 허용하지 않는 한 개막 후 글로벌 패치가 바뀌어도 대회 종료까지 유지한다. 새로운 챔피언의 프로 출전 허용일과 당시 대회용 챔피언 풀 잠금은 별도로 검증한다.
- **초기 지역 국제 경쟁력 평가 창:** 현재 연도와 직전 2개 연도의 실제 공식 국제대회 결과 **3개 시즌**을 사용한다. 구형 기록이 존재하지 않으면 결과를 상상해 추가하지 않는다.
- **대회별 초기 가중치:** First Stand 1, MSI 2, Eastern Cup 1, Western Cup 1, World Championship 3, Masters 2, Open 1.
- **대회 내 실제 도달 성적의 초기 점수:** 우승 8, 준우승 6, 4강 4, 8강 2, 그 외 실제 참가 1. 각 경기·대회에서 확인된 실제 결과만 부여하며 참가만으로 미래 결과를 추정하지 않는다.
- **지역별 평가의 초기 방법:** 해당 대회에 실제 출전한 지역 팀들의 점수 평균을 2로 나누고 대회 가중치를 적용하여, 그 지역이 출전한 대회들의 가중치 합으로 나눈 결과를 지역 경쟁력 지수로 삼는다. 대회·구단 참가 수가 많은 지역이라는 사실만으로 같은 성적을 이중 가산하지 않는다.
- **추가 출전권 동점:** 가장 최근 World Championship에서 해당 지역이 실제 도달한 최고 순위를 우선 비교하고, 비교해도 같거나 기록이 없으면 안정적인 지역 식별자로 재현 가능한 순서를 정한다. 해당 시즌 세계 상태에 이미 확정된 다른 유효한 동률 규정이 있다면 그 규정의 시행 범위를 검증한다.
- **이력:** 지역·대회 ID, 실제 참가팀의 당시 소속 지역, 결과, 최초 규정 버전과 대회 가중치를 그 시점의 이력으로 보존한다. 후속 지역 합병이나 가중치 개정으로 과거 대회의 소속·점수·기록을 소급 재산정하지 않는다.

초기 기초값이 세계 구성에 없거나 적법하게 공표되지 않았다면 현재 효력을 가진 것으로 **자동 추정하지 않고** CORE-012의 개막 전 규정 제정 절차를 먼저 시행한다. 초기값의 채택과 후속 지역·국제사무국의 재량적 개정은 구분한다.

## 13. 초기 세계 프리셋의 설계·발효·장기 변화 검증

이 절은 [CORE-012⑦](rulebook/00-CORE.md)을 구현·검증하기 위한 **비규범적 기술 수용 기준**이다. 프리셋은 게임 제작자가 미리 검증한 세계 초기 상태와 관할별 시행 규정의 준비본이며, 프리셋이 존재한다는 사실만으로 적법한 내부 법규가 제정된 것으로 보지 않는다.

### 최초 시즌에 준비할 영역

| 영역 | 초기 설계·검증 대상 | 임의 자동 보충 금지 |
|---|---|---|
| 기관·관할 | 실제 국제·지역사무국, 국가협회, 주관 기관, 제정권·승인 경로, **이사회 이해충돌 시 임시 대체 이사의 적법한 선임 절차** | 권한 없는 국가협회·사무국의 새 규정 또는 가상 대체 이사·표결 |
| 지역 리그·구단 | 각 지역의 실제 1~N부·참가 구단·승강 채택 여부·대회 등록 기준 | 전 지역 동일 포맷, 가짜 구단·참가권 |
| 국가대표 | 국가협회별 운영 여건, 실제 선발·소집·예선 규정과 별도 대회 일정 | 국가별 무조건 같은 팀 수·본선 진출권 |
| 선수·계약 | 기존 계약·등록·로컬·국적·의료 정보권·직원 수·대회별 명단 | 없는 선수·국적·자격·차출 권한 |
| 일정·패치 | 구단 공식/독립 경기·국가대표 경기, Worlds 피날레, 28일 시장, 대회 패치 | 동시 중복 경기·금지 기간 실경기 |
| 재정·상업 | 실제 자본·채무·임금 규제·참가비·후원·지급 의무 | 재원 없는 보조금·전 지역 임의 공통 세율 |

초기 여섯 주요 지역과 국제대회 기초값은 §11~12 및 실제 초기 세계 상태에서 가져온다. 로컬 취득 기간, 지역 샐러리캡 금액, 국가별 본선 정원 등 **근거가 확인되지 않은 수치**는 이 절에서 새로 정하지 않는다. 각 관할의 유효한 원자료 또는 적법하게 제정·공표한 초기 시행 규정으로만 채울 수 있다.

### 생성·발효·전환 절차

1. **동일 초기 버전·시드의 재현성:** 지정된 초기 프리셋과 실제 계약·대회·구단 데이터를 로드할 때 같은 입력이 같은 시작 상태를 형성한다. 운영 주체와 초기 규정 버전은 각각 구별해 기록한다.
2. **제정·공표·시행 확인:** 프리셋의 규정 후보가 승인·공표·발효되어 있지 않으면 해당 기관의 적법한 최초 제정 절차가 필요하다. 개발자가 마련한 초안이나 AI의 무작위 선택만으로 법규의 효력을 생성하지 않는다. 플레이어에게 매번 반복 승인 업무를 요구하지 않되, 권한 있는 기관의 법적 사건·이력은 보존한다.
3. **교차 검증:** 선수·구단·국가대표의 시간·명단 중복, 공식 경기 일정·국제 시드·지역 등록, 재정·계약·패치의 충돌과 누락을 확인한다. 해당 행위의 필수 규정이 없으면 `NEEDS_RULE`, 증거가 없으면 `NEEDS_FACTS`이며 임의 값·허위 경기·허위 지급으로 통과시키지 않는다. 관련 없는 독립적인 활동을 한꺼번에 중단시키지 않는다.
4. **장래 개정:** 사무국 AI의 정책 변경은 실제 성적·참가 수·구단 재정·운영 병목 등 당시 관측한 근거와 적법한 권한에 따른 별도 제안·심의·공표·발효 사건으로 처리한다. 최초 로스터 5~10명·비로컬 2명·시즌 이적 최대 2회·직원 7/4/6명은 **초기 시즌에 유효한 기준**이며 그 후 실제 제정·공표·발효된 규정이 없다면 초기 수치가 그대로 적용된다. 변경에는 해당 수치의 관할과 다른 지역·국제 등록/계약의 충돌 여부를 확인하고, 아직 효력이 없는 안을 현재 등록·거래·고용 판정에 적용하지 않는다. 초기 프리셋의 지역 차이를 모두 제거하거나, 변화를 매 시즌 의무적으로 일으키거나, 완결된 경기·계약·원장을 개정으로 다시 쓰지 않는다.
5. **기존 저장 보존:** 이 원칙을 도입하기 전에 생성된 세계에 신규 시작용 프리셋을 덮어씌우지 않는다. 저장 세계의 당시 유효한 규정·권리·계약·원장을 사용하고, 실제로 적법한 장래 개정만 반영한다.

### 검증 사례

| 사례 | 기대 결과 |
|---|---|
| 같은 초기 버전·시드로 새 세계를 두 번 생성 | 초기 지역·리그·등록·규정 상태가 일치하며 무작위 규정 차이 없음 |
| 서로 다른 두 지역이 다른 초기 리그 형식을 보유 | 각각의 적법한 초기 규정과 전체 일정이 유효하면 둘 다 가능; 하나로 강제 통일하지 않음 |
| 설계 프리셋에 국가대표 본선 정원 값이 없고 해당 대회의 규정이 미제정 | 임의 정원을 생성하지 않고 해당 대회의 참가 판정을 `NEEDS_RULE`로 처리 |
| 승인되었으나 아직 발효 전인 지역 샐러리 규정 | 현재 시행 규정을 유지하고 신규안은 `NOT_EFFECTIVE` 처리 |
| 시즌 중 참가 기반이 늘어난 지역의 다음 시즌 개편 | 실제 관할·사전 공표·다음 시즌 효력 및 계약·일정 조건을 충족할 때만 허용 |
| 기존 저장 세계가 새 버전의 초기 프리셋을 불러옴 | 세계를 재초기화하지 않으며 당시 시행 규정과 완료된 결과·채무를 유지 |

초기 프리셋의 목록·실제 수치·제정 기록은 별도의 초기 세계 데이터와 내부 시행 규정 기록에 보관한다. 이 명세와 정본 본칙은 **아직 미승인인 세부값이나 시행되지 않은 규정을 실제로 존재하는 것처럼 간주하지 않는다**.

## 14. 열린 결과 경로와 의결 불능에 대한 안전성 검증

이 절은 세계 내부에 없던 타이브레이크·표결·국가대표 등록법을 새로 만드는 규정이 아니라, 기존 승인된 [COMP-019](rulebook/10-COMPETITIONS.md)·[GOV-004/012](rulebook/70-GOVERNANCE.md)·[NAT-011](rulebook/15-NATIONAL-TEAMS.md)에 따른 **엔진 검증 범위**다.

### 월즈 진출·상위 시드 경계의 유한 BO1 결정전

- 2026-11-11 사용자 후속 확정으로 D-032의 **반복 라운드로빈은 철회**되고 [COMP-019](rulebook/10-COMPETITIONS.md)의 **유한 BO1 탈락형**을 적용한다. 기존 승수·상대 일정 강도·세트 득실·상대 세트 득실·세트 승수와 실제 비교 가능한 승자승으로 **경계가 먼저 해소**되면 새 경기를 생성하지 않는다.
- 미해결 동률 `n`팀과 16/17위 본선 진출 또는 8/9위 상위 시드 그룹의 빈자리 `q`개에 **결정전 참가팀 모두 최소 1회 실제 BO1을 치르게** 한다. `n≥2q`에서는 `q`개 최소 2팀 진출조에서 패자 탈락으로 `n-q`경기, `n<2q`에서는 `n-q`개 최소 2팀 탈락조에서 **승자 진출·패자 다음 대결 잔류**로 `q`경기를 치른다. 초기 부전승도 실제 출전 전에는 자격을 확정하지 않고 총 `max(n-q,q)≤n-1` 유효 BO1으로 완료한다. 한 동률 집단이 양 경계에 걸치면 16강 확정 후 상위 8위 그룹 분류. 기존 완료 세계 기록·기존 시드/대진을 소급 변경하지 않는다.
- **결정전 전용 승패·세트·선수 경기 기록은 월즈 리그 페이즈 기존 승수·SoS·세트 득실·상대 세트 득실·세트 승수·맞대결·기본 순위에 합산하지 않는다.** 판정은 해당 8/9·16/17위 경계에만 적용하며, 실제 출전·의료/피로·세계시각·계약상 효과와 별도 결정전 경기 기록은 보존한다. 정상·거부·저장/로드 시 기존 성적 원장이 불변이어야 한다.
- 참가 원시 시드·포트/전원 비교 가능한 실제 맞대결·당시 사전 공표된 공개 대진/부전승 추첨을 **합법적인 시드/대진 판정에만** 사용한다. 동일한 다섯 지표를 재사용해 가짜 시드 우열을 만들지 않고, **추첨·해시로 경기를 이긴 팀이나 16강 진출을 직접 확정하지 않는다**. 특히 n=3 q=1에서 상위 배정 시드 부전승/2대3 준결승/최종전, n=4 q=2에서 1대4·2대3 실경기로 진출 두 자리를 채우는 대진을 검증한다.
- **실제 경기 수의 수학적 유한 상한과 일정 마감은 별개**다. 밴픽·세트 실제 시간·국제시장 개장·선수 점유/회복·방송/장소·현지 1일1시리즈 및 적법 예외가 있어 시장 전에 항상 완료한다고 단정할 수 없다. 양측 실격/유효 승패 미성립이면 `max(n-q,q)` 전제를 충족하지 않는 별도 법적 사건으로 기록한다.
- 합법적인 추후 편성 슬롯이나 대회별 실제 유효 대진/추첨 규정이 없는데 경계가 아직 미해결이면, 가상의 결승·시드·결과를 기록하거나 다른 대회의 확정 일정을 침해하지 않는다. **해당 진출·후속 대진 확정을 보류**하고 적법한 기관/규정에 따른 처리를 요구한다. 이 상태를 숨겨 '전체 일정 자동 완료'로 오인하지 않는다.

### 이사회 이해충돌·의결

- 이해충돌로 회피한 이사 대신 **같은 의석군의 이해충돌 없는 적격한 임시 대체 이사**를 적법하게 선임할 수 있다(GOV-012). 중앙 측은 중앙 측, 지역 측은 해당 지역의 자격을 가진 실제 인물을 사용한다. 정당한 선임권·절차·관할·당사자 이해충돌 여부를 확인하고 원 이사와 대체 이사가 동시에 표를 행사하거나 총 재적·찬성 기준을 변경하지 않는다. GOV-004의 통상 7표·중대 9표 기준을 소수 참석자 비율로 다시 계산하지 않는다.
- 유효한 임시 대체 이사를 선임할 수 없는 경우나 선임 후에도 찬성 수가 부족한 경우에는 **정책의 미가결**과 **투표 자체의 미실시·절차 불능**을 구별하여 기록한다. 정책을 강제로 시행하거나 실재하지 않는 인물을 생성하지 않는다. 대체 이사 선임의 법적 권한은 GOV-012를 적용하되 **최초 세계 개막 전 관할 기관이 제정·공표·발효시킨 세부 선임 절차**와 실제 인사 결정의 적법성을 검증한다. 미제정이면 대체 선임에 한해서 `NEEDS_RULE`로 판정한다.

### 국가대표 초기 명단

- 최초 대회의 **기본 등록 7명(주전 5·후보 2)**은 유지하지만 NAT-011에 따라 **적격 선수 5명 또는 6명 등록도 허용**한다. 5명 명단에는 교체 선수 0명, 6명 명단에는 1명만 존재한다. 당시 대회에 적법하게 공표된 후속 정원 개정이 없다면 4명 등록이나 기본 상한을 넘긴 등록은 허용하지 않는다.
- 적법한 명단을 이미 등록했더라도 실제 출전 시 의료·참가 의사·선수 시간·5:5 출전 조건은 별개로 검사한다. 없는 선수를 채우거나 미등록 선수를 자동 출전시켜서는 안 된다.

### 재현·경계 사례

| 상황 | 최소 검증 |
|---|---|
| 월즈 한 경계에서 n=3,q=1 · n=4,q=2 · n=3,q=2 · n=4,q=3이 기존 지표·H2H로 미해결 | 실제 BO1 전원 출전. 앞 두 유형은 2경기, n=3,q=2는 패자 잔류형 2경기, n=4,q=3은 패자 잔류형 3경기. 부전승 무출전 직행·정규 승수 합산·추첨 승리 모두 금지 |

| 이사 13석 중 이해충돌 회피로 기존 이사만으로는 찬성 7표가 불가능 | 실제 적격한 같은 의석군의 임시 대체 이사를 적법하게 선임한 경우 한 의석 한 표로 의결 가능; 미선임·불충분 찬성에는 의결 불능·미가결 구별, 중대 9표 기준 유지 |

## 15. 선수단·근속·방송 수용 반례

이 절은 이미 명시된 [TRANS-013·014](rulebook/30-TRANSFERS.md)와 [CAL-009·010](rulebook/20-CALENDAR.md)을 대상으로 하는 **비규범적 엔진 수용 기준**이다. 새 선수단 정원·로컬 기간·중계 슬롯 수를 입법하지 않는다.

| 다음 시즌에 적법한 제정권·협의·공표·발효를 거쳐 등록 수치가 바뀜 | 그 시즌에 실제 발효한 비로컬·명단 상한을 적용하고, 이전 시즌에 유효했던 등록·출전 이력과 확정 결과를 그대로 보존. 규정 미발효·관할 불일치는 `NEEDS_RULE` 또는 `NOT_EFFECTIVE`로 구별 |

| 같은 지역의 서로 다른 1·2부 공식 경기 | 서로 다른 부의 실제 운영·방송 자원과 선수/구단의 시간 점유가 독립적이면 병행 가능. 1부의 직렬 편성 규칙을 2부로 일괄 확대하지 않음 |

**해석 경계:** 과거 2027 LCK Split 2·3의 8주/132시리즈와 주마다 동일한 경기 수를 동시에 고정한 안은 그 자체로는 정수 조건이 맞지 않지만, 이후 11주/매주 12시리즈 기준 일정이 검토·채택되었고 나중에는 구간 수·길이의 영구 고정도 철회되었다. 과거 중간 시안의 불가능성을 현행 세계법 자체의 모순이라고 주장하지 않는다. 규정의 상위 제약, 당시 대회별 유효 초기 시행 규정, 실제 대회 편성 가능성은 각각 검증한다. 실제 경기 종료시간/세트 수가 변할 수 있으므로 일정 생성 가능성의 최종 증명은 실대진·방송 슬롯·경기 시간·이동과 조건부 결정전 경로를 기준으로 한다.

## 16. 공식 대회 명칭과 이력 표현

이 절은 COMP-005·015의 **법적 대회 명칭·기록 연속성**을 프로그램의 정보 표시와 연결하는 비규범적 수용 기준이다. 화면 표현·검색 색인·내부 데이터 식별자를 새로운 세계 법규로 만들지 않는다.

- 새로 개시한 공식 대회 회차에는 그 회차의 유효한 공식 명칭(First Stand, MSI, Eastern Cup, Western Cup, World Championship, Masters, Open 또는 장래 적법하게 개정된 명칭)과 그때 공표된 참가·시드 조건을 사용한다. 이전 대회의 **구형 표시명을 현재 공표문·일정·뉴스 제목에 혼입하지 않는다**.
- 과거 회차의 그 당시 실제 명칭·구단·성적·우승·출전권·대회 정체성은 보존한다. 현재 명칭 변경에 맞춰 과거 회차의 당대 공표문을 일괄 치환하거나 다른 대회로 병합하지 않는다.
- 내부 안정 ID는 명칭 표시와 분리해 동일 대회의 역사적 연속성을 연결한다. 지역 관할·연합 구역의 최신 적격성은 그 시즌에 유효한 지정과 대회 규정으로 판정하며, 과거 ID 또는 공석을 이유로 임의 시드를 창작하지 않는다.

| 상황 | 기대 결과 |
|---|---|
| 당시 명칭과 현재 공식 명칭이 다른 과거 대회를 열람 | 과거 당시 명칭·기록을 보존, 현재 정보와 구분 |
| 기존 대회에 미래 시즌부터 새로운 유효 명칭 시행 | 동일한 역사 연결·정체성 유지, 유효 시즌의 공표에는 새 명칭만 사용 |
| 지역이 합병되어 과거 지역 식별자가 실효 | 과거 출전 기록은 원본대로, 새 시즌은 유효 관할·배정·선발 규칙으로 참가 자격 재판정 |
| 시드가 공석이거나 과거 지역 참가 슬롯이 존재 | 실제 권한 있는 기관의 유효 대회 규정 없이 과거 지역 ID나 공석을 근거로 자동 참가팀 생성 금지 |

## 17. 다구단 동일 소유 그룹과 독립 경영 슬롯 수용

이 절은 BIZ-010·012와 2026-11-08 사용자의 **I-02 A안 직접 확정**을 구현하는 **비규범적 검증 계약**이다. 프로·아마추어 등의 고정 구단 종류를 새로 도입하지 않으며, 프로 라이선스·공식 대회 참가 자격과 독립 구단의 조직적 소유/경영 여부를 구별한다.

### 판정 대상·권한

1. 동일한 실질 지배 주체(직접·간접 지분과 계약·지배관계를 통합한 소유 그룹)는 여러 **독립 구단을 100%까지** 소유할 수 있고 소유 개수에 인위적 상한이 없다. 세계에 실제 존재하지 않는 소유주·자본·구단을 자동 생성하지 않는다.
2. 구단의 실제 별도 조직·경영 의사결정권·계약 주체·재정·참가 권리를 바탕으로 **독립 구단**인지 판정한다. 프로/세미프로/아마추어라는 명칭·전업 선수 계약·리그 등급·현재 프로 라이선스 보유 여부를 직접 경영 제한의 예외나 추가 조건으로 사용하지 않는다.
3. **한 소유 그룹이 동시에 직접 경영하는 독립 구단 수는 최대 1**이다. 나머지 그룹 소유 구단은 독립 경영진의 실제 결정권·예산·계약·정보권을 보유한다. 관련 구단의 선수 영입·방출·급여·전술·선발, 임원 임면과 특정 출자 조건을 통한 실질적 지시 등 **권한 우회도 검증기에서 거절**한다. 화면상 명령 숨김만으로 완료하지 않는다.
4. 모구단 **내부에 실제 종속된 산하 2군·리저브·Academy**는 하부 공식 경기 참가 여부와 무관하게 모구단과 하나의 구단 조직이므로 추가 직접 경영 슬롯을 소비하지 않는다. 이름이 Academy여도 조직적·계약상으로 **독립한 별개 구단이면 슬롯 판정에 포함**한다. 모구단의 1군/2군 선수·직원·급여·시설에 관한 별도의 확정 규칙은 그대로 유지한다.
5. 직접 경영 구단 변경은 **시즌 종료 시 신청·차기 시즌 발효를 원칙**으로 하고, 기존 구단 직접 경영 종료와 새 구단 지정이 하나의 원자적 전이로만 성립한다. 실패하면 양 구단 권한 원상 보존, 이중 직접 경영 임시 상태·허위 경영권 사건·기존 계약 소급 변경을 허용하지 않는다. 특별 변경권은 별도 유효 권한·규정이 실제로 확인될 때에만 고려한다.
6. 같은 그룹 소속의 서로 다른 독립 구단 간 이적·경기·지원은 각 구단의 적법한 독립 동의와 대회 공정성·시장·등록·가격·현금·원장·비공개 정보 제약을 충족해야 한다. 동일 그룹 지분 100%는 자유 선수 이동·대리 계약 승인·가공 수익·무료 지급·비밀정보 공유권이 아니다. 동일 그룹의 투자 재원은 BIZ-014의 **하나의 실제 유한한 재원**을 소비한다.

### 필수 수용 사례

| 사실·동작 | 기대 판정 |
|---|---|
| 한 그룹이 프로 라이선스 있는 독립 1부 구단과 아마추어 성격의 별도 독립 구단을 모두 100% 소유 | **소유 가능**. 두 구단 각각 독립 구단이며 **직접 경영은 하나만 가능**. 아마추어라는 이유로 두 번째 직접 경영 자동 허용 금지 |
| 같은 그룹이 서로 다른 지역의 독립 구단 3곳을 소유하고 그중 하나만 직접 경영 | 허용. 나머지 2곳은 독립 경영과 정보·계약·원장 분리가 실제로 성립해야 함 |
| 그룹의 유일한 직접 경영 모구단과 실제 내부 산하 2군·Academy가 각각 공식 1·3부에 참가 | 산하 2군은 **추가 독립 경영 슬롯 아님**. 참가 자격·모구단과 동일 부 금지·인력·회계 규칙은 각각 검증 |
| 독립 구단의 이름을 `Academy`로 변경한 뒤 두 번째 구단 직접 경영을 시도 | 별도 조직·계약·경영 의사결정권이 유지되는 한 **불허**. 단순 명칭 변경은 조직적 독립성을 바꾸지 않음 |
| 두 그룹 소유 구단에 지분만 보유하면서 경영권 지시·임원 임면·특정 자본 지급 조건으로 양측의 일상 결정을 직접 좌우 | **불허**. 간접 실질 지배 명령에도 동일 한 곳 제한 적용. 실제 독립 경영 계약·라이선스 취지 위반 |
| 한 그룹이 시즌 종료에 직접 경영 구단 A에서 B로 변경 신청 | 정상 권한·시행 시각에 **A 해제+B 지정 원자적 전이** 후 성공. 중간 순간 동시 직접 경영 없음; 실패 시 기존 A 권한 보존 |
| 한 그룹 소유 구단 A와 B가 동일 세계 시각에 계약·선수 이적 제안 | 각 구단의 독립적 최종 수락·선수 동의·시장·재원·등록·정보 접근권 별도 검증. 그룹 소유라는 이유로 자동 체결·무상 정산 금지 |
| 기존 독립 구단이 아마추어 운영에서 전업 계약·프로 라이선스를 획득 | 실제 독립 구단과 슬롯 판정은 그대로. 신원·기존 계약·역사 보존, 새 별개 구단 복제 없음 |

정본의 새로운 적용 대상은 **개별 지역·대회의 소속·라이선스 또는 외부 법적 '프로 구단' 태그 없이도 판정 가능해야** 한다. 실제 소유·경영 권한의 명세가 누락되면 `NEEDS_FACTS`, 새로운 처분·시행 규정의 필수 권한이 없다면 `NEEDS_RULE`을 사용하되 그룹 소유주에게 이중 경영권을 임의 제공하지 않는다. 구현·시드·장기 모의 경기·재정·저장 복원 검증과 정본 조문의 입법 확정은 구별한다.
