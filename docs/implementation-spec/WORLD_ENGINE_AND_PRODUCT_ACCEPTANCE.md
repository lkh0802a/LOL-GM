# LOL-GM 엔진·제품 수용 요구사항

이 문서는 **게임 세계의 법규가 아니다**. 세계관 정본과 유효한 세계 내부 규정을 소프트웨어로 구현할 때 검증할 제품·데이터·UI·QA 요구사항이다. 어떠한 조항도 사무국·구단·국가협회·선수의 새로운 법적 권한을 만들어서는 아니 된다. 규칙의 참조점은 [세계관 정본](../rulebook/README.md)이다.

## 저장·버전 관리

- 개발 초기에는 과거의 폐기된 세계 제도를 구버전 파일 호환만을 이유로 활성화하지 않는다. 출시·장기 경력 지원 단계에서는 지원 대상 버전의 호환 또는 명시적 마이그레이션을 제공한다.
- 개발 단계와 지원 포맷, 비호환 전환과 내보내기·안내 정책을 명확히 기록한다.
- 현재 지원하는 저장은 원자적인 마지막 성공 스냅샷, 실패 복구, 슬롯 간 격리, 실제 세계 역사와 계약·채무·경기 결과의 일관성을 보존한다. 저장 손상이나 실패가 유효한 세계 사건을 소급 변경하지 못하게 한다.
- 규범의 효력 시점과 기술 스키마 버전은 다른 개념이다. 데이터 마이그레이션은 세계 안의 계약·대회 규정 개정과 같지 않다.

## 관리자 조작·업무 자동화

- 적법한 중대 결정권자는 전술·선발·계약·투자·대회 참가의 최종 선택을 보유한다. UI나 자동화가 권한자의 승인 없이 최종 확정·서명하지 않는다.
- 합법적인 반복 정산·일상 업무는 자동 집행하되 실제 지급 불능, 비용, 시간, 권리 및 계약 결과를 생략하지 않는다. 일상 계약 납부에 반복적인 확인·납부 버튼을 강제하지 않는다.
- 코칭·스카우팅 일정은 담당자가 추천할 수 있지만 감독에게 매일 스크림 예약·회의·보고 버튼을 강제하지 않는다. 선수에게 실제로 발생하지 않은 훈련·스크림 결과를 생성하지 않는다.
- 직원 계약 만료 안내는 선택적으로 제공하되 별도 감독/직원 인수인계 기능이나 강제 회의·자동 계약을 만들지 않는다.
- 랭크·스카우팅의 반복 유망주 발견 알림·수집 배지는 도입하지 않는다. 실제로 관측되지 않은 능력·잠재력은 UI에도 공개하지 않는다.
- 감독이 수동 밴픽을 입력하는 동안 **현실 시간 카운트다운을 강제하지 않는다**. 게임 세계 안의 실제 밴픽 시간과 적법한 드래프트 결과는 정본에 따라 처리한다.
- 이전 선발·저장 구성을 불러올 수 있으나 최종 선발·등록은 적법한 감독 결정과 대회 규정으로 확정한다.
- 별도의 주장(captain) 임명/관리 UI를 도입하지 않는다. 실제 경기 커뮤니케이션을 주장 전용 보너스로 중복 계산하지 않는다.

## 선수·재정 정보 및 보고

- 스카우팅 화면은 불확실한 추정치와 미관측 상태, 당시 정보·평가 근거를 구별한다. 후속 평가를 이용하여 당시 이미 알려졌던 것처럼 정보를 소급 수정하지 않는다.
- 재정 화면은 지급 기한, 미지급, 현금 부족 시점과 실제 선택 가능한 조치를 표시한다. 향후 1·3·6·12개월 현금흐름 전망을 지원한다. 추정 수익과 확정 현금·채무를 혼동하지 않는다.
- 구단이 실제 가입한 선수 의료·부상 **보험 계약**의 보험료·보장 조건·의료 사건·청구·미수 보험금·실수령을 각각 원장에 연결한다. 가입하지 않은 구단에 임의 보험 비용을 부과하거나 계약에 없는 보험금을 확정 현금으로 생성하지 않는다. [#251 79B 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244712136)
- 육성 구단 보상 보고는 확정 지급과 추정·미수·지급 시각을 구분한다. 실제 없는 재원·금액·비율·채권을 새로 생성하지 않는다.
- 선수 공급·신인 육성·장기 구단 경제를 다지역·다시즌 표본으로 검증한다. 제한된 시즌 테스트 결과를 장기 검증 완료의 증거로 제시하지 않는다.
- 실제 재정 원장과 계약에 근거해 육성·보상/성장 결과를 검증한다. 입력 차이가 있다는 사실만으로 다른 결과를 강제하거나 임의 현금을 생성하지 않는다.

## 기술 수용·회귀검증

1. **세계 상태의 단일성:** 동일 시각에 동일 선수가 두 실제 경기를 치르지 않으며 동일 경기·지급·이적·활동을 두 번 확정하지 않는다.
2. **규범과 제정된 내부 규정의 분리:** 세계 헌장의 버전·지역/대회별 유효 규정·개별 계약·경기 사건을 서로 다른 기록으로 보관한다.
3. **유효 시점:** 사건의 적법성은 당시 유효 규정으로 판정하며 후속 법률 개정이 과거에 소급 적용되지 않는다.
4. **정보 경계:** AI·사용자 모두 당시 허가된 정보와 실제 관측만 이용한다. 숨은 능력치나 타 구단 내부 계획에 직접 접근하지 않는다.
5. **권한 검증:** 새로운 활동은 이름이 아니라 실제 주체·권한·시간·자원·계약·효력에 따라 판단한다. 규정이 허용한 재량적 선택은 AI 전략에 맡기되 적법성 판정은 일관되게 수행한다.
6. **실패와 불확실성:** 권한·명단·예산·주최·등록 규정이 없으면 임의로 승인/지급/경기를 생성하지 않는다. 미확정 상태와 거부·대기·재검증 상태를 구분한다.
7. **도메인 분리:** 국가대표 대회는 구단 대회 네 종류와 별도로 관리한다. 국가대표가 28일 시장 동안 경기해도 구단 실경기 금지는 유지된다.
8. **코드 경로의 소유권:** Rust 엔진의 정산·경기·계약 결과만이 해당 세계 사건의 원본을 확정하며, TypeScript UI는 제안·표시·합법적 명령 전송만 수행한다. 기존 코드 보존과 이관 경로는 실제 아키텍처 명세에서 검증한다.

이 문서는 정본의 권한·의무·금지사항을 변경하지 않는다. 위의 구체적인 UI/QA 수용 조건은 [UI 요구사항](../interface-spec/USER_EXPERIENCE_REQUIREMENTS.md)과 합쳐 구현 검증에 사용한다.

## 선택형 데이터 열람·편집 및 과거 기록

- 모바일에서는 **권역 → 국가/연합 → 리그 → 구단** 탐색을 지원하고 실제 존재하는 지역·대회·구단을 즐겨찾기에 고정할 수 있다. 사용자가 **모든 상단 탭의 순서를 직접 재배치·보존**하며, 드래그/동등 조작·320px·브레이크포인트·설정 복구·새 메뉴 추가 후에도 필수 기능이나 기존 공식 기록에 대한 접근권은 삭제하지 않는다. [#251 195C 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6246141985)
- 한 주간의 중요한 실제 경기·계약·의료·재정·마감 사건을 중복 없이 요약한다. 법적 기한 또는 감독의 필수 결정을 놓치지 않도록 알림을 구별하고, 매일 미세 사건마다 강제 팝업을 생성하지 않는다.
- 과거 시즌의 선수단·출전·우승·실제 능력·재정·계약과 당시 유효한 패치·대회 형식·정책을 당시 원본으로 열람하고, **최소 두 실제 시즌**의 비교를 지원한다. 현재 상태나 현재 패치를 과거 기록에 소급 덮어쓰지 않는다.
- 관리 구단과 적법한 공개 기록에 한해 실제 경기 통계·시즌 성적을 **CSV 등 표 형식으로 내보내기**할 수 있다. 숨은 선수 잠재력, 비공개 의료·개인 계약, 타 구단 비공개 스크림·스카우트 보고서, 내부 MMR을 내보내기 데이터로 유출하지 않는다.
- 경기·선수·구단의 상훈·명예의 전당·기념 기록을 실제 과거 성적·당시 닉네임·소속·적법하게 확정한 시상 사건에 연결해 표시하고, 등재 자체에 추가 경기력 효과를 부여하지 않는다.
- 텍스트 중계·관전의 **표시 속도/시각효과**를 사용자가 조절하거나 간편 결과·상세 보기로 전환해도 **동일 확정 경기·세트·난수·세계시계·저장 이력**을 소비한다. 전환 시 경기를 새로 시뮬레이션하거나 승패·체력·계약을 변경하지 않는다. [#251 85B 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6244712136)
- 유료 팬클럽·입장권·상품·후원 수입은 **실제 가입·판매·계약 이행·환불·미지급** 상태로 나누어 표시한다. 자유로운 공식 동시 중계와 무료 다시보기의 접근권을 유료 구독 상품으로 오인하게 표시하지 않는다.

## 소규모 법규의 자동 회귀 사례

1. 동일 선수의 **계약·공식 구단 등록·국가대표 대회 명단·실제 한 세트 출전**의 구분, 비로컬 상한과 소집·시간 점유를 검증한다.
2. **최초 시즌에 적용되는** 구단 전체 코치 7명(감독 제외)·분석가 4명·스카우트 6명 **고용 상한**과 별도의 대회별 현장 등록 상한·자격을 분리한다. 이후 적법하게 제정·공표·발효된 직원 상한이 있으면 그 시각 이후 당시 유효한 상한으로 판정하며, 상한 미발효 상태의 조기 증원은 거절한다. 산하 2군 급여·시설비의 지급자는 실제 모구단 원장으로 단일화하되 2군 비용 분석을 가능하게 한다. 과거 9명 상한 때 적법하게 고용한 8~9명은 최초 7명 상한으로의 변경만을 이유로 기존 유효 계약을 소급 해제하지 않되, **7명 상한이 유효한 동안** 추가 신규 고용·초과 인원을 유지하는 갱신은 불허한다.
3. 공식 시리즈의 조기 종료와 스크림 약정 세트 수를 분리하고, First Selection의 실제 앞 세트 결과·픽 순서·진영 선택을 해당 대회 규칙으로 검증한다.
4. 새 지역 첫 시즌의 국제 슬롯·지역 리그 형식·장기 포지션 전향·로컬 취득 조건은 **적법하게 초기 제정·공표된 유효 세계 규정**과 실제 선수 계약에 따라 재현한다. 불완전한 초기 구성은 자동으로 존재하지 않는 구단·선수·유효 금액을 생성해서 보완하지 않는다.

이 수용 조건은 구단과 선수의 새로운 법적 권한을 직접 생성하지 않으며, 각 행위의 법률상 효력은 [세계 정본](../rulebook/README.md)에 따른다.
