# 룰북에서 분리한 비규범적 제품·검증 요구사항

> **성격:** 세계관 정본 바깥의 소프트웨어 구현·검증 요구사항. 규정 제정권을 새로 만들거나 사용자가 승인한 요구를 철회하지 않는다. 이 문서는 PR #328에서 직접 가져온 기존 정책 문장을 **검증 항목으로만 이관**한 것으로, 실제 코드 검사/CI가 통과했다는 뜻이 아니다.

## QA-001 · 국가별 장기 선수 공급 분포 검증

**이전 조문:** `PLAYER-012` / 검토 법전 제65조.

여러 시즌의 선수 능력 수준과 신인 공급·은퇴·실전 성장·포지션 및 지역 이동을 실제 표본으로 검토하고, 문제가 확인되면 입증된 원인을 찾아 교정한다. 제한된 시즌 검사를 다지역 장기 시즌 검증으로 간주하지 않는다. 분포 고정을 위한 선수 능력 일괄 강등이나 임의 난이도 보정은 세계 규칙상 금지된다.

**수용 조건:** 국가·지역 및 다중 시즌 표본 범위를 기록하고, 검증이 실제로 다룬 범위와 미검증 범위를 구분한다. 정본을 고치거나 임의의 고정 잠재력 상한을 새로 넣는 방법으로 테스트를 통과시키지 않는다.

## QA-002 · 육성 보상 정산·회계 표시

**이전 조문:** `BIZ-011` / 검토 법전 제105조 기존 ⑤항.

육성 보상 보고는 입증된 실제 기여를 근거로 확정 지급과 미확정 추정, 미수 및 지급 시점을 구분하고 같은 사건의 중복 지급 위험을 표시한다. 실제 없는 재원·금액·비율을 만들어 표시하지 않는다. 유효한 계약·권리와 실제 재정 원장을 기준으로 하며 단순 추정은 확정 채권이나 지급된 현금이 아니다.

**수용 조건:** 사용자·AI에게 표시하는 보고서는 정본에서 실제로 발생한 육성 사건과 지급 원장을 반영한다. 정본에 확정되지 않은 수치를 UI나 보고서가 새로운 채무/상금으로 만들지 않는다.

## QA-003 · 육성 보상과 장기 경제의 검증 방법

**이전 조문:** `BIZ-011` / 검토 법전 제105조 기존 ⑥항.

육성 보상과 장기 경제를 검증할 때는 실제 육성·계약, 구단 소유·임대, 기간과 당시 근거를 통제한 비교로 지급과 육성 성과를 확인한다. 다른 입력이 언제나 다른 결과를 내도록 강제하지 않으며, 실제 원장이나 계약이 없는 지급을 검증 결과로 만들어내지 않는다.

**수용 조건:** 입력 시나리오와 실제 정산/소유권/계약 차이를 기록하고, 결과 차이가 없다는 이유만으로 임의의 육성 보상을 생성하지 않는다.

## QA-004 · 세계 규정과 UI 구현의 구별

**이전 조문:** `MATCH-003` / 검토 법전 제91조.

수동 밴픽을 현실 시간 카운트다운으로 강제하거나, 입력 중이라는 이유로 자동 기권 및 허구의 기술 사고를 생성하지 않는 **사용자 인터페이스** 요구사항은 [별도 UI·UX 명세](../interface-spec/USER_EXPERIENCE_REQUIREMENTS.md)의 `UI-011`로 이관했다. 경기 세계의 유효한 밴픽 시간·실제 선택권·서명·등록·대회 적법성은 법전 본칙에 남긴다.

## QA-005 · 저장 버전 호환·마이그레이션 정책

**이전 조문:** `CORE-009` / 검토 법전 제9조에서 분리한 저장 구현 사항.

개발 초기·잦은 구조 교체 단계에서는 구버전 저장 파일을 영구 호환시키기 위해 **이미 폐기된 과거 세계 제도를 다시 활성화하거나 불필요하게 복잡한 별도 호환 체계를 유지하도록 강제하지 않는다**. 출시 및 장기 경력 안정화 단계에 진입하면 지원 대상 구버전의 호환 또는 명시적인 저장 마이그레이션 정책을 강화한다.

개발 단계·지원하는 저장 포맷·비호환 전환·내보내기·복구 안내는 명확히 기록한다. **현재 지원되는 정상 저장/불러오기, 마지막 성공 스냅샷의 원자적 보존, 실패 복구, 슬롯 격리 및 실제 역사·계약·재정·경기 결과 보존은 필수**다. 단순히 개발 초기라는 이유로 정상 저장을 손상시키거나 이전에 확정된 실제 사건을 임의로 삭제해서는 안 된다.

**규범 구분:** 저장 포맷과 마이그레이션 방식은 **제품·기술 요구**이며 세계 외부/내부 규정이 아니다. 그러나 이미 발생한 경기·계약·현금·채무·역사의 소급 불변은 외부 헌장의 제2조·제9조에서 보호한다.

## 경계 및 추적

- 이 문서의 QA 항목은 **세계 외부 헌장 또는 세계 내부 시행 규정이 아니며**, 그 규칙을 검증하는 구현 수용 조건이다.
- 과거 사용자 승인 기능과 문장은 각각 `LEGACY_MAP.md`/원문 `docs/rulebook/`에 계속 남긴다. 기존 `PLAYER-012`·`BIZ-011`·`MATCH-003`의 세계 내부 효력 자체를 취소하거나 기존 계약·사건을 변경하지 않는다.
- 이 항목에 관한 정적 파일 검사만으로 실제 Rust/TypeScript 엔진 기능, 장기 시뮬레이션 및 재정 원장 검증의 완료를 선언해서는 안 된다.
