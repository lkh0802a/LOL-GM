# D02-A — 선수 건강 사건과 일 단위 재활 (2026-09-29)

## 구현 범위

- 선수별 선택적 `medical`, `medicalResidual`, `medicalLoad`, `medicalOverloadDays` 상태. **월드 스키마 v15 / 저장 포맷 2 유지**. 기존 저장에서 해당 속성 부재 허용.
- 손목/허리/목 부상, 단기 질병, 누적 업무 강도가 높아진 경우의 드문 번아웃. 선수 나이, 공식 경기 세트, 스크림 세트, 훈련 강도, 피로와 컨디션을 입력으로 사용하고 선수·날짜별 별도 고정 RNG로 추첨한다. 무작위 사건은 세계 캘린더 **하루 1회만** 발생한다.
- 치료 소요 기간에 스태프 회복 숙련도·회복 시설·훈련 강도·피로가 반영된다. 치료 이후 작은 일시적 경기력 저하가 남고, **심한 신체 부상**은 연령·관리 자원에 따른 소확률로 해당 능력치 1포인트 영구 후유증을 남긴다. 이는 실제 의학 통계가 아닌 밸런스 수치다.
- 몸 상태 때문에 출전 불가한 선수는 공식 선발 5인 검증과 스크림 선발에서 제외하고, 동일 스쿼드의 다른 선수로 긴급 대체한다. 경증 치료 선수는 일정 경기력 패널티를 안고 뛸 수 있다. 팀별 5인 최소 로스터를 깨뜨리는 **동시 결장 발생은 경증 사건으로 대체**해 구조적 경기 진행 중단을 방지한다. 이 보수적 게임 예외는 의학적 현실의 보증이 아니다.
- AI 및 관리 구단에 동일 의료 추첨·회복·출전 자격 경로 사용. 선수 상세 페이지, 로스터, 뉴스, 커리어 사건에서 상태 확인 가능. 오프시즌 날짜 건너뛰기의 미처리 치료 시간을 계산한다.
- 공식 경기 성적/경험, 스크림·피로 상태에서 업무 강도가 입력되지만 치료 자체는 공식 경기 통계나 챔피언 메타 샘플을 생성하지 않는다.

## 수락 기준

`scripts/medical-acceptance.mjs`: 5인 최소 인원 보호, 6인 스쿼드 실제 결장·대체 선발, 양쪽 연습 부하 축적, 기존 v15 저장 및 포맷2 왕복, 중복 일일 이벤트 차단, 치료 복귀/후유증, 장기 날짜 이동, 중증 영구 후유증의 희귀 분포. 모든 표준 `npm run check`, 2시즌 커리어, 퍼포먼스·빌드 CI를 함께 통과해야 한다.
