# 방송 편성 UTC 날짜 경계 처리 및 국제대회 라운드 분산

## 시차 기준

각 정규리그·국제대회 중계 편성에는 개최지의 IANA 현지 시각을 사용한다. 실제 경기 진행과 세계 날짜의 기준은 **절대 UTC 시각**이다. 시각 변환에는 해당 경기 연도의 서머타임이 반영된다. 한국 시청 시간은 별도로 표시한다.

### 자정을 가로지르는 편성

북미(로스앤젤레스)의 겨울 화요일 오후 2시와 오후 8시는 서로 다른 UTC 날짜에 시작한다. 한 현지 중계일에 3~4개의 경기를 편성했을 때도 두 날짜를 하나의 UTC 날짜로 임의로 처리하거나, 일정을 거부하거나, 공식 경기를 건너뛰지 않는다.

- 매 시리즈의 `utcAt`, `localDate`, `timeZone`, `time`, `broadcastSlot`을 개별적으로 보존한다.
- `s.days[].date`는 해당 시리즈의 **실제 UTC 개시 날짜**이다. 같은 UTC 날짜가 된 인접 현지 중계일의 시리즈는 그 UTC 경기일로 함께 묶는다. 하루 동안의 세계 효과는 한 번만 실행한다.
- 같은 날짜로 합쳐진 다른 현지 라운드의 레이블은 버리지 않고 유지한다. 경기 ID는 일정 전체에서 고유하며 시리즈는 개최 시각 순으로 처리한다.
- 국내 정규리그는 여전히 현지 화요일~일요일 중계, 팀당 주 2시리즈와 공식 경기 사이 최소 하루 휴식을 지킨다. 월요일 중계 여부 판단도 UTC 요일이 아닌 **개최지 현지 요일**로 계산한다.
- 기존 저장 파일에 절대 개시시각이 없다면 기존 날짜 방식으로 복원한다. 월드 스키마 v15 / 저장 포맷 2를 그대로 사용한다.

### 국제대회

- 개최지는 해당 대회 전체에 하나의 실제 현지 시간대가 적용된다.
- 한 국제대회 스위스/그룹 라운드에 시리즈가 많은 경우 하루에 3시리즈씩 분산 편성한다. 경기 시작 시각은 현지 13:00·16:30·20:00 등으로 서로 다르게 지정한다.
- 여러 UTC 날짜에 걸쳐 종료된 같은 스위스 라운드의 **모든 경기**를 집계한 뒤 다음 라운드를 생성한다. 마지막 날짜에 열린 경기만 집계하는 오류를 방지한다.
- 다음 라운드 날짜는 마지막 경기의 **개최지 현지 날짜**를 사용한다. 스위스 다음 라운드 사이 최소 하루 전체 휴식일을 둔다.

### 스크림

양 팀이 실제로 공유하는 오후/저녁 3시간 연습 블록을 UTC 시각으로 교차시킨다. 두 블록의 교집합이 90분 이상이어도 그 시간에 3게임이 들어간다고 가정하지 않는다. 가능한 비공식 게임 수는 `floor((endsAt-startsAt)/1시간)` 이하로 제한한다. 상대 선택 확률, 가까운 공식전 상대 회피, 양 팀 중복예약 방지와 각자의 현지 연습 시간대는 기존 규칙을 유지한다.

## 검증

`scripts/timezone-calendar-acceptance.mjs`가 로스앤젤레스 현지 중계 10·12·16·18·20팀 리그의 다중 UTC 날짜, 공식 경기 ID 고유성, 주당 2경기, 현지 월요일 비편성, 16팀 스위스 라운드 전체 결과 반영, 다음 라운드 휴식일을 검사한다. 기존 서머타임·한국 시청 시간·양 팀 스크림 시각 일치·세이브 복원 수락 검사도 보존한다.

한계: 여기서 구현한 것은 실제 경기 시작 시간과 날짜, 시차에 따른 일정 충돌 검사다. 장거리 이동 소요 시간, 현지 적응·시차 피로, 방송국의 독립 병렬 송출 설비 또는 지역 외 스크림 협상까지 구현했다고 주장하지 않는다.
