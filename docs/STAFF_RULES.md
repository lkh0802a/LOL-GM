# LOL GM — 스태프 구조 규칙

상태: **확정 규칙 문서**
기준일: 2026-09-28

## 1. 감독

- 사용자 구단에서 사용자가 감독이다.
- 범용 '수석 코치' 슬롯은 두지 않는다.
- 전략적 최종 결정권은 사용자에게 있으며 스태프는 조언·분석·훈련·전문화 기능을 제공한다.

## 2. 코칭팀

- 구단은 코치를 최대 **9명**까지 고용할 수 있다.
- 코치 유형은 전략, 육성, 퍼포먼스, TOP/JGL/MID/ADC/SUP 포지션 코치 등을 포함한다.
- 모든 유형을 의무적으로 채울 필요는 없다.
- 포지션 코치 5명을 모두 보유하는 것도 가능하지만 연봉·구단 재정·채용시장이 실질적 비용 제약이 된다.
- 코치 역할은 서로 같은 코칭팀 고용 상한 9명 안에서 경쟁한다.

## 3. 분석팀

- 분석가는 코치 슬롯과 별도 부서다.
- 분석가는 최대 **4명**까지 고용할 수 있다.
- 상대 분석, 밴픽/메타 분석, 데이터 분석 등 서로 다른 전문성을 가질 수 있다.
- 여러 분석가의 효과는 단순 합산이 아니라 전문성·중복·협업 효율을 반영한다.

### 분석 전문성의 구현 범위 (2026-10-02)

- 새로 생성되는 분석가는 상대(opponent), 밴픽/메타(meta), 데이터(data) 중
  한 전문분야를 갖는다. 직원 ID로 결정되는 가상 정책이며 추가 RNG 소비로 다른
  생성 데이터를 바꾸지 않는다. 기존 저장의 누락 필드는 범용으로 그대로 둔다.
- 기존 주/보조 전문성 분산 및 직원 중복 한계효용을 먼저 적용한 분석 능력에
  자기 분야 1.2, 다른 분야 0.75를 적용하고 0~99로 제한한다. 범용은 모두 1이다.
  이 수치는 가상 시뮬레이션 정책이지 실제 분석가 성과 통계가 아니다.
- 상대 전문성은 실제 경기 상대 픽 관찰의 챔피언 연구/카운터 학습, 메타 전문성은
  밴픽 평가 오차·조언·First Selection, 데이터 전문성은 프로 표본의 가중/신뢰도에
  연결한다. 숨은 상대 능력을 새로 제공하지 않으며 기존 스크림 분석 보강은 유지한다.
- 공식전에는 기존 현장 등록 인원만 효과를 제공한다. 관찰 학습은 필터된 경기
  복사본이 아닌 실제 소속 구단에 남고 저장된다. 비공식/리플레이의 기존 미학습
  경계를 유지하며 과거 보고서·연구 수치를 소급 재계산하지 않는다.
- AI 채용은 관측 평가와 공개 전문성을 사용해 기존 분석가들이 덜 지원하는 맥락에
  더 높은 비교 가중치를 둔다(`1/(50+관측된 기존 분야 기여 합)`, 정규화).
  사용자 채용은 수동이다. 분석가 고용 상한 4·계약·해임·이직 비용은 바꾸지 않는다.
- 전문성은 동일 직원의 고용 변경·은퇴·저장에 보존하며 알 수 없는 명시 값은
  저장/계약 검증에서 거부한다. UI에는 분야/범용을 표시하고 숨은 능력치는 공개하지 않는다.

## 4. 스카우팅팀

- 스카우터는 별도 부서다.
- 스카우터는 최대 **6명**까지 고용할 수 있다.
- 지역/리그/선수군별 담당을 나눌 수 있다.
- 스카우팅 정확도와 범위는 인원뿐 아니라 개인 능력, 지역 지식, 시설과 예산의 영향을 받는다.

## 5. 구단 고용과 대회 등록은 다르다

- 위 9/4/6은 **구단 내부 고용 상한**이다.
- 모든 고용 스태프가 모든 대회 현장에 등록될 필요는 없다.
- 지역 리그 사무국과 국제 사무국은 각 대회별 코칭스태프/분석스태프 현장 등록 인원과 마감일을 별도로 정할 수 있다.
- 대회 등록 제한은 구단이 스태프를 고용할 수 있는 총인원을 줄이지 않는다.
- 사무국이 현장 등록 상한을 공표한 대회는 첫 공식 경기 전 제출 명단을 저장하고, 첫 경기부터 대회 종료까지 일반 변경을 잠근다. 상한을 공표하지 않은 대회에는 임의의 기본 인원을 만들지 않는다.
- 대회별 명시 마감일이 있으면 해당 날짜부터 명단 변경을 잠근다. 제출 당시 인원·마감 정책과 직원 신원은 시즌 기록에 보존한다.
- 공식전 코칭·분석 효과는 현장 등록 명단에 포함되고 현재 고용 중인 직원이 제공한다. 퇴사 후에도 제출 이력은 유지하며, 구단 훈련·비공식 연습은 전체 고용 스태프를 사용한다.

### AI 현장 인원 배분 (2026-10-02)

- 마감 전 AI는 현재 고용/계약 중인 직원의 관측 평가와 공개 주/보조 직무,
  분석 전문분야로 현장 명단의 추가 기여를 비교한다. 숨은 실제 rating이나 보조
  전문능력의 숫자를 읽지 않는다. 공개 보조 직무에는 관측 평가 × 기존 0.35
  가중, 모든 분야에는 기존 전문성 분산율을 적용한다.
- 전략, 상대/메타/데이터 분석, 스카우팅 관찰을 각기 기존 중복 직원 한계효용으로
  합산한다. 선택 목적 가중은 전략 1, 분석 각 1/3, 스카우팅 0.25라는 명시적
  가상 정책이다. 분석 분야 보강/감산과 0~99 상한은 공통 계산을 따른다.
  전략/분석은 조언·밴픽·상대 학습, 스카우팅은 상대 숙련 관찰에 실제 연결돼 있다.
- 가장 큰 양의 추가 기여를 한 명씩 선택하고 동률은 직원 ID로 정한다.
  이는 제한된 후보의 탐욕적 선택이며 모든 명단의 전역 최적해나 현실의 성과
  크기라고 주장하지 않는다. 직무별 의무 인원/최소 정원은 없다. 현장 관련
  전문성이 없거나 효과 상한에 도달하면 정원을 채우지 않는다.
- 구단 훈련/회복만 담당하는 직원은 그것만으로 현장 우선순위를 얻지 않는다.
  전체 고용 명단/급여/연습 효과는 그대로 유지한다. 공표 없는 대회의 기본
  정원을 발명하지 않으며, 공표된 0명도 준수한다.
- 기존 사용자/AI 공통 등록 명령으로만 제출한다. 사용자 명단은 수동이며
  종료/마감 이후 평가 변경이나 퇴사로 새 제출을 하지 않는다. 변경 없는 명단은
  제출 기록을 다시 쓰지 않는다. AI 미리보기는 공개 관측/전문성 기여가 달라지면
  무효이며 늦은 실패는 명단·기록을 함께 복원한다. 저장 형식/과거 기록은 유지한다.

## 6. AI/사용자 동등 규칙

- 사용자 구단과 AI 구단은 같은 고용 상한, 계약, 이동, 해임, 대회 등록 검증을 사용한다.
- AI 구단은 재정, 팀 철학, 목표, 현재 공석과 후보자의 능력을 보고 채용하며 항상 최대 인원을 채우지는 않는다.
- 사용자 구단의 채용/해임은 자동 실행하지 않는다.

## 7. 레거시 이전

- 현재 런타임의 `team.coach`는 범용 수석코치로 유지할 대상이 아니다.
- 성장, 밴픽, 분석, 재정 등 `team.coach`에 연결된 기능을 전문 스태프 속성/부서로 이관한 뒤 레거시 슬롯을 제거한다.
- 이관 전까지는 저장 호환성을 위해 필드를 유지할 수 있지만 UI에서 영구적인 수석코치 개념으로 고착시키지 않는다.


## 9. 69개 최종 선택 반영

- 코치는 여러 전문분야를 가질 수 있으나 전문분야가 많을수록 각 효과가 분산된다.
- 포지션 코치는 해당 포지션 선수 성장 + 챔피언 숙련/라인 연구에 영향을 준다.
- 동일 전문 분석가를 여러 명 둘 수 있지만 한계효용이 감소한다.
- 스카우터의 담당 지역 수/범위는 개인 능력과 지역 지식을 바탕으로 엔진이 결정한다.
- 스태프 계약 기간은 자유 협상한다.
- 계약 중인 타 구단 스태프는 위약금을 지급해 영입할 수 있다.
- 스태프 은퇴는 나이/커리어/성과/동기를 엔진이 종합해 결정한다.

### 다중 전문분야 효과 분산 (2026-10-02)

- 주 전문분야와 다른, 알려진 역할의 양수 보조 전문분야만 센다. 동일 역할 중복,
  0점 및 알 수 없는 레거시 키는 효과/분산에 포함하지 않으며 원본은 삭제하지 않는다.
- 분야별 효과에 공통 배분율 `1 / (1 + 0.35 × 보조 전문분야 수)`를 적용한다.
  주 분야는 기존 능력, 보조 분야는 기존 능력 × 0.35를 사용한다. 단일 전문가는
  기존 효과 그대로이며 분야를 늘리면 주/기존 보조 효과 모두 줄고 새 분야를 지원한다.
  이 배분율은 명시적인 가상 정책이며 실제 직무 시간/업계 통계가 아니다.
- 기존 중복 직원의 한계효용, 고용 상한, 연봉/동의/계약, 현장 등록 규칙은 유지한다.
  코칭·분석·스카우팅·지역 조사 능력 및 포지션 챔피언 학습은 공통 계산을 따른다.
- AI 채용의 주 분야 비교에도 같은 배분율을 관측 평가에 적용한다. 숨은 실제 능력을
  평가로 읽지 않으며 수동 구단의 채용은 자동 실행하지 않는다. UI는 전문분야와
  효과 분산을 설명하고 고용 전 정확한 능력치를 공개하지 않는다.
- 이직·자유계약·은퇴·저장 시 원본 전문분야를 보존한다. 알려진 분야의 값은
  유한한 0~100이어야 하며 잘못된 저장/계약 상태를 거부한다. 과거 조사 보고서나
  이미 얻은 챔피언 학습 보강은 다시 계산하거나 삭제하지 않는다.

### 포지션 코치의 챔피언 학습 (2026-10-02)

- 실제 챔피언 훈련/스크림 시점의 현재 포지션 전문능력(기존 중복 한계효용 및
  보조 전문성 가중 포함)을 99로 나누고 0.3을 곱해 0~30% 학습 보강을 적용한다.
  이것은 가상 정책이며 실제 코칭 효과 통계가 아니다. 다른 포지션은 보강하지 않는다.
- 원본 훈련/스크림 횟수와 공유 100점 시간은 그대로 기록한다. 숙련 보강은
  실제 횟수 × 기존 훈련 0.09/스크림 0.16 × 코치 보강률, 상성 연구 보강은
  실제 횟수 × 0.03 × 보강률이다. 시즌별 누적 상한은 각각 8/5다.
  시즌 성장에 선수 학습/챔피언 난이도를 함께 반영하며 기존 숙련 성장 상한 8,
  숙련/상성 99 상한을 유지하고 정산 뒤 두 누적치를 초기화한다.
- 퇴사/영입/포지션 변경은 이후 실제 연습에만 영향을 준다. 이미 기록된 보강은
  선수에게 남고 저장/복원된다. 과거 저장의 누락 필드는 0이며 소급 생성하지 않는다.
  공식전 횟수를 코치 보강으로 늘리지 않으며 휴식/부상/공식 일정의 기존 연습 제한을
  우회하지 않는다. 사용자와 AI는 같은 연습·정산 함수를 사용한다.

### 개인 지역 지식의 구현 범위 (2026-10-02)

- 개인 `scoutRegions`에는 실제 외부 선수 관찰의 지역·지식·횟수·마지막 날짜를
  기록한다. 관찰 위치는 현재 소속 구단의 지역, FA는 선수의 현재 region이다.
  국적/구단 근무지로 과거 경험을 소급 생성하지 않는다. 없는 레거시 기록은 0이다.
- 관찰을 담당한 현재 직원 한 명만 경험을 얻는다. 선수별 양의 gain에 대해
  `min(2, gain/20) × (1−기존지식/100)` 증가하고 0~100으로 제한한다.
  여러 선수 관찰은 여러 실제 관찰이며, 이미 완전 파악한 자체 선수는 추가 경험을 주지 않는다.
- 개인 동시 지역 수는 `1 + floor((스카우팅 전문능력 + min(30, 평균지역지식×0.3))/45)`,
  최대 3이다. 지역 전문성·다른 지역의 상대적 전문성·개인 능력을 함께 사용해
  담당자를 배분하며 이미 배정된 지역당 적합도 10을 낮춰 부하를 분산한다.
  해외 담당자가 없으면 해당 운영 배정은 제외한다.
  팀의 시설/인력에 따른 기존 조사량·지역 슬롯·현금 유동성 상한도 계속 적용한다.
- 기존 부서/시설 관찰 효과에 배정 직원의 지역 지식을 한계효용 가중
  (1, 0.28, 0.16, 이후 0.1)으로 최대 15% 보강한다. 최종 효과는 0.8~1.65다.
  기록 없는 조직은 기존 효과와 정확히 같으며 사용자/AI가 같은 계산을 쓴다.
  이 수치는 명시적인 가상 시뮬레이션 정책이지 실제 업계 통계가 아니다.
- 개인 지식은 이직·FA·은퇴·저장 후에도 본인에 남는다. 이전 고용주는 직원이
  떠난 뒤 그 개인 효과를 사용하지 못하지만 이미 작성된 선수 보고서는 유지한다.
- 수동/AI 능동 조사 실패는 해당 구단 현금·보고서·개인 지식·운영 이력과
  관련 영입 후보 관찰 상태를 함께 복원한다. UI는 기록된 지역 경험을 설명하되
  고용 전 숨은 능력치를 노출하지 않는다. 지역 지식 자동 감쇠나 수동 담당 편집은
  이번 구현에서 추가하지 않는다.
### 은퇴 판단의 구현 범위 (2026-10-02)

- 매년 고용/자유 스태프에 동일한 가상 판단 모델을 적용한다. 최소 62세,
  기본 확률 0.12 + 초과 나이당 0.04 + 확인된 경력년당 0.004(최대 0.08)
  + (50−활동 동기)×0.002 + 확인된 미고용년당 0.025, 최종 0~1 제한.
  실제 업계 은퇴 통계나 고정 은퇴 예고가 아니다.
- 활동 동기는 기존 개인 ambition을 기준으로 최근 3년 실제 현장 시리즈
  승률의 중립점(50%) 대비 ±20, 확인된 미고용년당 −8을 반영해 0~100으로
  제한한다. 표본이 없으면 성과 효과는 0이며 숨은 능력치를 읽지 않는다.
- 경력은 저장된 고용 구간/현장 참여 연도의 합집합이다. 과거 저장에 없는
  근속·승패·미고용 기간을 발명하지 않는다. 현장 시리즈의 팀 승패는 개인의
  인과적 공로 점수가 아니다. 비공식 연습/리플레이/행정 몰수는 현장 실적으로
  기록하지 않는다.
- 공식전 시작 시 현장 인원의 ID/직무를 스냅샷으로 보존하고 결과 확정 때
  시즌·소속·직무별 이력을 집계한다. 중도 퇴사와 시즌 중 이직은 이전 소속의
  기록을 새 고용주에게 이전하지 않는다. 이전 버전 미완료 경기에는 소급하지 않는다.
- 연간 중복 노화/검토를 차단한다. 은퇴는 시스템 전용 공통 계약 명령을 통해
  고용/FA 목록에서 동일 인물을 은퇴 목록으로 이동하고 근거를 이력에 남긴다.
  사용자 후임 선임은 자동화하지 않으며 메시지에서 근거와 공석을 설명한다.
- 고용 전 정확한 능력치는 숨기고 평판/인터뷰/경력/성과로 평가한다.
