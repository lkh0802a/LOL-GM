# LOL GM — 사무국 / 구조개편 / 등록 행정 규칙

상태: **확정 규칙 문서**
기준일: 2026-09-28

## 규정 집행
- 명백히 불가능한 행위는 공통 검증에서 사전 차단.
- 서류/기한/행정 요건처럼 사후 심사가 자연스러운 위반은 제출 후 사무국 판정 가능.
- 사용자와 AI 구단은 같은 판정 경로 사용.

## 로스터/재정 위반
- 로스터 미제출/불완전 제출 처리는 각 대회·지역 사무국 규정.
- 샐러리·재정 규정 위반 제재도 해당 리그 규정.

## 규정 변경
- 구단은 규정 변경에 투표/의견 제시 가능.
- 최종 규정 권한은 사무국.
- 사무국은 매 오프시즌 규정을 검토할 수 있음.
- 변경은 충분한 이유, 사전 공지, 다음 시즌 적용을 기본으로 함.

## 로컬 취득 조건
- 비출신지역 로컬 취득 조건은 지역 사무국+국제 사무국 협상 엔진으로 합의.
- 조건 변경 시 이미 진행 중인 선수는 구규칙, 새로 진행하는 선수부터 신규칙 적용.
- 취득했지만 비활성인 로컬 자격에는 유효기간 존재.

## 합병/분할
- 지역 합병/분할 시 선수는 후속 지역 로컬 중 하나 선택.
- 구조개편 때문에 기존 계약 선수가 비로컬이 되면 현재 계약 종료까지 레거시 로컬 인정.

## 구단 연속성
- 구조개편 이벤트가 어떤 구단을 동일 구단으로 존속시키는지 명시.
- 일부 선수/스태프 계약은 구조개편 상황에 따라 재협상 가능.
- 팀 역사 승계는 successor club 관계로 처리.
- 일반 자발적 타지역 이전은 기존 구단 해체+새 지역 신규 구단 창단만 허용.

## 2군/Academy
- 2군이 모구단 때문에 승격 불가하면 다음 자격 있는 독립팀이 승격권 승계.
- 2군/Academy 국제대회 참가 여부는 대회별 규정.
- Academy 글로벌 연령 제한 없음.
- 베테랑 Academy 등록은 지역 사무국 규정.
- 국제대회 중 2군 선수의 1군 훈련 합류 금지.
