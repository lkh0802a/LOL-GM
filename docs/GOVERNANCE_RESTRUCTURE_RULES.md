# LOL GM — 사무국 / 구조개편 / 등록 행정 규칙

상태: **확정 규칙 문서**
기준일: 2026-09-28

## 규정 집행
- 명백히 불가능한 행위는 공통 검증에서 사전 차단.
- 서류/기한/행정 요건처럼 사후 심사가 자연스러운 위반은 제출 후 사무국 판정 가능.
- 사용자와 AI 구단은 같은 판정 경로 사용.

## 로스터/재정 위반
- 로스터 미제출/불완전 제출 처리는 각 대회·지역 사무국 규정.
- 샐러리·재정 규정 위반 제재도 해당 리그 규정.

## 규정 변경
- 구단은 규정 변경에 투표/의견 제시 가능.
- **2026-11-01 최신 승인 해석:** 구단의 투표·공동 건의·협의는 의견수렴 절차이며 **자동 거부권/사무국 정당한 정책에 대한 구단 의무 표결권이 아니다**. 지역 내부 운영권은 지역사무국에, 국제대회 진출권/다지역 권리는 국제사무국 경영진에, 국제 체제 대개편·지역사무국 통폐합·대규모 재정은 **국제사무국 혼합 이사회 승인**에 둔다. 중앙 이사회 의결권 과반과 지역 대표 참여는 [#324](https://github.com/lkh0802a/LOL-GM/issues/324) 및 [Draft PR #325](https://github.com/lkh0802a/LOL-GM/pull/325)의 승인 설계이고 **아직 게임 코드에 구현·병합된 것은 아니다**. 기존 사전 공표·다음 시즌 효력·과거 결과 불변 규칙은 유지. [효력표](POLICY_PRECEDENCE_2026_11_01.md) 참조.
- 최종 규정 권한은 사무국.
- 사무국은 매 오프시즌 규정을 검토할 수 있음.
- 변경은 충분한 이유, 사전 공지, 다음 시즌 적용을 기본으로 함.

## 로컬 취득 조건
- 비출신지역 로컬 취득 조건은 지역 사무국+국제 사무국 협상 엔진으로 합의.
- 조건 변경 시 이미 진행 중인 선수는 구규칙, 새로 진행하는 선수부터 신규칙 적용.
- 취득했지만 비활성인 로컬 자격에는 유효기간 존재.

## 합병/분할
- 지역 합병/분할 시 선수는 후속 지역 로컬 중 하나 선택.
- 구조개편 때문에 기존 계약 선수가 비로컬이 되면 현재 계약 종료까지 레거시 로컬 인정.

## 구단 연속성
- 구조개편 이벤트가 어떤 구단을 동일 구단으로 존속시키는지 명시.
- 일부 선수/스태프 계약은 구조개편 상황에 따라 재협상 가능.
- 팀 역사 승계는 successor club 관계로 처리.
- 일반 자발적 타지역 이전은 기존 구단 해체+새 지역 신규 구단 창단만 허용.

## 2군/Academy
- **모구단 산하 2군은 승격하거나 승격 결정전에 참가할 수 없다.** 2군 성적·순위 때문에 **다음 독립 구단에 승격권을 자동 승계시키지 않는다**. 실제 승강은 지역별 사전 공표 규정과 적법한 **승강 결정전** 결과에 따르며, 부별 소속 변경은 차기 시즌부터 적용한다. [#234 최신 확정](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6460306910), [승강 결정전 승인](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6459532093).
- 2군/Academy 국제대회 참가 여부는 대회별 규정.
- Academy 글로벌 연령 제한 없음.
- 베테랑 Academy 등록은 지역 사무국 규정.
- 국제대회 중 2군 선수의 1군 훈련 합류 금지.
