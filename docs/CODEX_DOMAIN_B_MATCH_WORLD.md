- **자료 정책:** 확인 가능한 Riot 패치 고정 원본/검토된 보조 근거와 내부 시뮬레이션 가정을 명시. 경험적 밸런스/프로 경기 캘리브레이션에는 **공식 조직 대회 데이터만 사용**, 솔로랭크 승률 대체 금지. 원자료 누락은 명시하고 임의 스킬 숫자·확정 효과/승률·가격 만들지 않음.
- **실제 소비:** 데이터 갱신 → 출전 자격/밴픽/선수 연습·AI 메타 준비 → 경기 속성/스킬 효과/상점·기록 → 저장 당시 패치. 패치 수치가 데이터 테이블만 바꾸고 엔진에서 사용되지 않으면 미완료.
- **반례:** 신챔은 프로 해금 전 훈련 가능해도 공식 밴픽 금지, 임시 글로벌 밴은 미시작 세트만 적용; 잘못된 고유 장비 중첩, 금지 조합/빈 슬롯/미보유 골드, 패치 이후 기존 역사 기록 소급 변경.
- **완료:** 챔피언/시스템 스냅샷 검증+단일 스킬/아이템/룬 소비 fixture+패치 전후 통제 동일시드 비교. 기존 `validate:champions`/`validate:systems` 및 관련 acceptance를 실제 실행.

- **감독 권한:** 사용자가 담당 팀의 선택을 직접 하면 AI가 해당 수동 결정을 덮지 않음. 수동 입력의 유효하지 않은 champion/순서/선수 숙련·포지션은 **사전 안내 + 안전 거절**, 이미 선택 완료한 세트/과거 기록 소급 수정 금지.
- **AI 판단:** 선수 챔피언 풀/역할/숙련, 팀 전술/대회·패치·상대 **합법 공개 관측**, 조합 역할/교전·포킹·사이드 운영, Fearless 잔여 풀을 근거로 선택. 적의 비공개 마스터리/미래 픽/비공개 스크림을 직접 읽지 않음.
- **First Selection:** 선택권 보유자·상대가 남은 선택권을 행사하는 규칙과 팀 상황·패치·픽 순서 가치 기록. 고정 선호 숫자/랜덤 설명으로 실제 근거를 위장하지 않는다.
- **반례:** 블루/레드 뒤집기, 똑같은 챔피언 중복/글로벌 밴·Fearless 재선택, Bo3/Bo5 중단/재개/선후픽 변경, 마지막 밴 이후 패치 적용 시도, 이전 세트의 금지 챔피언으로 AI 선택/사용자 UI 버튼 활성.
- **완료:** 하나의 `draftSession`에서 합법성 검증→AI/사용자 픽→공식 기록→시리즈 다음 세트 금지 풀→저장/복원·당시 수동 이유 재검토까지 연결. 실제 `draft-history`, `draft-preparation`, `first-selection` 집중 검사.

- **자원/동작:** 실제 경기 tick/상태 중 사용 가능한 선수 10인, 위치·거리·이동·부활·귀환·포지션/측면 진입, HP/방어/관통·마나/에너지·공격/스킬 재사용, 시야·마지막 관측/정보 부족, 라인 웨이브/CS 막타·XP 범위, 정글 캠프 시간/보상·동선, 팀·개인 골드/구매/인벤토리.
- **구매:** 현재 자동 구매/실제 `item-purchases.js` 구매 장부가 있으므로 '상점 기능 없음'이라고 쓰지 않는다. 귀환/상점 접근·실제 골드 지출·구매 시간/재료·슬롯/unique 제한이 경기 능력에 연동되는지가 남은 C안 핵심.
- **스킬:** 패치 원자료에 근거한 유효 대상·사거리/자원·재사용/대상 챔피언·대미지 타입/피해 계산/보호막·회복·치감/CC·개별 스킬 조건·소환사 주문과 아이템/룬 상호작용. '모든 챔피언 173개' 일괄 재작성보다 원본 확보·공통 효과 primitive → 검증된 챔피언 수직 단위 확대. 겉으로 시전 로그만 남기고 실제 전투에 효과가 없으면 불합격.
- **전투:** 스킬 발동 → 대상/방어/시야/자원/시각 제약 검증 → 실제 상태 변경 → 교전 지속/후퇴/오브젝트 합류·회복/사망·부활 → 골드/XP/포탑/바론·용/승패·MVP·통계. 환경요인과 선수 세부 속성/전술 지시는 실제 가능 행동/오류 확률로 연결.
- **종료:** 스코어/골드시간 초과로 임의 승자를 만들지 않고 넥서스 파괴/실제 규정상 행정 몰수로 판정. 계산 안전 상한/막힌 시뮬레이션에서 *성공한 공식 결과를 조작 생성*하지 않음.
- **반례:** CS 공급보다 많은 획득, 타격 없는데 골드/XP 증가, 이동·사거리/마나·쿨다운 부정 행동, 아이템 원장 이중 차감, 동시 넥서스/바론 스틸/킬 보상, 회복/보호막 순서, 선수 복귀 불가능 중 출전, 약 70분 이후 정상 경기/180분 계산 안전 경계(기존 승인 수치 유지).
- **완료:** 실제 행동 로그·자원·골드 원장·승패/개인·팀 지표의 인과와 동일 시드 재현, 저장 당시 게임 결과/리플레이·AI 전술 데이터 연동, 스킬/전투/오브젝트·구매 관련 acceptance. 출력 예쁘게 표현만 하는 접근 금지.

## B4. 경기 전술 AI · 라인 운영 · 오브젝트/변형 전략

- **담당:** Stage 7·8, #235·#233·#238·#236.
- **코드:** `meta-tactics.js`, `meta-opponent.js`, `meta-opponent-draft.js`, `macro-picks.js`, `engine.js`, `player-relations.js`, `draft-preparation.js`, `ui-opponent-report.js`, `ui-draft-preparation.js`.
- **의사결정:** 경기 전에 공개 자료에서 짠 운영 목표(라인 주도/정글 침투/오브젝트/보호·포킹/사이드·느린 전개)를 당시 선수 실력/커뮤니케이션/챔피언/위치·시야/웨이브·스킬 가용성에서 **실제 가능한 행동**으로 내려보내고 실행 실패를 허용한다.
- **AI 공정성:** 사용자 팀 감독도 자신의 선수와 공개 상대 정보를 사용, AI는 타 구단의 확정 미래 전술·숨은 위치/쿨다운/의료/잠재력을 알 수 없음. 공격/수비 방향·한타 참여/회피 근거는 경기 로그와 사용자 분석 화면에서 확인 가능.
- **Bo 적응:** 이미 끝난 세트에서 관측된 픽/운영/교전·조합만 다음 세트에 반영; 져서 강제 보정 승률을 주지 않음. 상대가 숨겨둔 새 전략을 경기 시작 전에 AI가 사전 인지하지 않음.
- **반례:** 상대 비공개 속성을 바꾸고 공개 기록을 고정했을 때 AI 판단이 바뀌는지; 오브젝트 참여 불가 위치/사망 선수에게 지시, 실전보다 스크림 전술 유출, 감독 지시를 항상 100% 성공 처리.
- **완료:** 실제 준비/지시→판단 근거→경기 행동→공식 기록/시리즈 적응까지 확인; 능력·전술·조합·패치와 원인 연결 없는 별도 효과점수로 통계 생성 금지.

- **데이터·행동:** 챔피언/아이템/룬/시스템의 실제 old→new 변동, 선수 숙련/훈련 재적응, 합법 공개 메타 자료, AI 밴픽/전투 아이템·룬 소비와 경기 변화. 승률을 맞추기 위한 고정 강제 버프/임의 패치 진단 도입 금지.
- **결정론:** `patch-content.js`의 난수 comparator 정렬 위험은 #246에서 선제 수정. 같은 시드/패치·원본 snapshot, 후보/메타 결정이 런타임/시드 변경 없이 재현.
- **반례:** 같은 날짜 이중 발효, 국제전 종료 전 조기 적용, 진행 중 시리즈/이미 시작한 경기에 수치 소급, 버그성 글로벌 프로 밴 또는 가상 기술 장애가 생성되지 않음, 신챔 자료 부족, 패치 예정·실제 일정 충돌.
- **완료:** 시점·규칙/당시 스냅샷·연습/밴픽/경기 소비·분석/표본·세이브를 이어서 검증.

- **과거 replay:** `replayGame(db,rec,g)`가 현재 `db.teams`/`db.players`로 역사 세트를 다시 계산할 수 있다. 따라서 기록에 충분한 당시 선수 상태/패치/전술/시드·엔진 버전이 없으면 '완전 재현'이라 표현하지 않고 저장된 당시 공개 경기 결과를 조회. 현재 능력치로 *과거 공식 결과를 덮어쓰는 것은 절대 금지*. 관련 #249.
