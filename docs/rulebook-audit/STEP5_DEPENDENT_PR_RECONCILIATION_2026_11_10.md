## 의미 비교 결과와 보존

1. **#313 vs COMP-004:** 1~N부·적격 실제 하위 부의 존재와 정원을 전제로 사무국의 적법 행정 이동, 매각, 해체를 처리한다. 구형 R01D는 당시에 다른 **동급** 2부 임의 재배치를 폐기한 것; 2026-10-28 #234는 실재하는 **하위 부** 행정적 이동을 더해 승인하였다. 이 후속은 현재 COMP-004에 반영되어 있으므로, 옛 R01D 문장만 보고 역변경하는 것은 오류다.
2. **#320/#327 vs CAL/TRANS:** 세계 공통 선수시장 개장일·28일, 선수 FA의 연중 적법 계약과 시즌 중 지역 이적창의 독립성, 7일·14일 별도 독점 기간 폐지, 시장 중 4종 구단 실경기 금지와 국가대표 대회 정상 운영의 구분을 우선한다. 실제 코드 전환의 현재 main 반영 여부와 레거시 `exclusive` 상태 명칭은 각자 실제 실행·계약 의미를 검증해야 한다.
3. **#328 법률/제품 구별:** 법률 문서에 코덱스 진행 상태·UI 문구·과거 PR을 주입하지 않으며, 원본 역사 추적은 감사 대장에 둔다. 문서의 세계법 124개 ID 자체를 곧바로 실제 Rust/TS 게임이 수용했다는 뜻으로 표시하지 않는다.
4. **현재 mergeable=true의 한계:** GitHub의 당시 병합 가능 상태만 확인한 것이며 최종 리뷰/보호 요구·정확 새 HEAD 검사·순차 병합 후 회귀 성공을 인증하지 않는다. 세 종속 Draft PR과 정본 PR은 각각 별도 병합 결정이 필요하며, 문서 반영만으로 코드가 업데이트되지 않는다.

## 남은 구체적 5단계 완료 조건

- 각 PR의 정확 최신 HEAD와 요구 CI/Training·추가 필수 회귀·리뷰/보호규칙을 재확인하고, 순차 병합 시 같은 파일·규칙의 충돌과 마지막 `main` 전체 검사 결과를 검증한다.
- 특히 #320의 실제 월드 시계·협상·로스터 데이터·세이브와 #313의 지역 공식/국제 시드·등록 정보가 현행 헌장의 **같은 실제 시점·원장·권한**을 사용하도록 수직 엔진을 실행해 확인한다.
- 자동 병합·배포·'최종 정본 확정' 선언은 하지 않았다. 모든 이슈/PR 승인 효력과 초기 실제 법규 발효 원장이 검증되기 전에는 `STAGE5_PARTIAL`을 유지한다.
