# PLAYER-011·PLAYER-012·UI-005 — 선수 배경·공급과 스카우팅 원문 부분 대조

| 조항 | 확인한 출처·범위 | 경계 |
|---|---|---|
| [PLAYER-011](../rulebook/40-PLAYERS.md) | [#311 사용자 최종 결정](https://github.com/lkh0802a/LOL-GM/issues/311)은 정식 3부 이상의 공식 리그는 실제 경기·순위·승강을 실행하고, 별도의 미시뮬레이션 아마추어 배경에서 가짜 공식 결과를 만들지 않도록 구분한다. | 배경 설정은 실제로 열린 공식 경기나 증빙 없는 대진·전적으로 바뀌지 않는다. [#251 구단 분류 최종 정정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6461053117)에 따라 고정·배타적 아마추어 구단 클래스나 새 프로 등급을 임의로 만들지 않는다. |
| [PLAYER-012](../rulebook/40-PLAYERS.md) | [#251 국가 생태계·수요 기반 스카우팅 본문](https://github.com/lkh0802a/LOL-GM/issues/251)은 국가별 게임/랭크 인구와 경제·팬덤·노출·육성의 시간차를 다루고, 필요하지 않은 완전 선수 엔터티의 대량 생성을 금지한다. | 리그 없는 국가 선수를 배제하거나 국적 자체에 고정 잠재력 상한·버프를 두지 않는다. 인구에 따른 발견 기회와 선수 개인 실력을 구분한다. |
| [UI-005](../rulebook/80-EXPERIENCE.md) | [#251의 스카우팅 축소 후속 결정](https://github.com/lkh0802a/LOL-GM/issues/251)은 매주 신규 유망주 보고·특별 발견 알림·수집 배지를 철회하고 실제 로스터 수요·시장 변화에 따른 후보 비교로 정리한다. | 수동 검색과 실제 유료 조사/계약 최종 선택은 유지한다. 정기 보고 섹션이 같은 이슈의 역사 본문에 남아 있어도 최신 철회보다 우선하지 않는다. |

위 본문과 조항의 범위 비교는 3개 관련 원문의 부분 대조다. 모든 후속 댓글·PR의 최종 효력, 장기 세계 엔진·UI·실기기·CI 검증 완료를 뜻하지 않는다.
