## M206 최신 효력 사슬 (M206C는 제출 문자열로만 보존)

1. **직접 사용자 최신 수정 → 대상:** 2026-10-21 사용자가 “구버전 저장은 생각하지마 그건 다 소급적용해”라고 지정하였다. 이 발언은 옛 저장 *파일 포맷*의 별도 호환 부담을 제거하고 최신 확정 **게임 모델/규칙을 현행 세계 상태와 확인 가능한 기존 이력에 적용**하라는 것이다.
2. **이후 폼에서 M206C 제출 → 최종:** 해당 선택은 같은 날 앞서 기록된 직접 맞춤 수정 M206D를 철회하겠다는 별도 명시가 없어 M206D가 우선한다. 유효 승인 **M206D**, 출처 변경 전 원문 `M206C`는 변경 이력으로 남긴다.
3. **역사적 사실/채무 경계:** 당시 실제로 없었던 경기·조합/이적/육성 사실을 발명하거나, 이미 지급한 상금을 다시 송금하거나, 계약이 없는 과거 셀온·보상 채무를 생성하지 않는다. 과거 기록을 **현재 평가의 근거로 재사용**하는 것과 이미 확정된 게임 내 계약·세계 사실을 **뒤집는 법률 소급 효력**은 다르다. CORE-009·011·012와 현행 저장 원본의 정합성을 지킨다.
4. **제품·저장 게이트:** 구세대 포맷 호환 **필수 아님**. 지금 지원하는 저장 슬롯·이어서 하기·복원·원자성·역사·채무·경기 결과 보호는 계속 필수. 이후 출시 버전부터 지원 범위를 명시할 수 있다는 제품 지침이 과거 폐기된 포맷을 영구 지원할 명령은 아니다.

## 실규범 / 수용 조건의 구별

- M199~M200은 국제 참가·공식 주최 일정 변경의 적법성이고 M201~M205는 사용 권한·정보·제품 조작 수용. 공식 외부 이벤트의 사익으로 이미 적법한 공식 캘린더 경기를 기권 처리할 수 없다.
- M207~M212의 장기 경제·선수 실력·짝지은 조건 실험은 **제품·QA 수용 조건**이다. 정적 문서/본문만으로 실제 세계 엔진의 장기 회귀·성능 검증 완료 선언 금지. M212C의 미확정 금전·MMR 임계 수치에 대한 후속 사용자 승인 조건 유지.
- 이번 14개에서 새 세계법 권한·지급채무·영구 수치의 승인이 없는 곳에 **새 조문이나 새 자동 집행 정책을 만들어내지 않는다**. 단, 정본화 작업은 법적 공백이 직접 확인되면 신규 조문 신설을 허용한다.
