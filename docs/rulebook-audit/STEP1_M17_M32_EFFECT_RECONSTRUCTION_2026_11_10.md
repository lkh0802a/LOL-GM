# 1단계 — M17~M32 후속 승인과 정본 효과 재구성 (2026-11-10)

> **비규범 효력 감사 / PARTIAL_FINALITY.** [#251 M17~M32 사용자 직접 최종 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6290080827)의 **16개 전부 C**를 실제 문장별로 검토했다. 특히 M26은 당시 추천 **B가 아니라 사용자 직접 선택 C**라는 변경 효과를 유지한다. 이는 기존 [M01~M16](STEP1_M01_M16_EFFECT_RECONSTRUCTION_2026_11_10.md)을 후속 심화한 승인이고 **독립 인격 엔진·임의 계수·새 게임 모드**를 16개 추가하라는 뜻이 아니다. 원문 당시 선택 확인·현재 규정과의 의미적 대조와 **모든 후속 PR/대화 최신 효력 전수 인증**을 구분한다.

## 확인한 승인 우선순위

1. [M01~M16 초기 직접 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6289688904)과 M17~M32의 실제 후속 구체화. M01~M16을 소멸시키거나 동일 효과를 중복 생성하지 않는다.
2. [M33~M48](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6290271107) 및 [M49~M150](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6312021889)도 앞선 결정을 별도 독립 시스템으로 복제하지 않고, 실제 기존 세계 사건/판단/기록과 연결하는 방향을 반복한다.
3. 이 범위에서는 이 16개를 일괄 철회한 증거를 확인하지 못했다. 하지만 #251 원문과 지정 후속 설명만 확인한 것이므로 **이후 전체 이슈·PR의 최종효력 독립 확정**은 아직 아니다.

## 확인 범위와 결과의 구별

- **원본 당시 직접 승인 확인:** 16개(M17~M32). **B→C 해석 교정:** M26은 C를 유지. M01~M16 원문과 같이 사용자가 직접 선택했다는 점을 원본 댓글에서 확인했다.
- **현행 정본 구체성 보완:** PLAYER-014(M18), MATCH-009(M26), BIZ-012(M30), BIZ-007(M31), UI-007(M24·M27). 각 항목의 핵심 효과를 **기존 규범·제품 문서에 통합**하며 세계 조문 수는 늘리지 않았다.
- **새 상한·가중치·실제 AI 기능 추가:** 없음. 원문에 확정되지 않은 능력치 개수, 학습률, 전략 재귀 깊이, 결과 보정 계수를 신설하지 않았다.
- **전체 후속 결정 최신 효력 100% 인증:** **아직 아님**. 이 파일의 '반영'은 해당 승인과 지정 후속 기록을 실제 현재 문구에 대조했다는 의미이다.
