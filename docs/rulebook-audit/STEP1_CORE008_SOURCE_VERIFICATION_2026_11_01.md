# CORE-008 승인 원문 대조 (2026-11-01)

[CORE-008](../rulebook/00-CORE.md)은 상대의 비공개 자료·실제 의료/능력·잠재력·내부 MMR·비공개 스크림·미래 경기 결과를 적법한 관측 없이 제공하지 않고 예측과 확정 사실을 구별한다.

- [#238 이슈 본문](https://github.com/lkh0802a/LOL-GM/issues/238)은 실제 숨은 속성, 공개 경기·경력·계약, 팀 소유 관측과 시점, 불확실성을 가진 추정치를 분리한다. 타 구단 비공개 스크림·선수 상태·미관측 위치·미래 경기·타 감독 비밀 자료 누출을 금지한다. 실제 출처의 표본·시점과 오차를 유지해야 하며, 과거 관측과 새로운 정보를 구분한다.
- [#280 이슈 본문](https://github.com/lkh0802a/LOL-GM/issues/280)은 사용자와 AI의 숨은 값 접근 금지 및 실제 관측·불확실성·당시 기록에 기반한 경기 전후 판단을 요구한다. 관측에 따른 추정이 결과의 확정 정보로 바뀌거나 사후 정보가 과거 판단의 원인이 되어서는 안 된다.
- 개인에게 정당한 자신의 정보나 실제 공개 경기 기록까지 일률적으로 숨기라는 뜻은 아니다. 어느 관측이 합법적인지는 선수·팀·담당자의 실제 권한과 시점에 따른다. 이 원문 대조는 구현 완성·전체 승인/철회 이력 최종 판정을 뜻하지 않는다.
