## 증거·우선순위 규칙

- `CONFIRMED_CURRENT`: 실제 사용자 최종 선택과 대상/발효 범위의 후속 정정이 추적되고 현재 위치·예외를 확인함.
- `SUPERSEDED` / `REVOKED`: 원래 승인 내역은 역사로 보존, 최신의 명시적 수정/철회 효과만 현행화. 부분 철회는 생존 부분을 분리.
- `CONDITIONAL`: 특정 시즌/대회/관할/적법한 제정 사건에만 효력. 최초 세계 수치를 영구 고정하지 않음.
- `IMPLEMENTATION_ONLY`: 기술 사양·테스트·안내 요구, 상위 법률로 승격 금지.
- `PARTIAL_FINALITY`: 원문/일부 후속 원문과 현재 정본 관계는 직접 대조했지만 모든 후속 결정·PR 심사가 끝나지 않은 상태.
- `BLOCKED_SOURCE` / `BLOCKED_DECISION`: 직접 출처가 없거나 실제 사용자 정책 선택이 없어 현 시점에 최종 판정을 내릴 수 없는 경우. 출처 누락을 승인 취소로 추정하지 않음.

## 실제 작업 순서·다음 시작점

1. **1단계 역사 선택 의미 대조 401건:** M01~M96의 6개 배치와 **M97~M112, M113~M128, M129~M150, M151~M166, M167~M182, M183~M198, M199~M212**의 7개 추가 배치에서 #251 당시 사용자가 선택한 내용을 지정된 후속 설명과 현행 규범·제품 위치에 연결했다. M01~M212 **212개**, 최초 1~30 **30개**, R01~R21 **21개**, R2/57~86/87~116/117~146의 네 묶음 **120개**, R4 비연속 **18개**를 더해 역사적 선택 **401행 전체의 당시 선택·지정 후속 설명·현행 권위 위치를 부분 대조**했다. 그러나 모든 나중 결정·이슈·PR 리뷰·대화의 후속 효과까지 각각 인증한 **401건의 최신 확정 효력**을 뜻하지 않는다. 승인 효력 전수 감사 게이트는 계속 열려 있다.
2. **실제 내용 수정:** M49~M64 관전·하이라이트 데이터 원본(UI-007), M65~M80 밴픽 보조(UI-008), M81~M96 스크림 추천·후속 피드백(UI-007·008), M97~M112 스카우팅 근거·협상(UI-005·004) 보완. **R01D→#234의 후속 효력 사슬**을 다시 확인해 기존 COMP-004의 적격한 실제 하위 부 행정 이동/매각·해체가 유효함을 확인. 일시적으로 옛 R01D만 근거로 적용한 이동 전면 금지 수정은 철회하고 후속 규칙·검사를 복원. **세계법 조문 신설 0개**이지만 필요하면 신설 가능. 수정된 실제 엔진·현금 원장/매각 동작까지 검증한 것은 아니다.
3. **1단계 잔여:** **401개 모든 역사적 선택 행에 대한 다른 이슈·PR/리뷰·원대화 후속 최신 효력 사슬 전수 검증**. #251 밖의 2026-11-01 이후 결정과 미수록 권리/예외·원문 접근 차단을 개별 추적하며, 당초 401개 당시 선택의 부분 대조를 전수 인증으로 승격하지 않는다. 사용자 의사결정이 필요한 미정 금전·보상 숫자는 임의 확정하지 않으며 `BLOCKED_SOURCE`(CORE-007·TRANS-011 원대화 전문) 유지.
