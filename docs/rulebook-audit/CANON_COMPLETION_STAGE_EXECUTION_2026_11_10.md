## 목적 — '모으기'가 아니라 '최신 효력의 재구성'

**입력:** 원래 사용자 결정과 이후 수정·철회·조건부 승인, 옛 이슈/PR의 근거·구현·반례를 구분한 기록.  
**중간 산출:** 각 결정마다 `원본 선택 → 나중 승인/철회 → 남은 법적 효과 → 적용 주체·시점 → 현행 정본 또는 시행/제품 문서 위치 → 검증 사례`를 명시하는 효력 사슬.  
**최종 산출:** 한 개의 규범적 세계 헌장, 별도의 가변 시행 규정·제품 UI/구현 수용 계약, 역사적 승인의 추적 가능한 감사 대장. 과거 PR 문구·과거 테스트 값·대화 표현을 정본 본문으로 단순 복사하지 않는다.

## 증거·우선순위 규칙

- `CONFIRMED_CURRENT`: 실제 사용자 최종 선택과 대상/발효 범위의 후속 정정이 추적되고 현재 위치·예외를 확인함.
- `SUPERSEDED` / `REVOKED`: 원래 승인 내역은 역사로 보존, 최신의 명시적 수정/철회 효과만 현행화. 부분 철회는 생존 부분을 분리.
- `CONDITIONAL`: 특정 시즌/대회/관할/적법한 제정 사건에만 효력. 최초 세계 수치를 영구 고정하지 않음.
- `IMPLEMENTATION_ONLY`: 기술 사양·테스트·안내 요구, 상위 법률로 승격 금지.
- `PARTIAL_FINALITY`: 원문/일부 후속 원문과 현재 정본 관계는 직접 대조했지만 모든 후속 결정·PR 심사가 끝나지 않은 상태.
- `BLOCKED_SOURCE` / `BLOCKED_DECISION`: 직접 출처가 없거나 실제 사용자 정책 선택이 없어 현 시점에 최종 판정을 내릴 수 없는 경우. 출처 누락을 승인 취소로 추정하지 않음.

## 실제 작업 순서·다음 시작점

2. **다음 효력 묶음:** #251 **M33~M48 → M49~M150 → M151~M212**, 초기/기타 R 선택. 이후 후속 타 이슈의 직접 결정 사슬과 기존 PR 본문·리뷰 중 정책 효과를 교차 대조. 각 묶음을 **자료 수집 수량·의미 대조 건수·최신 효력 인증 건수**로 나눠 보고한다.
3. 단계 1에서 새로운 권리·금지 누락이 확인되면 그 시점에 해당 기존 정본 조항/적법 시행 규정·제품 명세를 수정한다. 아직 생존 여부가 불확실한 추천이나 테스트 기본값은 임의로 옮기지 않는다.
4. 1단계 전체가 완결되기 전에 2~7단계의 현재 문서 완성도를 '**최종 완료**'로 변경하지 않는다. 다만 발견한 실질 오류/검사 차단은 작은 커밋으로 고치고 정확 HEAD를 검사한다.
