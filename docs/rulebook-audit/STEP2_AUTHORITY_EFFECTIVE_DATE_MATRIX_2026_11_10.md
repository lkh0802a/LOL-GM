## 선행 조건·효력 검증 규칙

**법규 판정은 제안 → 심의/승인 → 공표 → 시행 → 개별 행위 → 원장 확정을 서로 다른 시점·주체로 보아야 한다.** 특히 `approved=true` 또는 설계 파일에 수치가 존재한다는 사실만으로 유효한 규정이나 실제 계약 채무를 발생시켜서는 안 된다. 정본의 상위 권한·금지와 각 세계 내부 실제 제정 규정이 충돌하면 상위 헌장을 우선하고, 이미 확정된 과거 사건은 당시 유효했던 규정과 원장에 귀속한다.

- **승인 경계:** 국제사무국 경영진의 일반 운영·국제 참가권 관할, 국제 이사회의 중대 재편, 지역사무국의 관할 내 지역 형식, 국가협회의 대표팀 운영/선수 선발, 선수 본인의 참가 의사와 감독의 출전·전술을 **서로 대체할 수 없는 법적 행위**로 분리.
- **세계 외부/내부:** 124개 세계법 조항이 적용되는 것과 지역·대회별 가변 시행 규정이 **실제 제정돼 존재**하는 것은 별개. 국적 귀속·전향, 국가대표 명단, 소유·경영·매각, 재정/이적창은 해당 구체 사건의 사실·법적 책임을 적법한 원장에서 확인.
- **잔여 명시 차단:** 현재 코드/시뮬레이터의 각 관할 최초 시즌 프리셋이 게임 시작 시 **권한 가진 기관에 의해 제정·공표·발효된 법규 객체로 기록되는지** 실제 검사 미완료. 위 행렬의 개별 사례는 `EXPECTED_BY_LAW`인 **정적 판정 기준**이며 테스트가 실행된 `PASS` 아님. 구체 최초 협회·리그 규정·결정·의결 이력 및 대회 시작 시각을 추출하여 확인해야 한다.

## stage 2 판정

**`STAGE2_PARTIAL`**: 상위 조항의 권한·시점/비소급 관계를 15개 시나리오로 정리. **유효한 초기 실제 내부 규정 원장·기관별 발효 기록과 엔진 실행 검증 전까지 미완료.** 새 세계 헌장 법률 조문 수 증설은 필수라고 입증되지 않았으나, 신규 조문을 금지하지 않는다.
