## 이번 실질 검토에서 해소한 오해

1. **통합 선수단 11명:** [기존 확정 운영 문서](../ROSTER_TRANSFER_LOCAL_RULES.md) §5.4에 최소 5+5명보다 1명을 더 확보하는 산하팀 안전망이라는 설명이 있다. 계산 오기로 보아 10명으로 완화하지 않는다. 다만 인력 보유와 공식 등록·긴급 콜업은 별도의 법적 판정이다.
2. **부분 시즌 근속:** 같은 문서 §2는 *실제 유효한 부분 시즌을 시즌 단위 1시즌으로 인정*한다. 근거 없는 최소 등록 일수는 만들지 않는다. 한 **시즌 ID를 여러 번 등록했다는 이유로 두 시즌 이상 누적하지 않는** 계산 경계를 TRANS-014에 명료화했다.
3. **동일 리그 직렬 편성:** [실제 같은 리그 비동시 승인](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6394328655)과 [국제·부별 독립 운용 후속](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6394537279)에 따라 유지. 12팀 더블 RR = 132시리즈, 16팀 = 240시리즈의 실시간·방송 용량을 검사한다. 영구 1개 리그 포맷·기간을 강제하지 않는다.
4. **역사적 LCK 일정 충돌:** [8주/132시리즈 중간안](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6394877897)의 주간 동일 경기수 산술 충돌은 [11주·132시리즈 후속 시안 검증](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6397449540) 및 [14구간 영구 고정 철회](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6437451822)를 고려하지 않고 현행 불변 규정의 모순으로 분류하지 않는다.
5. **최근 직접 정책:** 국가대표 등록 5~6명 허용(초기 기본 7명), 이해충돌 이사의 같은 의석군 적격 임시 대체와 7/9 가결 기준 고정은 최신 사용자 직접 선택으로 각각 NAT-011·GOV-004/012에 기입했다.
6. **월즈 반복 타이브레이크:** 결론이 나올 때까지 반복하는 D-032은 [선행 선택](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6377402894)과 [승자승 보완](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6377687670)을 보존한다. 임의 라운드 상한이나 가상 행정승은 생성하지 않고, 수용성 문제는 실제 경기 일정의 미완료 상태로 진단한다.

## 후속 최신 승인 효력 검증 — 수치의 최초 효력과 법적 변경

- [#311 2026-10-28 사용자 최종 7개 선택 중 1번](https://github.com/lkh0802a/LOL-GM/issues/311)은 **비로컬 최대 2명·선수 등록 정원·시즌 이적 제한 등 현행 수치를 초기 규칙으로** 구별한다. 정본 TRANS-012·013의 기존 표현이 영구 상한으로 오독되지 않도록 v0.17.2에서 정리했고, 직원 7/4/6명의 현행 초기·개정·그랜드파더링도 BIZ-016에 대응시켰다.
- **규범 수정의 범위:** 최초 적용 수치는 유지한다. 이후 적법하게 권한·합의·공표·효력 시각이 성립한 내부 규정만 해당 장래 시즌의 한도를 바꿀 수 있다. 제안만으로 기존 등록·거래·급여·과거 역사를 소급 변경할 수 없다.
- **이번 대조에서 실제 확인한 타 PR 원문 잔여:** #313의 2군 '같은 1부만 금지'와 세계 모든 국제 중계 비중복/비로컬 상한 변경 불가 문구, #320의 **글로벌 통합 시장 중 독립 단기 컵 개최 허용** 문구가 그대로 존재한다. 정본이 잘못됐다며 뒤집지 않고 원래 PR 소유자에게 위 교정 인계 링크로 전달했다.
- 제정·공표·시행된 초기 시행 규정 데이터와 장래 엔진의 실제 세계 버전 판정은 아직 실증되지 않았다. 관련 [수치별 회귀·출처 감사](INITIAL_WORLD_BASELINE_AND_REMAINING_REVIEW_2026_11_08.md) 및 [구현 수용 명세](../GAME_IMPLEMENTATION_ENTRYPOINT.md) §13·15 참조.

## 다음 작업의 차단·인수 경계

- **정본 내부 실질 오류**로 최신 승인 원문을 확인한 경우, 현 PR #328의 해당 조문과 테스트를 직접 교정한다. 단지 별도 구현 PR에 구형 표현이 남았다는 이유로 신규 법률을 만들지 않는다.

- **실제 엔진 기능**은 정본과 별도. Rust 세계·경기 엔진/TypeScript UI 전환, 초기 세계별 시행 규정·첫 시즌 프리셋, 구형 저장 마이그레이션, 장기 시즌/재정·경기력 검증은 실기능 수용 검증 후 완료로 표기한다.
- **종료 선언 금지:** 1~7의 필수 근거·리뷰·정확 SHA·main 병합이 확인되기 전에는 “정본화 완료”, “전체 승인 100% 대조”, “전 엔진 규정 준수”로 기록하지 않는다.
