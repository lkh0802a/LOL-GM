# PLAYER-007 선수 자원과 정보의 경계 — 원문 부분 대조

[PLAYER-007](../rulebook/40-PLAYERS.md)은 공식 경기·스크림·랭크·휴식·이동·의료·계약 의무의 시간/자원과 합법적인 스카우팅 관측을 구분한다.

[#236의 선수 성장·의료 본문](https://github.com/lkh0802a/LOL-GM/issues/236)은 실제 활동·일정·기회비용·피로·회복을 연결하고 동일 활동의 중복 성장이나 수행하지 않은 훈련 보상을 금지한다. 의료·등록·선수 동의와 AI/사용자 동일 규칙을 유지한다. 과거에 폐지한 수동 훈련 포인트/강도를 새로 요구하지 않는다.

[#238의 관측 본문](https://github.com/lkh0802a/LOL-GM/issues/238)은 실제 숨은 상태, 공개 자료, 팀별 관측·시점, 추정과 불확실성을 분리하고 타 구단 비공개 자료와 미래 정보를 정답처럼 노출하지 않도록 한다. [#251의 실제 선택 기록](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6290271107) M37C~M40C도 실제 시간·권한·의료 상태를 지키면서 허구 생활 사고나 보고서 열람만의 성장 보상을 배제한다.

이는 지정된 이슈 본문 및 선택의 부분 비교이며 후속 승인·철회 전수나 실제 의료/스카우팅/장기 세계 구현·CI 완료를 뜻하지 않는다.
