# P01~P10 채택 이후 새로 노출된 교차 경계 (2026-11-12)

> **2026-11-14 현행 효력 우선 기록:** 사용자가 **확정 대회 취소/무기한 연기 및 양 팀 동시 실격·무우승 결승 제도를 폐지**했다. 아래 **R01(취소 Worlds 이후 선발), R02(양측 실격 포함 경계 결정전)**의 당시 제안은 **RESOLVED/SUPERSEDED**로 더 이상 새로운 결정이 필요하지 않다. 현재는 COMP-006·010·012·019, NAT-011, CAL-004의 **정본 v0.18.1**이 우선이다. R03~R07은 별도 시행·법적 세부 검토가 남으며 이 문서의 과거 발견 내용은 승인 기록 이력으로 유지한다.

> **비규범 후속 검토 / NEW_CANDIDATES_NOT_APPROVED.** [승인된 P01~P10](REMAINING_POLICY_AND_CONFLICT_RESOLUTIONS_2026_11_12.md)과 현행 [정본 v0.18.0](../rulebook/README.md)을 바탕으로 추가로 찾아낸 **조건부 규칙 공백 및 실행 위험**을 정리했다. 현재 정본의 확정된 오류 또는 사용자가 이미 폐기한 선택이라고 과장하지 않는다. 아래 R01~R07은 **추가 권고**이며, 앞선 “추천안대로”는 그때 제시된 P01~P10에 대한 승인이다. 이번 후속 후보를 사용자 허가 없이 새로운 세계법으로 만들지 않는다.

## 기술·규범 판정 분리

- **현행 규범으로 이미 대응 가능한 부분:** 확정 계약/돈·일반 라이선스·공식 등록/시간/규정 효력 우선, 실제 없었던 경기·선수·출전·상금 금지, 새 지역 의석 자동 생성 금지. 실제 데이터·엔진에서 실행 검증 필요.
- **추가 선택이 필요한 부분:** R01(취소된 Worlds의 최상위 출전자격 후속 선발), R02(적법 기권과 전원 실출전 원칙의 예외), R03(임대 종료 후 채무·가용성의 계약 기본 조항), R05(미확정 상금의 분쟁 종결 절차). R04·R06·R07은 기존 유효 규정/기관 위임으로 개별 시행 조건을 구체화할 여지가 크다.
- 모든 후보는 2026-11-12 시점 **PROPOSAL_NOT_ADOPTED**. 9개 세계법 124개 조항·38개 기존 결합 반례를 실제 엔진에서 통과했다는 증거가 아니며, 아직 존재하지 않는 세계 내부 시행 규정이나 대회 자격 조건을 창작하지 않는다.
