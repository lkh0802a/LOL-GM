## 조사 방식·미완료 경계

- 원본 #311에는 **7일 우선 재계약 기간의 후속 폐지** 정정이 본문 상단에 기록되어 있다. 본문 하단의 과거 7일 결정이 더 오래된 기록임을 확인했다. 이것은 위 16조와 별도의 TRANS-003/시장 정책이며 [선행 대조](STEP1_CROSS_ISSUE_EFFECT_AUDIT_2026_11_01.md)에서 최종 변경 사슬을 추적한다.
- 원본 #321의 **발급 기관 미확정**을 확정된 구체 국제/지역사무국 권한으로 바꾸지 않는다. 특히 공식 참가/강등 보호 라이선스의 권한과 혼동 금지.
- 원본 #324는 이사 수·정족수·임기·위기 계량 기준 및 정기 감사 수치가 **미확정**이라고 명시한다. 조문 GOV-001~009를 대조했다고 미정 수치까지 확정하는 것이 아니다.
- 이 표의 판정은 **해당 공개 이슈의 승인 본문 ↔ 현재 문장**의 범위 일치다. 다른 이슈 댓글/미병합 PR·후속 사용자 대화 전체에서 덮어쓴 적이 없다는 **전원본 최종 효력 전수 인증은 아직 아님**. 그래도 기존 '검증 대기'와 달리 이 16개 조항의 관련 이슈 본문은 개별 내용을 직접 열어 확인했다.
- [나머지 직접 댓글 없는 조항](STEP1_42_CLAUSES_SOURCE_PRECISION_QUEUE_2026_11_01.md) 중 사용자 대화 직접 승인 2조항은 실제 대화만 출처로 남기고 가짜 GitHub 댓글 URL을 발명하지 않음. 기타 복합 24조항은 해당 도메인 승인·후속 선택의 교차 판정을 계속 수행한다.
