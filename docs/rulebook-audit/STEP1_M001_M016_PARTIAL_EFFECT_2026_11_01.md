# M01C~M16C — 원문·분야별 승인 범위 부분 대조

원본 [#251의 M01~M16 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6289688904)을 [선수 성장 #236](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6289713574), [전술 #235](https://github.com/lkh0802a/LOL-GM/issues/235#issuecomment-6289713035), [스카우팅 #238](https://github.com/lkh0802a/LOL-GM/issues/238#issuecomment-6289714908), [역사 #239](https://github.com/lkh0802a/LOL-GM/issues/239#issuecomment-6289715451)의 2026-10-20 연결과 대조했다. 이들 분야 댓글은 원본을 인용한 구현 계약이며 별도의 추가 사용자 승인을 만들지 않는다.

| 선택 | 원본에서 확인한 효력 | 연결 범위·금지 |
|---|---|---|
| M01C | 개인별 타고난 기질과 후천 경험의 상대적 영향이 다를 수 있다. | 모든 인물에 하나의 고정 가중치를 일괄 적용하지 않는다. 구체 계수는 미확정이다. |
| M02C | 성향의 상호작용은 개인·상황·경험에 따라 달라진다. | 고정 독립 스탯이나 동일 프리셋으로 강제하지 않는다. |
| M03C | 판단 편향은 개인·경험에 따라 달라질 수 있다. | 실제 접근 가능한 관측과 행동에 기반하며 원인 없는 무작위 실수나 숨은 정답 열람을 허용하지 않는다. |
| M04C | 당시 자료·접근 가능한 의견·기존 신념에 따라 같은 사건의 주관적 해석과 학습이 달라질 수 있다. | 객관적 실제 결과와 해석을 구분하며 승패만으로 고정 성향을 자동 증감시키지 않는다. 과거 판단에 미래 정보를 소급 제공하지 않는다. |

네 항목은 구체적인 소수점 계수·독립 정치/파벌 사건 엔진·실제 발생하지 않은 사건 추가 승인이 아니다. 이 표는 명시된 다섯 원문과 현재 사용자 제한까지의 **부분 효력 대조**다. 모든 후속 댓글/PR의 철회 부재, 실제 엔진 구현, 테스트 완료는 미확인으로 남긴다.

## M05C~M08C 추가 원문 범위

같은 [#251 승인 원문](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6289688904), [#235](https://github.com/lkh0802a/LOL-GM/issues/235#issuecomment-6289713035) 및 [#236](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6289713574)을 비교했다. 다음은 그 원문 범위의 부분 대조이며 모든 후속 수정과 실제 구현의 검증은 별도다.

| 선택 | 원본에서 확인한 효력 | 경계 |
|---|---|---|
| M05C | 신뢰·존중·친밀·직업적 평가와 관계의 방향성 및 역할/상황을 구별한다. | 무조건 상호 대칭이나 단일 수치 환원 금지. 개인/구단 정보 권한은 유지한다. |
| M06B | 감독·코치의 전문 의견을 고려하되 해당 업무의 최종 권한자가 결정한다. | 모든 정책을 감독에게 강제 위임하거나 코치 의견이 사용자의 최종 서명권을 대체하지 않는다. 매번 사용자 중재를 강요하지 않는다. |
| M07C | 지도·학습·소통과 전술/역할/상황의 실제 상호작용이 관련 수행에 영향을 준다. | 좋은 관계만으로 일률 전투·성장 버프 또는 같은 원인의 중복 가산을 만들지 않는다. |
| M08C | 선수 목표는 계약·실제 출전/성과·경력·관계·이전 선택의 만족과 우선순위에 따라 형성된다. | 선수 동의와 실제 계약·마감 및 사용자 최종 서명권을 보존하며 근거 없는 매일 무작위 변심을 금지한다. |

이 항목들은 사용자가 배제한 정치·파벌·권력투쟁이나 허구 사고의 신설 근거가 아니다. 서로 다른 당사자의 합법적 의견과 직업적 관계만 원문 범위에서 다룬다.

## M09C~M16C 추가 원문 범위

같은 [#251 직접 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6289688904)과 관련 [#235 전술](https://github.com/lkh0802a/LOL-GM/issues/235#issuecomment-6289713035), [#238 관측](https://github.com/lkh0802a/LOL-GM/issues/238#issuecomment-6289714908), [#239 역사](https://github.com/lkh0802a/LOL-GM/issues/239#issuecomment-6289715451)를 비교했다. 각 행은 해당 원문 범위의 부분 대조이며 이후 모든 변경의 최종 효력 인증이 아니다.

| 선택 | 원본 범위·경계 |
|---|---|
| M09C | 세트 중 콜의 영향은 당시 상황·포지션·합법 정보·신뢰에 따라 변한다. 별도 주장 직책/보너스 및 진행 중 감독 직접 개입의 폐지는 유지하고, 세트 사이 감독/코치의 전략 수정은 허용한다. |
| M10C | 메타 발견은 실제 관측·연구·경험의 해석과 결합에서 비롯될 수 있다. 근거 없는 혁신 사건·비공개 스크림 누출·최상위팀 자동 독점은 금지한다. |
| M11C | 합법적으로 관측한 전술은 이해·실행 조건에 따라 모방·변형·거부·발전할 수 있다. 모든 팀의 자동 최적 메타 수렴이나 결과 보정은 금지한다. |
| M12C | 선수 자율성·전술 준수는 실제 능력·경험·신뢰·상황의 영향을 받는다. 감독 지시가 성공을 보장하거나 진행 중 전능한 실시간 조종이 되는 것은 아니다. |
| M13C | 구단 문화는 실제 누적 역사와 현재 구성원에서 형성된다. 강제 고정 유형이나 감독 교체·매각을 이유로 한 당시 역사/안정 ID 재작성은 금지한다. |
| M14C | 스카우터의 이전 예측과 실제 결과 비교는 당시 보고서와 접근 가능한 자료를 기준으로 한다. 미래의 실제 능력·타팀 비공개 자료를 사전 지식처럼 누출하지 않는다. |
| M15C | 국가·리그 경쟁력은 실제 투자·인구·인재 이동/교류 등에서 변화할 수 있다. 국가 코드 고정 능력 보정이나 자동 리그 신설을 만들지 않는다. |
| M16C | 모바일의 판단 설명은 실제 관측·당시 근거와 후속 결과·불확실성을 구분한다. 숨은 정확 능력·사적 자료를 드러내거나 매일 확인을 강제하지 않는다. |
