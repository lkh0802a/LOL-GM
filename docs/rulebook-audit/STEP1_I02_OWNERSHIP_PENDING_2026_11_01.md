# I-02 다구단 경영 적용 대상 — 후속 원문 대조

[#251 2026-10-22 B안](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6336990133)은 전세계 독립 프로 구단의 100% 복수 소유를 허용하면서 동일 그룹의 독립 구단 직접 경영을 최대 한 곳으로 제한하고, 모구단의 산하 2군은 별도 독립 슬롯으로 세지 않는다. 독립 구단 간 인사·경기·계약·재정·정보는 별도로 유지한다.

[#251 2026-10-28 구단 분류 결정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6461053117)은 공식/독립 또는 프로/세미프로/아마추어를 고정·배타적인 구단 종류로 두지 않고 실제 계약·조직·참가 조건으로 구별한다. 프로 라이선스나 대회 등록 자격은 실체적 조건으로 검토하며 구단 ID를 새로 만들지 않는다.

**확인된 범위:** 공통 구단 모델과 별개의 조직적 독립 경영 원칙은 양립 가능하다. 다만 원문의 '독립 프로 구단'이 최신 단일 구단 모델에서 어떤 실질 조건을 충족하는 모든 구단에 적용되는지, 비전업/초기 구단을 포함하는지는 두 원문만으로 일의적으로 판정하지 않는다. **BLOCKED_DECISION:** 사용자 후속 승인 원문을 더 확인하거나 해당 범위를 별도 결정해야 한다. BIZ-010을 모든 구단으로 확대하거나 라이선스가 없는 구단에 한정해 예외를 신설하지 않는다. BIZ-012의 고정 종류 폐지 및 구단 ID·권리 보호는 계속 적용한다.

이 항목은 관련 두 원문에 대한 비교이며, 실제 소유권 엔진 구현이나 전체 승인·철회 최종 효력 검증 완료를 뜻하지 않는다.
