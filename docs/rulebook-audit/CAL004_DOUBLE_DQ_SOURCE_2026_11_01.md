# CAL-004 월즈 피날레와 양측 실격 — 원문 대조 및 교정

[#311의 HARD-INV-WORLDS-FINALE](https://github.com/lkh0802a/LOL-GM/issues/311)은 정상적인 월즈 결승을 해당 시즌 마지막 공식 경기로 영구 보호하지만, 적법한 양측 실격으로 결승이 실경기 없이 종료될 수 있는 경우 **가짜 승자·가짜 경기·시간을 만들지 않고 결승 단계의 종료/판정 이력으로 피날레를 검증**하도록 명시한다. [#234의 양측 실격 최종 정정](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6381690538)은 우승자 없음이며 차순위 팀의 자동 재결승을 허용하지 않는다.

현재 [COMP-006](../rulebook/10-COMPETITIONS.md)은 양측 실격의 우승자·경기 창작 금지를 담지만, [CAL-004](../rulebook/20-CALENDAR.md)는 단정적으로 '마지막 공식 경기'라고만 해 경기 없이 실격 판정된 상황에서 실경기 생성이 필요한 것처럼 오독될 여지가 있다. CAL-004에 해당 승인된 예외와 판정 이력·COMP-006 교차 참조를 명시했으며, 우승자·경기·경기 시각을 창작하지 않는 반례를 룰북 가드에 추가했다. 정상 결승 지위와 다른 공식전 종료 선행은 유지하고, 최초 선택/후속 정정의 출처와 적용 범위는 변경 이력에 남겼다.

이 메모는 원문 부분 비교이며 전체 승인·철회 효력 인증이나 엔진 구현/CI 완료를 뜻하지 않는다.
