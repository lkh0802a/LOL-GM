# CAL-004 월즈 피날레와 양측 실격 — 원문 대조 및 교정

> **후속 효력:** 아래는 2026-11-01 당시 원문과 교정 이력이다. 2026-11-14 후속 결정으로 양측 동시 실격·무우승 결승 사건은 폐지됐다. 현재 [COMP-006](../rulebook/10-COMPETITIONS.md)·[CAL-004](../rulebook/20-CALENDAR.md)은 결승 전 자격 검증과 실제 단측 기권·실격의 상대 행정승을 구별하고 미실시 경기·선수 기록을 만들지 않는다. 후속 직접 대화 전문 독립 열람은 `UNKNOWN`이다.

당시 [#311의 HARD-INV-WORLDS-FINALE](https://github.com/lkh0802a/LOL-GM/issues/311)은 정상적인 월즈 결승을 해당 시즌 마지막 공식 경기로 영구 보호하면서, 양측 실격으로 결승이 실경기 없이 종료될 수 있는 경우 가짜 승자·가짜 경기·시간을 만들지 않고 종료/판정 이력으로 피날레를 검증하도록 기술했다. [#234의 당시 양측 실격 정정](https://github.com/lkh0802a/LOL-GM/issues/234#issuecomment-6381690538)은 우승자 없음이며 차순위 팀의 자동 재결승을 허용하지 않았다. 이 양측 실격 가정은 위 후속 결정으로 대체됐다.

2026-11-01 당시 COMP-006은 양측 실격의 우승자·경기 창작 금지를 담았지만 CAL-004는 단정적으로 '마지막 공식 경기'라고만 해 경기 없이 실격 판정된 상황에서 실경기 생성이 필요한 것처럼 오독될 여지가 있었다. 그때 CAL-004에 해당 예외와 판정 이력·COMP-006 교차 참조를 명시했고 관련 반례를 룰북 가드에 추가했다. 해당 예외는 현재 조항에 복원하지 않는다. 정상 결승 지위와 다른 공식전 종료 선행은 유지하며, 최초 선택/후속 정정의 출처와 적용 범위는 변경 이력에 남긴다.

이 메모는 원문 부분 비교이며 전체 승인·철회 효력 인증이나 엔진 구현/CI 완료를 뜻하지 않는다.
