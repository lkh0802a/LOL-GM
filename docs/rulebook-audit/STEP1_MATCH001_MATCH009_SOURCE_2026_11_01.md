# MATCH-001·MATCH-009 — 경기 정본과 합법 관측 원문 부분 대조

| 조항 | 원문·승인 범위 | 경계 |
|---|---|---|
| [MATCH-001](../rulebook/50-MATCH.md) | [#233 최상단 신규 코어 결정](https://github.com/lkh0802a/LOL-GM/issues/233)과 [#241 단일 결과 작성](https://github.com/lkh0802a/LOL-GM/issues/241)은 실제 시간·위치·자원·행동으로 계산되는 단일 새 5v5 코어와 공식/연습/기록 소비를 요구한다. | 새 코어 한 개는 승인된 이행 대상이며 경쟁하는 두 엔진이 같은 경기 승자를 각각 확정하는 것은 금지한다. 검증 원자료가 없는 챔피언 효과·결과를 만들어 실제 코어 완성으로 간주하지 않는다. 구형 집계 결과의 존재는 새 코어 완성이 아니다. |
| [MATCH-009](../rulebook/50-MATCH.md) | [#235 전술·AI](https://github.com/lkh0802a/LOL-GM/issues/235) 및 [#280 게임성](https://github.com/lkh0802a/LOL-GM/issues/280)은 실제 합법 관측·표본·패치/로스터 변화·선수 숙련과 전술 준비를 행동과 결과에 연결한다. | 비공개 의료·숨은 기량·미래 정보로 AI를 우대하거나 스타일 자체에 근거 없는 고정 승률 버프를 부여하지 않는다. 실제 실행·결정·기록과 사후 설명을 구분한다. |

위 원문·조항의 부분 대조는 모든 후속 승인/철회, 경기 원자료 확보, 실제 구현·세이브·실기기 또는 CI 완료를 뜻하지 않는다.
