# M17C~M32C — 원문·분야별 승인 범위 부분 대조

[#251 원본](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6290080827)을 [#233 경기](https://github.com/lkh0802a/LOL-GM/issues/233#issuecomment-6290119951), [#235 전략](https://github.com/lkh0802a/LOL-GM/issues/235#issuecomment-6290118219), [#236 선수](https://github.com/lkh0802a/LOL-GM/issues/236#issuecomment-6290119243), [#237 경영](https://github.com/lkh0802a/LOL-GM/issues/237#issuecomment-6290120658)과 대조했다. 분야별 댓글은 원 승인과의 연결이며 실제 구현·전수 후속 효력 인증이 아니다.

| 선택 | 확인한 의미와 제한 |
|---|---|
| M17C | 경험의 영향은 사건의 관련성·반복성 등에 따라 달라지며 실제 기록과 주관적 기억을 구별한다. |
| M18C | 자신의 능력에 대한 인식은 경험과 평가에 따라 변하며 숨은 실제 능력·미래 성장의 자동 정확한 인식이 아니다. |
| M19C | 의견 수용은 전문성·관계·근거·경험에 따르되 업무별 기존 최종 결정권을 바꾸지 않는다. |
| M20C | 기회비용·불확실성과 기존 계약·권리·의무를 함께 고려하며 목표 가중치로 법적 의무를 무효화하지 않는다. |
| M21C | 실제 공동 출전·역할·챔피언·전술 경험의 상황별 상호작용이며 팀 평균·일률 버프·동일 원인 중복 가산이 아니다. |
| M22C | 실제 공동 활동을 통한 전술 이해도 선수·역할·상황에 따라 달라질 수 있다. 수동 훈련 포인트를 복원하지 않는다. |
| M23C | 경기 중 콜은 시간·관측·소통에 따르며 주장 직책/보너스와 세트 중 감독 직접 개입은 금지한다. 세트 사이 조정은 유지한다. |
| M24C | 결과·정보·전술·실행·상대·정당한 난수의 불확실성을 분리해 잠정 평가한다. 가짜 사고나 미래 정보 유출은 금지한다. |
| M25C | 실험의 학습 가치·위험과 실제 시간·스크림·재정 비용을 비교한다. 실험 강제나 없는 결과 생성은 금지한다. |
| M26C | 상대의 공개 전략 대응 가능성을 실제 정보·시간·역량 내 유한하게 추론한다. 깊이 수치는 미확정이고 숨은 정보·무한 재귀는 금지한다. |
| M27C | 감독·코치 기여는 당시 로스터·예산·상대·실제 판단을 근거와 불확실성과 함께 평가한다. 승률만으로 확정하지 않는다. |
| M28C | 실제 관측된 상대 대응·패치와 성공 원인 해석에 따라 전략을 유지·수정·폐기할 수 있다. 동일 시점의 일괄 수렴은 강제하지 않는다. |
| M29C | 실제 현금·채무·계약·권한·대안 비용에 따라 투자한다. 가상 무상 투자와 재정 버프는 금지한다. |
| M30C | 감독 교체 후 변화는 누적 역사와 실제 구성원·성과·합법 권한에 따른다. 문화 즉시 초기화 및 별도 인수인계 화면 부활은 금지한다. |
| M31C | 평판은 공개 가능한 실제 근거와 관측자의 접근 범위에 따라 달라질 수 있다. 비공개 진실 열람이나 임의 스캔들 엔진을 만들지 않는다. |
| M32C | 실제 원인·결정·기록·동일 시드·저장 복원 및 정보 경계를 비교 검증한다. 입력 차이가 항상 다른 결과를 낸다고 강제하지 않는다. |

정치·파벌·권력투쟁·철회된 가상 기술 사고를 신설하지 않는다. 구체 수치와 계산 깊이는 원문에서 확정되지 않은 범위에 임의로 추가하지 않는다.
