## 다른 결정과의 직접 충돌 처리

1. **M129C와 선행 R01D:** M129C에 포함된 강등시 2군 처리 요구는 [R01D 사용자 직접 수정 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6247461134)을 따라야 한다. R01B의 '다른 2부 자동 재배치'는 철회됐다. 기존 COMP-004에 있는 '적격한 하위 부로 행정 이동' 경로는 **동일 2부 충돌의 경우** R01D '매각/해체'와 불일치했으므로 해당 경우 타 2부·3부·N부로 회피할 수 없도록 기존 COMP-004를 수정했다. 매각은 독립 구단의 실질 경영·계약/채무/라이선스 승계가 필요하며 미완료 시 참가 등록을 보류한다. 실제 기존 경기·금전·이력은 보호한다. **이번은 신규 정책 선택이 아니라 확정된 정책의 명문 충돌 교정**.
2. **M140C와 패치 잠금:** 일시적 글로벌 프로 금지의 적용 시각과 해당 대회 지정 패치 및 이미 시작/확정된 세트의 적용 범위는 별도로 판단. 당일 모든 공식 경기 종료 후 적용되는 핫픽스의 상위 불변 원칙을 바꾸지 않는다.
3. **M145B·M148B는 그대로 B:** 중요 알림/선택적 입문 안내이지 모든 매일 행동/튜토리얼을 강요하지 않는다. M146C는 사용자가 선택한 자동 진행 정지 조건이지 감독의 계약·밴픽·등록 권한을 전 직원에게 양도하는 새로운 법적 권한이 아니다.
4. **M149C와 M206D 관계:** 현행 저장/손상 복구 및 공식 결과의 무결성은 필수지만 폐기된 구버전 세이브 형식을 지원하라는 요구와 구별한다. [M206D 직접 정정](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6312434301)은 후속 M206C 자동 선택 문자열보다 우선하며, 기존 진행 중인 실제 세계의 확인 가능한 역사 자료에 최신 평가 모델을 적용하되 과거에 없는 계약채무·경기 결과를 만들지 않는다는 뜻이다.
5. **신규 조문 허용:** 이 배치에서 세계법의 새로운 금지·권리보다 기존 법규의 적용과 UI·제품 수용/검증이 주를 이루어 별도 조문은 증설하지 않는다. 앞으로 미규율 법적 효과 확인 시 신설 가능하며 조문 수 인위적 상한 없음.
