## 판단 및 문서 처리

- **재정/후원(M113~120):** 확정 채무·실제 현금·미지급·예측, 실제 수익 이행과 직원·소유권 인수 상황을 구별한다. BIZ-004·005·008·014·017의 지급·경영·사업 원칙을 그대로 사용한다. 제품 명세의 재정 화면이 실제 계약 지출·수령과 미래 의무의 차이를 보여주는 기준은 유지하고, **확정/예측과 만기·미수/현물·계약상 권리충돌**을 예시로 보강한다. 사용자 직접 결정 없이 보조율·지출 상한·스폰서 개수·차입 한도 신설 없음.
- **팬·미디어(M121~127):** BIZ-007에 실제 출전·이적/구단 역사·연고·관점과 계약이 이미 포함되어 있다. 경기/계약·여론의 사실·추정·미확인 보도 범위는 UI-006. 기사 또는 라이벌의 존재를 증명하는 실사건 없이 매일 가짜 분쟁/스캔들/지역 갈등을 자동 생성하지 않는다. **실제 관측 사건 → 관측 주체 → 평판/실판매·계약 → 지급 원장**의 소비 흐름을 후속 테스트에서 별도 검증한다.
- **신생 리그(M128):** 법규에 창설 권한이 있다고 즉시 승인된 초기 세계의 국가별 실존 리그/라이선스가 발생하는 것은 아니다. 유효 사무국 심사·실재 재정·시행 시점을 구분하여 세계관 정본/초기 프리셋 실제 수용에서 검증한다.
- **R01D 별도 후속 충돌:** 이번 batch의 M128 자체가 2군 충돌 대안을 신규 승인한 것은 아니다. [R01D 직접 수정 원본](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6247461134)은 1군의 2부 강등 충돌 시 **산하 2군을 적법 매각하거나 해체**하도록 정했으므로, 기존 COMP-004가 '적격한 실제 하위 부로 행정 이동'까지 허용하던 차이를 확인해 **동일 2부 충돌 예외를 매각/해체로 직접 교정**했다. 조문의 기존 참가 보류·계약·역사 보호를 유지하고, 가짜 매수인·타부 강제 재배치 금지. 정책상 이전의 일반적인 다구단 소유 금지와 혼동하지 않으며 2026-11-08 다구단 A안을 별도로 존중한다.
- **신규 조문 심사:** 기존 세계법의 금지·권한으로 규율할 수 있어 이번 16건 자체만으로 새로운 법률 조문은 추가하지 않았다. 실제 새 법적 공백 발견 시 신규 조문은 허용한다.
