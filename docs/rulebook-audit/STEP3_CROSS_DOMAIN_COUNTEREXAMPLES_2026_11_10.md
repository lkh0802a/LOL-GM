## 결합·원자성 우선순위

1. **단일 세계 시계/원장/실제 경기 원본:** 합법 국가대표 경기 + 시장 중 구단 금지 + 시즌 국제 피날레·패치 잠금은 서로 다른 개념을 단일 시각으로 심사한다. 같은 선수·구단 원장·저장 슬롯을 두 곳에서 두 번 확정하는 구현을 허용하지 않는다.
2. **제정/승인/실행 권한의 차이:** 이사회 투표는 내부 시행 규정의 실제 공표·시행과 같지 않다. 국가협회 선발은 국제대회 출전권 부여가 아니며, 구단 소유는 자동 공식 라이선스가 아니다. 본문 조문에는 제3자 사적 권한·숨은 수치를 마음대로 추정할 수 없다는 원칙을 유지한다.
3. **같은 사건의 유효 자료:** 과거 경기 결과·직원/선수 계약·진짜 재정 원장은 미래 모델·UI·로컬 규정 변경으로 소급 수정하지 않는다. 스카우트/보고서·AI 분석은 당시 합법 관측 자료의 표본 한계와 불확실성을 보존한다.
4. **명시적 철회 효과:** R01D 다음의 실제 #234 하위 부 이동 승인, 87B/140 맞춤/190 불변 닉네임/다구단 A/M206D를 원안 문자열보다 최신 효력으로 사용한다. 직원 인수인계·주장·수동 훈련 강도·가상 퍼즈/사고를 이전 이슈로부터 복원하지 않는다.

## 테스트 인수 전 조건

- 이 파일의 23개는 **테스트 케이스 명세**, 현재 실제 Rust/TS 또는 레거시 엔진 테스트 파일에 그대로 삽입·통과한 실험 개수가 아니다.
- 각 사례에 대해 최초/후속 규정의 실제 세계 저장객체 버전·관할·발효시각/권한, 정상/불법 예외, 최종 거부 이유·원장 롤백, 경기 재현성, 저장/로드/동일 시드/AI-사람 동등 결과를 함께 검증해야 한다.
- **기존 `scripts/rulebook-guard.mjs`는 정적 정책 핀**이며 경기/계약/재정 실제 소비의 인과·시나리오를 검증하지 못한다. 정확 HEAD에서 별도 `npm run check:rulebook`과 통합 `npm run check`·원격 CI·장기 실게임 시뮬레이션 및 제품 동작 검증 필요.
- 발견된 실제 미규율 권리·예외는 적법한 새 조문 또는 실제 세계 내부 시행 규정/계약으로 정비할 수 있다. **신규 세계법 조문 금지가 아님.** 승인되지 않은 보상금·고용 숫자·시장 창은 발명하지 않는다.
