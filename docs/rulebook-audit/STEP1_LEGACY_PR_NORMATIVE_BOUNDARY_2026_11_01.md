### 출처 유효성 판정 원칙

1. **사용자 직접 최종 지시 > 같은 주제 이전 사용자 지시 > 구현 PR 선택/추천**. 다만 사용자 후속 결정이 이전 모든 세부사항을 전면 폐기하는지는 **수정한 대상의 범위**로만 해석한다.
2. 병합된 구현 PR의 **테스트용 상수/초기 추정값**은 게임 엔진에서 실제 존재하더라도 상위 룰북의 영구 법적 수치가 자동 되는 것이 아니다. 최신 승인 체계와 충돌하는 경우 원래 당시 시즌의 보존 기록·시행시점도 함께 검증한다.
3. 수정 중인 Draft PR은 실제 게임 상태·사용자 승인 원문을 교체하지 않는다. 구형 정책/코드 소비자를 가진 경우 **내용별 최신 직접 승인 + 이후 확정 이력**을 정리한 뒤 병합해야 한다.
