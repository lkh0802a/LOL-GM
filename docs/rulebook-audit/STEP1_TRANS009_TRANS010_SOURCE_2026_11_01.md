# TRANS-009·TRANS-010 — 선수 의사와 계약 효력 원문 부분 대조

| 조항 | 승인 원문 | 확인된 의미 |
|---|---|---|
| [TRANS-009](../rulebook/30-TRANSFERS.md) | [#224 사용자 최종 결정](https://github.com/lkh0802a/LOL-GM/issues/224), [#322 협상·연쇄](https://github.com/lkh0802a/LOL-GM/issues/322) | 선수의 실제 역할·출전·조건·대안을 반영하며 명백한 거절은 즉시, 합리적 조건은 즉시 수락 가능하다. 의미 있는 역제안을 사용하되 인위적 왕복·고정 지연·허구 제안을 강제하지 않는다. 사용자 화면의 전망은 합법적인 관측에 기반한 불확실한 추정이지 선수의 숨은 의사나 확정 승낙이 아니다. |
| [TRANS-010](../rulebook/30-TRANSFERS.md) | [#322 실제 이적 요구와 계약](https://github.com/lkh0802a/LOL-GM/issues/322), [#321 비라이선스 팀 특례](https://github.com/lkh0802a/LOL-GM/issues/321) | 실재 출전/약속/계약 상황에 따른 요구는 가능하지만, 요구만으로 계약이 즉시 종료되거나 일반 동의·바이아웃 요건이 소멸하지 않는다. 실제 계약상 법적 특례와 #321의 적법한 바이아웃 예외를 일괄 폐지하지 않는다. 동일 요청을 무작위로 매일 강제하거나 지급·소속을 중복 반영하지 않는다. |

이 표는 위 원문 및 해당 조항의 범위 비교다. 후속 전체 승인·철회 최종 효력과 실제 UI/시장 엔진·저장·CI의 완료 여부는 별도다. 1~3일/약 5일은 원문상 체감 목표이며 새로운 고정 법적 기간으로 바꾸지 않는다.
