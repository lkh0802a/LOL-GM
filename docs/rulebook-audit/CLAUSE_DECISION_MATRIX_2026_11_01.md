## 2026-11-01 7차 CORE-007 사용자 재확정 — v0.7.0 최신 판정

- **결정 원천:** 2026-11-01 사용자 대화에서 CORE-007의 세 가지 적용 시점과 보호 조건을 제안했고 사용자가 명시적으로 동의하였다. 해당 대화에 공개 GitHub 원문 링크는 없으므로 [#311](https://github.com/lkh0802a/LOL-GM/issues/311), [#323](https://github.com/lkh0802a/LOL-GM/issues/323), [#324](https://github.com/lkh0802a/LOL-GM/issues/324), [#316](https://github.com/lkh0802a/LOL-GM/issues/316)은 관련 과거 승인·설계 근거로만 표기한다. **대화 승인의 존재를 GitHub 댓글 확인으로 가장하지 않는다.**
- **공식:** 공식 지역·국제 대회 체계의 *구조적 개편*은 원칙적으로 차기 시즌부터 적용한다. 진행 중 경기의 실제 부전승·기권·순연 등 당시 규정에 따른 정상적인 집행까지 차기 시즌으로 미루지 않는다.
- **기존 독립 행사:** 대회 규모·형식·상금·참가 규정 등 기존 독립 대회의 *구조적 개편*은 원칙적으로 차기 회차부터 적용한다. 해당 회차의 기확정 경기·계약·성적을 소급 수정하지 않는다.
- **신규 독립 행사:** 기존 행사 규정 개편이 아닌 별도 신규 행사 개설은 **현재 시즌에도 가능**하다. 다만 대회 신설과 실제 개최 승인, 참가 선수 등록/경기 실시를 구분하며 사전 공표·권한·실제 계약/자금·공식 경기 우선·팀/선수/운영 자원·세계 선수 시장 28일 실경기 금지 등 모든 공통 제약을 따른다. 임의의 신규 예외 기간·자동 참가팀 생성 권한은 승인하지 않았다.
- **정본 조치:** [CORE-007](../rulebook/00-CORE.md) 및 [COMP-011](../rulebook/10-COMPETITIONS.md)을 v0.7.0으로 동기화, 추가 회귀 검사 대상 등록. '원문 부분대조' 상태로 전환하되 **103개 중 103개 부분대조 / 0개 심화 대기**는 모든 과거 610개 댓글/289개 PR의 최종 승인을 전수 입증했다는 뜻이 아니다. 코드 구현·UI·스케줄 실행은 별도 작업이다.

[최신 설계 원문 §2.2·§2.5](https://github.com/lkh0802a/LOL-GM/blob/main/docs/design/COMPETITION_SYSTEM_REDESIGN_NOTES_2026_10_28.md)은 **1군이 2부로 강등되고 2군도 2부인 경우까지** 하위 부 행정 이동·매각·해체를 직접 적용한다.

- **범위:** 현재 단계는 **승인 효력 판정**으로, 이 대장에서 게임 규칙 문장을 수정하지 않으며 v0.6.0 조항을 새로운 확정 규칙으로 증설하지 않는다.
