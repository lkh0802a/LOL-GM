# 1단계 — 승인·철회·미이관 효력 조사 (2026-11-01, 1차 원문 판정)

> **상태: 진행 중 / 표본별 실질 판정 시작.** 룰북 최종 확정 전에 반드시 수행하는 **1단계(기존 승인 사항 전수조사)**의 실제 판정 대장이다. 기존 [댓글 610건 색인](README.md)·과거 PR 약 289건 목록은 **탐색 인덱스**이고, 113개 룰북 조항의 관련 근거 **부분대조** 역시 전체 세부 선택의 최종 효력 전수 인증이 아니다. 아래 표에 원문과 후속 철회를 대조한 **개별 쟁점만** 판정한다. 이 표는 게임 규범 자체가 아니며, 사용자 승인 없는 정책·수치·새 의무를 만들지 않는다.

## 수행 순서와 분류 기준

1. **원본 추적:** 사용자 선택을 담은 원문 이슈/댓글과 동일 결정의 후속 승인·철회·수정 기록을 연결한다. 개발 체크포인트·가상 테스트 작성·Codex 제안은 실제 사용자 승인과 구분한다.
2. **효력 분류:** `현행·상위 반영` / `현행·세부 미이관` / `후속 철회·대체` / `개발·구현 조건만` / `후속 판정 필요`를 구분한다. '세부 미이관'은 **승인된 규칙이 없다는 뜻이 아니라**, 현재 113개 조항의 표현만으로 그 세부 실행을 결정하기 어렵다는 뜻이다.
3. **규정 위치:** 게임의 영구·상위 원칙은 룰북 분야별 장, 개별 대회의 기존 승인된 특수 타이브레이크·UI 표시·수치 없는 실행 절차는 해당 분야의 **승인된 하위 운영 규정/대회별 규정**으로 추적한다. 모든 세부사항을 상위 조항으로 복제하지 않는다.
4. **진행 조건:** 1단계에서 실제 승인 누락·대체 관계를 기록한 뒤 2단계에서 규범 효력/우선순위를 결정하고, 3단계 내부 충돌 검증, 4단계 누락 편입, 5단계 구형 문서와의 정합화로 진행한다. 순서상 구형 문서 편집이나 게임 코드 작업만으로 1단계를 완료했다고 표기하지 않는다.

**추가 원본 선택 색인:** [#251 기타 7개 일괄 승인 선택 기록 156행](STEP1_CHOICE_SOURCE_INVENTORY_B_2026_11_01.md)을 추출하였다. 앞선 224행과 함께 380개의 **출처상 선택 기록 행**을 구축했으나 **동일 번호의 재등장 및 중간 철회가 포함돼 서로 다른 최종 유효 규정 380개가 아니다**. 개별 후속 효력 판정은 별개로 남는다.

**개별 선택 원문 색인 추가:** [#251 일괄 승인 4개 묶음의 선택 ID 224개](STEP1_CHOICE_SOURCE_INVENTORY_2026_11_01.md)를 별도 번호별 행으로 수집했다. **224개는 원문 선택 문자열의 누락 없는 추출 수량이지 개별 승인 효력 판정 완료 수량이 아니다.** 실제 효력은 아래 표와 후속 정정 검증 기록으로만 판단한다.

**후속 이슈 실질 판정 추가:** [#311·#321·#323·#324 및 관련 #251 총 12개 후속 정책 쟁점](STEP1_CROSS_ISSUE_EFFECT_AUDIT_2026_11_01.md)을 대조했다. 이 중 #311의 **안정화 단계 구버전 세이브 지원 강화**는 이 문서 이전의 M206D 결론을 조건부로 보완하고, #311의 7일 독점기 중간 정책은 2026-10-29 후속 결정으로 철회된 사례다. **18개 명시적 승인·대체 효력 사슬**은 [별도 실질 사슬 표](STEP1_SUPERSESSION_CHAINS_2026_11_01.md)와 원본 선택 색인의 해당 행에 연동했다. 수치들은 전체 규정 최종 효력 판정 수로 합산하지 않는다.

**추가 원문·효력 판정:** [#251 R01~R21 21개 별도 선택 코드](STEP1_R01_R21_SOURCE_ADJUDICATION_2026_11_01.md) 및 [#234 일정/보호 라이선스 16개 후속 효력 사슬](STEP1_CALENDAR_LICENSE_SUPERSESSION_2026_11_01.md)을 검토했다. 기존 대형 선택 색인 380행과 R계열 21행은 **401개의 원본 선택 기록**이지 401개 확정 유효 정책이 아니다. 후속 효력 16사슬은 별개의 비교 쟁점이므로 더하지 않는다. #234 최종 2군 보호 라이선스 정정의 **집단별 신규 발급과 사후 개별 실효** 구분은 이미 현행 COMP-020/021에 반영돼 있어, 이 단계에서 중복 규칙을 추가하지 않는다. 주말 증편의 최종 6393919786 댓글은 이전 '주말 선호 자체 폐지' 해석을 다시 정정한 기록이다.

**구현/규범 구분의 신규 사례:** [#251 2026-10-22 정적 개선 1~72의 대표 17개 묶음](STEP1_QA72_NORMATIVE_BOUNDARY_2026_11_01.md)은 승인된 실체 규칙과 기존 코드 정합화·성능·QA 항목을 분리했다. **17묶음 = 독립 새 규칙 17개가 아니다.** 내부 권한/단일 경기/역사 보호에 이미 들어가는 위반 사례는 실법규 중복 이관이 아니라 실제 수용 반례로 관리한다.
