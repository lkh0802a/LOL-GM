# 월즈 D-032 타이브레이크 — 전원 출전·정규 통계 비합산 (2026-11-11)

> **비규범 정책 효력 감사 / APPROVED_BY_USER · ENGINE_NOT_RUN.** 사용자 직접 변경: 유한 BO1 결정전 채택, **“출전 기회는 보장”**, **“타이브레이크는 그 안에서만 반영해야지 정규에 반영하면 안되지”**. [현행 COMP-019](../rulebook/10-COMPETITIONS.md)의 승인 효력을 설명하는 문서이며 새로운 법률/게임 엔진의 실행 성공을 의미하지 않는다.

## A. 적용 범위와 정규 성적 보존

- 월즈 D-032 리그 페이즈의 기존 **승수 → 상대 일정 강도(SoS) → 세트 득실 → 상대 세트 득실 → 세트 승수 → 적법하게 비교 가능한 실제 맞대결** 순서로도 미해결인 **16/17위 진출 경계**와 **8/9위 상위 시드 그룹 경계**에만 결정전을 적용한다. 이미 해소된 순위에 불필요한 새 경기를 만들지 않으며, 일반 국내/국제 동률을 전면 강제 결정전으로 바꾸지 않는다.
- **실제 타이브레이크 참가 대상으로 편성된 모든 팀은 최소 한 번 실제 BO1을 치러야 한다.** 초기 대진 부전승/높은 원시 포트는 추첨 위치의 배정일 뿐 출전도, 경기 없이 자격 확정도 아니다.
- 결정전은 **별도의 tiebreak match/score ledger**로 집계한다. 승리·패배·세트 승수·챔피언 결과가 **해당 경계의 16강 진출 여부 또는 상위/하위 시드 그룹 판정**에만 영향을 주고, 완료된 리그 페이즈의 **기존 승수·SoS·세트 득실·상대 세트 득실·세트 승수·실제 상대전적·정규 순위**를 소급 합산·재계산하지 않는다. 실제 경기의 시간·선수 출전/체력·의료·계약 효과·리플레이는 별도로 보존한다.
- 두 경계가 하나의 동률 집단에 걸치면 16강 진출 집단부터 확정한 후 그 적격 팀 사이의 1~8위 포트 경계를 판정한다. 결정전 탈락 순서만으로 전체 1~24위 세부 순위를 자의적으로 생성하지 않는다.

## B. 전원 출전과 유한 경기 수의 동시 보장

`n` = 아직 결정전을 치를 적격 팀 수, `q` = 그 경계의 미확정 자격 자리 수(`1≤q<n`). 승패가 확정된 실제 BO1의 수는 다음처럼 두 갈래로 구성할 수 있다.

| 조건 | 실제 대진 구조 | 실제 BO1 경기 수 |
|---|---|---|
| `n≥2q` | 최소 2팀으로 이루어진 **q개 진출조**를 구성. 각 조에서 패자 탈락형 싱글 엘리미네이션으로 최종 승자 1팀만 진출 | `n-q` |
| `n<2q` | 최소 2팀으로 이루어진 **r=n-q개 탈락조**를 구성. 각 조에서 승자는 자격 획득, 패자는 다음 대결에 잔류하고 마지막 패자 1팀만 제외 | `q` |

**구성적 종료 증명:** 크기 k≥2인 조는 일반 패자 탈락형이든 패자 잔류형이든 각각 실제 승패가 확정된 BO1 k−1개로 끝난다. 첫 유형은 조당 승자 1팀, 두 번째는 조당 마지막 패자 1팀을 특정한다. 모든 조가 최소 2팀이고 **초기 부전승 팀도 자격 확정 전에 나중 실제 경기를 반드시 치러야 하므로** 출전 기회가 전원에게 주어진다. 조별 경기 수를 더하면 각각 n−q, q이며 **최대 `max(n-q,q)≤n-1`경기**라는 유한 상한이 존재한다. 출전 횟수의 동등성까지 보장하는 것은 아니다.

**경계 사례:**

- **n=3, q=1:** 1개 진출조. A–B 후 승자가 C와 실제 BO1 → 최종 승자 진출, **2경기**, C도 출전
- **n=3, q=2:** 1개 탈락조. A–B **승자는 진출**, 그 패자와 C가 실제 BO1 → 그 승자도 진출, **2경기**. C의 무출전 진출 금지
- **n=4, q=2:** 2개 진출조. A–D, B–C 각각 실제 BO1 → 두 승자 진출, **2경기**, 전원 출전
- **n=4, q=3:** 1개 탈락조. A–D, B–C 승자는 각각 진출하고 **두 패자가 BO1**로 마지막 자리를 결정, **3경기**
- **n=5, q=4:** 1개 탈락조. 초기 두 BO1의 승자 진출, 처음 쉬는 팀은 다음에 실제 패자 측에 합류해 반드시 BO1 출전, 총 **4경기**

**시드·대진:** 기존 다섯 지표가 이미 동률이므로 같은 지표를 재사용해 우열을 꾸미지 않는다. 유효한 전원 맞대결/미니리그 → 사전 공표된 원시 월즈 참가 시드·포트 → 비교 불가시 사전 공표된 **공개·감사 가능한 대진/부전승 추첨**에 따라 조 편성·경기 순서를 확정한다. 추첨으로 승자·진출팀을 직접 결정하지 않는다. First Selection은 국제 녹아웃 첫 세트의 적법한 코인 토스 등 MATCH-003 규칙을 따른다.
