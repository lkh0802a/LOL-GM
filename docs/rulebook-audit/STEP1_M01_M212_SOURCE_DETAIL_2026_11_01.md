# 1단계 — #251 M01~M212 사용자 승인 세부 항목 212건 설명 매핑

**원본 개별 내용 매핑 완료:** M01~M212 사용자 승인 댓글의 해당 범위에서 번호마다 항목별 설명을 추출하고, 선택안 문자를 연결했다. 이는 **당시 사용자가 승인한 세부 판단·UX/엔진 수용 기준**을 개별 출처에 연결한 것이며, 212개의 독립적인 상위 룰북 조문이 아니고 2026-10-28~11-01 후속 모든 결정을 최종 대조한 판정도 아니다. 해당 후속 상위 결정이 같은 주제에 있으면 나중 결정을 우선하고 기존 효력 대장과 대조한다.

2026-11-07 부분 대조: [M164B·M176B 직접 원문](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6312524720)의 미관측·적은 표본과 AI의 비공개 능력 접근 금지를 [PLAYER-007](../rulebook/40-PLAYERS.md)에 명시했다. 기존 `scripts/scouting-coverage-cost-acceptance.mjs`의 비공개 getter 반례는 특정 경로의 인접 검사이며 스카우팅 전체 효력·실제 UI 수용 완료가 아니다.

같은 원문의 M182B·M183C·M186C·M187B는 [UI-007](../rulebook/80-EXPERIENCE.md)의 대안/확정 역사 구분과 [CORE-010](../rulebook/00-CORE.md)의 감독 교체·수동 권한·선택형 직원 계약 경계에 연결했다. 해당 경로의 엔진·UI 및 다른 후속 원문 전체 검증은 별도다.

같은 원문의 M188C는 [BIZ-014](../rulebook/60-BUSINESS.md)에 확정 채무·현금흐름·결정권을 확인하는 배당/재투자로 연결했다. [다구단 B안 후속 승인](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6336990133)의 독립 경영·독립 원장과 함께 적용하며 임의 배당률은 정하지 않는다. 재정 writer·계약·저장 동작의 실제 수용은 별도다.

같은 원문의 M189C~M191C 및 [#237 분야별 연결](https://github.com/lkh0802a/LOL-GM/issues/237#issuecomment-6312556693)은 [BIZ-005·007](../rulebook/60-BUSINESS.md)의 후원 권리·현물/현금 구분과 실제 입장·판매 수익에 연결했다. 실제 후원 계약·재정 원장·과거 기록 및 다른 후속 원문 전수 검증은 별도다.

## 감사 판정의 정확한 범위

- 212개 모두 **번호·당시 선택안·설명 문구·원문 댓글**을 실질 대조했다. 다른 #251 R·일반 1~146 선택이나 #234·#311 최신 세부 정책 전체가 이 212개 건과 일대일로 동일한 것은 아니다.
- **M206만 명시적 최종 재정정**으로 D안을 따른다. M26은 사용자 직접 C를 채택한 사항으로 B 추천안 미승인. 다른 제안 안의 임의 선택·가중치/확률/금액을 새로 발명하지 않는다.
- 전체 다차원 설계는 실제 활동·경제·경기·관측·시간을 소비하는 승인된 기존 엔진의 **하위 수용조건**으로 읽고, 숫자 수만큼 새 시스템·상위 조항을 중복 생성하지 않는다.
- 각 항목에 어떤 후속 이슈 댓글·PR 리뷰가 적용되는지는 [도메인 간 최신 효력 대조표](STEP1_CROSS_DOMAIN_FINALITY_2026_11_01.md) 및 관련 하위 규정으로 추적하며, 전수 효력 확정 여부는 별도 기록한다.
