# 1단계 — #251 일괄 선택의 개별 번호 원본 색인 (4개 묶음)

> **진행 상태: 원본 선택 문자열을 개별 번호로 분해 완료 / 최종 승인 효력 전수 판정은 미완료.** 이 파일은 [실질 원문 효력 판정](STEP1_APPROVAL_EFFECT_AUDIT_2026_11_01.md)을 보조하는 **기계적 번호 색인**이다. #251의 선택 묶음 4곳에서 30+30+102+62 = **224개 선택 ID를 중복·누락 없이 추출**했다. `선택 원문 존재`는 현재 효력 유지·룰북 미이관·구현 완료를 뜻하지 않는다. 한 댓글의 선택은 뒤 댓글/명시적 사용자 정정으로 **전체 또는 일부가 철회될 수 있음**을 특히 유의한다. 다른 #251 선택 묶음 및 다른 이슈/PR은 이 224개 범위에 포함되지 않는다.

**열 읽는 법:** `계열-번호`는 원본 묶음을 분리하기 위한 감사키(게임 룰 ID가 아님)다. `원문 선택`은 당시 제출 문자열, `최신효력`은 실제 후속 정정의 확인 여부다. 한때 승인되었다는 사실과 최종 유효성 확인을 구분한다.
