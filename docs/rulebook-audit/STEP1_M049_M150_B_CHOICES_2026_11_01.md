# M49~M150의 B 선택 여섯 건 — 원문 및 일부 분야 대조

[#251 2026-10-21 사용자 제출 원문](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6312021889)은 102개 중 **M65B·M84B·M90B·M93B·M145B·M148B만 B**, 나머지는 C라고 명시한다. 이는 당시 선택의 개별 범위이며 후속 102개 전부의 효력 인증은 아니다.

| 선택 | 원문에서 확인한 범위 | 후속 비교·경계 |
|---|---|---|
| M65B | 기본은 단순 요약, 상세 모드는 선택. 모든 조작을 기본 노출하지 않는다. | 경기 결과는 실제 단일 기록이며 상세 모드는 새 경기를 생성하는 뜻이 아니다. |
| M84B | 직원의 유효한 스크림 일정 추천을 감독이 결정한다. | 매일 강제 예약이나 가짜 스크림을 승인하지 않는다. |
| M90B | 스태프가 일상 루틴을 처리하고 예외를 보고한다. | 매일 사용자 승인을 강제하거나 기존 최종 서명권을 소멸하지 않는다. |
| M93B | 피드백·코칭 회의는 근거 있는 사건·정보가 필요한 때 제안한다. | [#237 분야 연결](https://github.com/lkh0802a/LOL-GM/issues/237#issuecomment-6312054317)은 매일 필수 회의가 아님을 재확인한다. |
| M145B | 중요한 결정이 필요한 사건·오류 중심으로 알린다. | [UI-001](../rulebook/80-EXPERIENCE.md)에 반영; 모든 미세 이벤트 알림을 강제하지 않는다. 실제 사건 없는 가짜 사고 생성은 별개로 금지된다. |
| M148B | 빈 선수단의 첫 영입 안내는 선택형이다. | [#225 분야 연결](https://github.com/lkh0802a/LOL-GM/issues/225#issuecomment-6312087208)과 [UI-001](../rulebook/80-EXPERIENCE.md)은 강제 튜토리얼·가짜 로스터·임의 서명을 금지한다. 실제 UI 수용은 별도다. |

이후 정정·철회의 부재는 해당 관련 원문 전체 대조 전까지 미확인이다. 표는 코드·UI·CI 완료 또는 사용자 최종 권한의 자동 위임을 의미하지 않는다.
