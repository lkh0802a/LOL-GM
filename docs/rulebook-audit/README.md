# LOL-GM 승인 기록 전수조사: 1차 원본 색인 (비규범)

**조사 시점:** 2026-11-01 · **조사 방식:** GitHub REST에서 전체 일반 이슈 **39개**를 식별해 **모든 이슈 댓글 610개**의 원본 링크·첫 제목·조사 후보 표시를 누락 없이 수집했다. 이미 존재하는 메인 이슈 본문/사용자 코멘트는 **역사·원본**으로 유지한다.

[**113조 중 댓글 직접 링크가 없는 42개 조항의 승인 근거 정밀화 대기열**](STEP1_42_CLAUSES_SOURCE_PRECISION_QUEUE_2026_11_01.md)을 추가했다. 별도 사용자 대화 직접 승인 2조항, #324·#321·#311 등의 사용자 확정 이슈 본문으로 확인할 16조항, 복합 이슈 본문/댓글 근거를 추가 대조할 24조항으로 분류했으며, **댓글 링크가 없다는 이유만으로 미승인 규칙이라 판정하지 않는다.**

[PR 전체 290건의 본문 정책 키워드 검사·19건 집중 판정](STEP1_PR_BODY_POLICY_SCREEN_2026_11_01.md)은 사용자 직접 결정과 게임 구현·CI 기록을 분리한다. 제목/본문의 단순 단어 검색은 최종 사용자 승인 효력 100% 인증이 아니다.

[**직접 승인된 이슈 본문 16조의 조항별 핵심 의미 일치 검증**](STEP1_DIRECT_ISSUE_SOURCE_16_CLAUSES_2026_11_01.md) 완료: #311/321/324의 원문과 해당 COMP/CAL/TRANS/GOV 조항을 개별 대조했다. 직접 댓글 미연결 42조 중 16조에 근거 판정표를 연결했고 나머지 26조는 계속 확인한다. 16조 역시 아직 모든 후속 댓글/PR 영향의 100% 최종 인증은 아님.

## 현재 1단계 전수 자료와 정확한 판정 상태

[**1단계 종합 대장 — 전체 출처 수집/선택별 내용/승인 효력 및 종료 게이트**](STEP1_SOURCE_COMPLETENESS_AND_DECISION_GATE_2026_11_01.md)에 2026-11-01 현재 GitHub에서 확인 가능한 이슈 **39건**, 이슈 댓글 **612건**, PR **290건**, 댓글이 있는 PR **53건의 토론/리뷰 224항목**의 탐색 색인을 연결했다. #251의 원본 사용자 선택 **401행은 모두 개별 설명과 당시 선택/후속 주요 정정 관계를 매핑**했다.

자료 수집·401개 선택 원문 내용 매핑은 완료했지만 **612개 댓글 전체·290개 PR 전체의 사용자 최종 효력을 조항별로 심화 대조하는 작업은 여전히 미완료**다. 기존의 610댓글/289PR은 과거 조회 시점의 모수였으며 새 조회값으로 과거 수치를 덮어 쓰지 않는다. 사용자와의 대화만으로 직접 승인된 CORE-007·TRANS-011은 공개 GitHub 댓글 링크와 구별한다. **1단계를 완전히 끝냈다고 표시하지 않으며, 룰북 9장 113조/정본 후보는 Draft로 유지한다.**

## 실제 원문 판정 작업 단계

**두 번째 원본 선택 색인:** [#251 기타 7개 묶음 156행](STEP1_CHOICE_SOURCE_INVENTORY_B_2026_11_01.md) — 1~30, 11~56, 87~116, 비연속 18개, M01~M48의 48개 선택. 총 **380개 원본 선택 기록 행**(최종 유효 정책 수가 아님)을 추적 중이며 묶음 간 번호가 중복된 항목과 후속 철회 후보를 별도 표시한다.

**기계적으로 분해한 개별 선택 목록:** [#251 원본 4개 일괄 선택의 224개 선택 ID 색인](STEP1_CHOICE_SOURCE_INVENTORY_2026_11_01.md) — 57~86(30), 117~146(30), M49~150(102), M151~212(62). 번호·제출 선택을 1개씩 조회할 수 있으나, 대부분은 **최종 유효성 판정 대기**이며 완료율로 계산하지 않는다.

**현재 진행 순서: 1단계 사용자 승인 원문·후속 철회·누락 사항 전수조사 중.** [1차 개별 효력 판정표](STEP1_APPROVAL_EFFECT_AUDIT_2026_11_01.md)에서 **실제 확인한** 월즈 타이브레이크/양측 실격·최종 철회, 랭크 세부 선택, 직원·선수/재정·구단 운영의 현행/대체/세부 미이관을 각각 원문 링크와 함께 기록한다. 이 표는 아래 전체 댓글 색인과 달리 **선택 내용 및 후속 효력을 대조한 소수 쟁점의 판단 기록**이다. 사용자 승인 규칙의 누락을 '미승인'이라고 판단하지 않으며, 문서 생성만으로 1단계 전수 조사나 다음 규정 검증 단계를 완료했다고 표시하지 않는다.

**확정된 작업 순서:** ① 승인·철회·대체 원문 개별 전수 판정 → ② 영구 상위 규칙/사무국 변경 가능/초기 프리셋의 규범 효력 판정 → ③ 현재 룰북 내부 모순 검사 → ④ 확인된 미이관 항목의 상위/하위 규정 배치 → ⑤ 구형 문서 정합화 → ⑥ 문체·형식 통일 → ⑦ 정확 HEAD 검증·정본 확정. [교차문서 충돌 감사표](CROSS_DOCUMENT_CONFLICT_AUDIT_2026_11_01.md)는 **5단계 입력 자료**이며 1단계의 원문 효력 판정을 대신하지 않는다.

2. 일반 이슈와 별개로 **과거 PR 289건의 본문·리뷰·코멘트**, 오래된 `docs/DECISIONS.md`의 사용자 확정 이력·이전 토론의 변경 근거까지 전량 판정한 상태가 아니다. PR에는 구현 메모와 승인 발언의 복사가 섞여 있으므로 전부 자동으로 규범에 편입하지 않는다.
3. 현재 [룰북](../rulebook/README.md) **113개 조항**은 승인된 상위·일부 세부 규칙이다. 세부 기록을 임의로 생략하거나 **미수록은 승인 부재**라는 결론을 내리지 않는다.
4. 분야별 미이관/재검토 대상은 [기존 이관 감사표](../RULEBOOK_MIGRATION_AUDIT.md)로 추적한다. 최신 후속 결정 검증 없이 규칙을 삭제하거나 새 숫자를 추정하지 않는다.
