# 3단계 실행 반례 대장 — 정상/위반 쌍·오라클·우선순위 (2026-11-11)

> **비규범 QA 명세 / `STAGE3_PARTIAL`.** [정본 반례 C01~C38](STEP3_CROSS_DOMAIN_COUNTEREXAMPLES_2026_11_10.md)을 실제 엔진 테스트로 이관하기 위한 판정표다. 세계법 본문·과거 승인코드 자체를 변경하는 문서가 아니다. 모든 행의 `NOT_RUN`은 **게임 엔진 검증 미실행**을 뜻한다. 아래 정상안의 *허용*은 사용자 명령·적법한 실행 절차 없이 **자동 발생**한다는 뜻이 아니다.

## 1. 통일된 판정·기록 계약

모든 사례는 `fixture`(당시 유효 세계법 버전, 내부 시행규정/공표·발효, 단일 세계 UTC 시각, 실제 당사자/등록·계약, 유한 재정·정보 권한, 재현 시드)를 가진 **정상 경로(+)와 규정 위반 경로(-)**의 쌍으로 작성한다.

- **정상(+):** 법률상 허용되는 *조건을 모두 충족한 명령*만 유효한 게임 원본에 한 번 커밋하고, 원장·선수 상태·법적 효력·역사와 UI 관측이 일치해야 한다. 유효 계약·출전은 적법 주체의 승인/동의 없이 저절로 발생하지 않는다.
- **위반(-):** 명령을 거부하거나 필요한 정상 보완·등록 보류 상태로 두되, 이미 완성된 경기·계약·재정/기존 타구단 권리를 *침묵 속에서 변경하지 않는다*. **거부 이유, 검증 실패한 조건, 실제 변경되지 않은 세계 상태**가 관측되어야 한다.
- **원자성:** 유효 커밋의 이벤트 ID는 1회만 적용하고 중간 오류 시 *미완료 트랜잭션만* 안전 롤백한다. 이미 유효했던 독립 계약·경기·시리즈·채무를 임의 소급 삭제하지 않는다.
- **사전조건과 인과 소비:** 코드에 법률의 문자열이 있다는 사실로 PASS를 주장할 수 없다. 유효한 기관/계약/사용자 명령과 실제 세계 상태를 생성하고 그 사건을 **실제 경기/AI/회계·등록/저장·후속 UI**가 소비하는지 확인한다.
- **반례 결과 등급:** `NOT_RUN`(미실행), `BLOCKED_FIXTURE`(초기 규정/원문·엔진 스냅샷 부재), `FAILED`(실제 위반), `PASS`(정상+위반 모두 실행하고 단일 원본/부작용까지 검증), `PARTIAL_PASS`(부분 경로만 검증). GitHub 정적 핀 검사는 별도 `STATIC_CHECKED`로 표기하고 이 표의 실행 PASS에 합산하지 않는다.
- **우선순위:** `P0`은 상위 권한·불가역 경기/계약/재정·등록·역사 손상의 가능성이 커서 먼저 검증할 사례이고, `P1`은 주요 편의/관측·경계 사례다. **정책상 중요도나 법적 효력이 낮다는 뜻은 아니다**.

## 3. 필요한 실행 단계와 결함 분류

1. **먼저 위계/시각 기반 fixture:** S2-01~15에서 실제 게임 최초 규정이 제정·공표·시행된 원장인지 확인한다. 미제정 규정 시나리오는 의도적으로 `PENDING/REJECT`가 정상 오라클이고, 유효한 다른 규정의 활동까지 차단하는 구현도 실패로 판정한다.
2. **정상+반례 시드 제어:** 같은 입력·같은 시드로 재실행할 때 계약·경기/재정 결과·이벤트 순서가 재현되어야 한다. 서로 다른 입력이 우연히 같은 결과일 수 있다는 점과 시뮬레이션 완전 결정론을 구별한다.
3. **서로 다른 결과 원본:** 월드 실경기, 공식 등록, 선수 계약/영업 채권, 국가대표 귀속, 외부 UI 표시, 실제 과거 이력 각각의 단일 상태 작성자와 시간 순서를 확인한다. 문서 유사성이 아니라 실제 *writer/consumer* 경로로 합격시킨다.
4. **세이브/세계 경계:** 유효/무효 행위 직전과 직후 저장·로드, 장기 시즌 경계, 실제 사용자 감독/AI 동일 권한, 같은 세계에서 이전 승인 상태가 남았는지 검증한다. M206D의 구버전 별도 포맷 의무와 현재 지원 저장의 실제 무결성을 혼동하지 않는다.
5. **결함 분류:** `RULE_CONFLICT`(두 현행 규범이 동일 사실에 상반 판정), `MISSING_EFFECT`(규범은 있으나 집행/명세가 누락), `UNIMPLEMENTED`(실행 경로 없음), `REGRESSION`(구형 승인 효과 복귀), `BLOCKED_SOURCE`(최신 선택 근거 전문 접근 불가), `BLOCKED_DECISION`(실제 정책 수치/권한 미승인), `QA_GAP`(정본은 명료하나 인과/저장/롱런 실증 없음). `QA_GAP`만으로 **사용자 승인 조문이 누락됐다**고 추정하지 않는다.

## 4. 실행 순서·완료 게이트

- **1순위 `P0`:** 내부 제정/시각 C01·C02·C07·C08·C09, 등록/이적/역사 C11·C13~16·C20, 보호·시즌 C23~32·C34·C37, 정보/재정 C06·C17·C38 등. 각 사례의 최소 정상 1회+위반 1회·원자성/세이브를 기록한다.
