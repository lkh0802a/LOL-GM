# M33C~M48C — 사용자 선택 원문 확인

[#251의 M33~M48 사용자 직접 선택](https://github.com/lkh0802a/LOL-GM/issues/251#issuecomment-6290271107)을 기존 번호별 목록 및 관련 [#236 선수·의료](https://github.com/lkh0802a/LOL-GM/issues/236), [#237 재정·계약](https://github.com/lkh0802a/LOL-GM/issues/237) 이슈 본문의 상위 원칙과 대조했다. 분야별 이슈 본문은 전체 세부 선택의 후속 효력을 독립 인증하지 않는다. 아래는 원본의 당시 승인 범위이며, 다른 이슈·PR의 모든 후속 결정과 최종 효력을 확인했다는 뜻이 아니다.

| 선택 | 확인한 당시 의미·제한 |
|---|---|
| M33C | 챔피언 숙련 이전은 실제 기술·사거리·역할·개인 경험에 따른 조건부 재사용이며 동일 전이율/일괄 버프가 아니다. |
| M34C | 포지션 전향은 선수 동의·실제 경험·시간·등록과 학습 맥락에 의존하며 즉시 자동 완료가 아니다. |
| M35C | 성장 정체/재성장은 실제 경험·학습·코칭·적응의 상호작용이며 임의 나이 문턱이나 무조건 재성장 금지. |
| M36C | 선수 전성기/쇠퇴는 기량별 경험과 실제 건강·역할에 따라 다양하며 동일 고정 하락·의료 이중 패널티를 금지한다. |
| M37C | 실제 시계·일정·계약 아래 활동/휴식을 선택하며 감독 최종 권한과 선수 동의를 지킨다. 수동 포인트/매일 확인 강제와 가짜 활동 결과 금지. |
| M38C | 피로·회복은 실제 활동·일정·건강과 회복 기회에 따른다. 근거 없는 수면 데이터·생활 사고나 새 무작위 사건 시스템 금지. |
| M39C | 의료 판단·선수 의사·전술 판단·등록 자격·적법한 최종 권한을 구별한다. 의욕으로 의료 금기/등록 불가를 우회하거나 상대 비공개 의료를 열람하지 않는다. |
| M40C | 코칭 피드백은 실제 경기 관측·근거·선수 이해와 후속 적용/재평가를 따른다. 보고서 읽기만으로 가짜 능력 향상을 부여하지 않는다. |
| M41C | 스태프의 실제 전문성·경험·협업·권한을 업무별로 반영하며 직책 단일 점수/중복 버프를 금지한다. |
| M42C | 상충 분석은 출처·전문성·근거·불확실성을 고려해 업무별 최종 권한자가 판단한다. 코치 다수결로 감독 권한이나 의료/재정 제약을 무효화하지 않는다. |
| M43C | 스폰서의 실제 목표·권리·이행·위험·기회비용에 따른 계약이며 고정 계약 수 상한·가짜 수익·권리 이중 판매를 금지한다. |
| M44C | 경영진의 실제 예산·부채·정보·권한과 의무를 반영한다. 무한 자금·AI 우대·감독에게 모든 경영 권한 자동 이전 및 별도 인수인계 부활을 금지한다. |
| M45C | 팬 지지 변화는 실제 역사·성적·관측 가능한 경험과 관계되며 개별 수백만 팬 시뮬레이션이 필수는 아니다. 허구 사건 강제 금지. |
| M46C | 수익은 실제 거래·계약 권리와 비용을 기존 원장에 한 번 기록한다. 팬 수와 단순 비례하는 허위 매출·없는 활동 생성 금지. |
| M47C | 실제 합법적 이동·교류가 지역 경쟁력에 영향을 줄 수 있다. 국가 ID에 따른 고정 재능 특혜·일괄 상한을 금지한다. |
| M48C | 팀 간 경쟁 변화는 실제 재정·시장·선수·시설·조직·비용의 상호작용이며 강제 몰락/왕조나 숨은 균형 버프가 아니다. |

정치·파벌·권력투쟁·철회된 가상 기술 사고는 추가하지 않는다. 실제 원문 대조나 PR 기록이 구현·CI 완료를 뜻하지 않는다.
