## 세계 외부와 내부의 규범 구분

이 법전은 **세계 외부에서 제정되는 상위 헌장**의 검토안이다. 그 헌장에서 국제·지역사무국·독립 개최사 등이 규정을 변경할 수 있다고 **허가하는 조문**도 외부 규칙이다. 실제로 해당 주체가 제정·공표한 지역리그/대회 규정이 **세계 내부 규칙**이고, 그 효력은 유효한 관할·시점·시즌에 따른다. 제정권의 부여와 실제 규정 제정을 혼동하지 않으며, 특정 구단에 대한 처분·계약 체결·경기 결과도 일반적인 규정의 제정과 구별한다. **외부 헌장에 기록된 모든 상세 조문이 영구 고정되는 것은 아니다.** 헌장이 실제 위임한 영역만 내부 기관이 개정할 수 있고, 초기 세계 설정은 해당 위임 범위 안에서만 변화한다. UI는 어느 쪽에도 속하지 않는다.

## 편찬 기준

1. 사용자 승인 결정의 의미를 보존하고, 구형 조항 ID는 영구 alias로 추적한다.
2. 국가별 복수 국가대표팀을 허용한다. 국가대표대회는 구단 대회 네 분류의 단순 예외가 아니라 별도 정규 대회 체계다.
3. 선수 통합시장 28일 동안 **구단 대회 실경기는 금지**, 국가대표 대회는 실제 개최 가능. 선수 구단 소속과 대표팀 명단은 분리하고 세계 시간과 실제 선수·피로·기록은 공유한다.
4. 공식 구단 대회 일곱 개와 구단 Worlds 공식 피날레, 기존 계약·재정·과거 기록은 보존한다.
5. **세계관 정본에는 UI·UX/조작·화면 설계가 들어가지 않는다.** 사용자 승인된 별도의 소프트웨어 제품 요구사항은 `docs/interface-spec/`에 관리하며, 이 명세는 정본 규범 계층의 일부가 아니다. 국가별 팀 수 상한, 대표팀 주관/차출·국적/귀화/선발 및 참가 시드 등의 미승인 수치는 임의로 제정하지 않는다.
