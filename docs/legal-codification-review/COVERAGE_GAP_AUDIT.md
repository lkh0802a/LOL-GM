# 세계 규정집 **충분성·누락 범위 감사** — 2026-11-08

> **결론: INCOMPLETE — 현 7장 108조가 충분하다고 입증되지 않았다.**
> `113-10+5=108`은 기존 113개 문서 조항 중 UI 10개 이관·국가대표 5개 신설을 합산한 **편집 산술값**이지, 규범의 포괄성·집행 가능성·완결성을 입증한 수치가 아니다. 원본 113/113 대응표의 완전성도 같은 의미다. 필요한 조항을 추가하거나 겹친 조항을 통합할 수 있어야 하며, 조항 수는 목표·상한·승인 기준이 아니다.

## 기준

- **외부 헌장:** 유효한 게임 세계의 권리·의무·금지, 규정 제정권과 한계, 안정적 상태와 역사, 공통 적용 규칙.
- **세계 내부 시행 규정:** 그 권한을 실제로 받은 주체가 관할·대회·시즌·회차에 대해 적법하게 제정·공표한 특정 기준과 값.
- **비규범적 문서:** 화면·조작 UX, Rust/TypeScript/저장 스키마, 게임 테스트·검증 계획.
- **문서 충분성:** 각 실제 사건에 대해 적법한 권한의 소재, 적용 규범, 규정의 유효 시점, 사건의 결과·기록, 충돌·미결 사안의 처리가 확인되는지. 규칙이 적다고 무조건 부족하거나, 많다고 완전한 것이 아니다.
- **편찬 한계:** 미승인 수치·권한·국가 자격·차출 의무·징계 사유 등을 '빈 곳을 채우기 위해' 즉시 제정하지 않는다. 미정인 사항의 **권한·원칙·절차**와 실제 **내용**을 분리해 별도로 결정한다.

### 편찬 결론

- **현재 108조는 '규정집 초안'이지 '완결된 정본'이 아님.**
- **새 상위 조문/내부 규정을 더할지, 기존 조문을 합칠지의 판단은 위 공백과 실제 승인 근거에 따른다.** 108을 정답이나 목표 숫자로 고정해 추가·삭제를 막아서는 안 된다.
- 구조 검사 `STRUCTURAL_PASS`는 조항 번호·대응표의 누락/오류가 없다는 좁은 의미이며 규범 충분성 `SUBSTANTIVE_COMPLETENESS`와 별도로 판정한다.
