# 세계 외부 규칙과 세계 내부 규칙의 구분

> **편찬 상태: REVIEW_ONLY.** 기존 승인 내용을 재분류하는 편찬 기준이며, 사용자에게 승인받지 않은 구체적 권한·대회 방식·수치·즉시 발효 규칙을 새로 제정하지 않는다. 이 문서는 `LAW_DRAFT.md`의 규범 계층 설명서이지 세계 내부에서 효력을 갖는 새 사무국 규정이 아니다.

## 제1절 원칙

**세계 외부 규칙(상위 세계 헌장)**은 LOL-GM이라는 세계가 어떻게 존재하고 작동하는지, 그리고 세계 내부의 기관이 무엇을 할 수 있고 할 수 없는지를 정한다. 이는 **사용자의 승인에 의해 정본으로 제정·개정**되며, 게임 속 국제·지역사무국, 대회 주최사, 구단 또는 AI가 임의로 변경할 수 없다. 외부 규칙은 게임의 내부 역사·승인된 계약이나 당시 경기 결과를 소급 변경하지 않는다.

**세계 내부 규칙(세계 내 시행 규정)**은 위 헌장에서 권한을 받은 실제 기관·대회 주관자 등이 특정 관할·시즌·회차에 대해 합법적으로 제정·공표한 규정이다. 해당 세계의 상태에 존재하는 실효 규정만 구속력을 갖는다. *제정할 권한이 있다*는 사실과 *그 규정이 이미 제정되었다*는 사실은 구별한다.

**핵심 법리:** 외부 규칙에 “지역사무국은 리그 포맷을 정할 수 있다”라고 적혀 있는 경우, 그것은 **내부 의사결정 권한을 부여하는 외부 규칙**이다. 특정 지역에서 실제로 스플릿 수·경기 형식을 정해 공표한 결정만 **내부 규칙**이다. 두 종류를 같은 조문에서 혼동하거나 세계 내부 AI가 외부 규칙 자체를 수정하도록 해서는 아니 된다.

## 제2절 소속 판정

| 판정 기준 | 세계 외부 규칙 | 세계 내부 규칙 |
|---|---|---|
| **규범 발원** | 사용자 승인·상위 정본 | 정본에 따라 권한을 가진 실제 세계 내 주체의 결정 |
| **적용 범위** | 전 세계 또는 상위 정본이 명시한 공통 범위 | 지정된 관할·대회·시즌·회차·계약 관계 |
| **수정 권한** | 사용자 명시 승인에 따른 정본 개정 | 적법한 기관·계약 당사자 및 승인 절차 |
| **변경 한계** | 과거 확정 사건·기록을 무근거 소급 변경할 수 없음 | 외부 규칙, 당시 유효한 계약·등록·기록과 법정 권한을 우회할 수 없음 |
| **관리 위치** | 정본 세계 헌장 `LAW_DRAFT.md`(확정 전 검토안) | 각 저장 세계에서 실제 제정·공표된 규칙/계약의 버전과 효력 이력 |
| **UI와의 관계** | UI는 해당 사실을 표현할 수 있으나 권한을 제정하지 않음 | UI는 내부 규정의 현재 유효 여부를 표시할 수 있으나 제정 주체가 아님 |

**법전 편집 시 주의:** 현 `LAW_DRAFT.md`에 있는 구단 계약·리그 운영 관련 조항도 대부분 **외부 규칙이 정한 합법성 조건 또는 권한의 범위**를 설명한다. 단지 사무국/구단이 등장한다는 이유로 그 조문을 **내부 기관이 고칠 수 있는 내부 규칙**으로 분류해서는 안 된다. 내부 규칙의 구체적 내용은 게임 세계의 적법한 제정 사건이 발생한 후에 확정된다.

## 제3절 도메인별 권한 분리

| 분야 | 외부 규칙으로 고정되는 사항 | 내부에서 정할 수 있는 사항(외부의 명시적 권한 내) |
|---|---|---|
| 세계 시간·기록 | 단일 세계 시간과 이중 처리 금지, 확정 이력 보존 | 적법한 대회별 일정·등록 마감의 구체 시각 |
| 구단 대회 | 공식/독립·지역/국제의 법적 분류, 기존 구단 국제대회 7개의 보호, Worlds의 구단 공식 피날레 | 지역별 시즌 형식·승강 방식·합법적 시드·개별 대회 포맷 및 사전 공표 절차 |
| 국가대표 대회 | 구단 대회와 독립된 체계, 국가당 복수 대표팀 구성 가능, 시장 28일간 국가대표 실경기 가능, 선수 단일 실체·시간 점유 | 실제 운영 주체·참가 적격성·선발·예선·명단·개최일 등 **향후 적법하게 정해야 할 구체적 규정**. 현재 미승인 운영주체/수치를 새로 승인한 것으로 취급하지 않음 |
| 이적·선수 | 12월 첫째 화요일 UTC 시장 개장·28일, 구단 경기 금지, 합법적인 FA·연중 바이아웃 예외, 계약/선수 권리 보호 | 지역사무국에 이미 위임된 시즌 중 지역 이적창의 실제 개장 여부·횟수·시각, 대회별 등록 기준 |
| 경기 | 실제 5:5 결과, Fearless Draft·First Selection의 외부 불변성, 시간·자원 중복 금지 | 정본이 허용하는 범위의 대회별 경기 형식·적격 선수 교체·세부 시드/타이브레이크 |
| 조직·재정 | 권한의 소재와 한계, 실제 계약·원장·채무·소유권·역사 보호 | 유효 권한에 따른 내부 의결·지급 계약·후원 계약·예산 배분·적법한 제도 개편 |

**내부 권한의 부재는 자유 재량을 뜻하지 않는다.** 사용자에게 직접 승인된 권한이 없는 국가대표 주최 기관·국적 판정·귀화·소집 강제·보상액 등을 임의로 법전이나 세계 내부 AI 기본값으로 확정하지 않는다.

## 제4절 충돌·개정의 판정 순서

1. **외부 규칙을 적용한다.** 유효한 상위 정본의 게임 세계 불변조건과 기관의 권한 경계를 확인한다.
2. **내부 규칙의 제정 권한을 검증한다.** 해당 결정 주체가 그 문제·관할·시각에 실질적 규정 제정 권한을 가진 경우에만 유효 규범 후보가 된다.
3. **대상·효력 발생을 검증한다.** 사전 공표, 승인, 계약 및 시행일·시즌·회차 요건에 따라 유효성을 판정한다.
4. **정당한 세계 상태에 적용한다.** 당시 적용된 버전으로 계약·경기·등록·재정·역사를 처리하고 후속 변경을 기존 확정 사건에 소급 적용하지 않는다.
5. **권한 밖이거나 외부 규칙과 충돌하면 거부한다.** 다른 내부 기관의 개정으로 외부 규칙의 하한·금지·보호를 무효화할 수 없다. 내부 기관이 합법적으로 위임받은 결정을 했다는 이유만으로 외부 정본을 자동 수정하지 않는다.

## 제5절 세계 내부 규정 이력의 최소 판정 항목

다음 항목은 **개념적 검증 조건**이며 저장 스키마의 구현 명세나 이미 제정된 내부 규정이 아니다.

- **제정 주체 및 적법한 권한 근거**: 실제 권한 있는 사무국·주최자/기관과 해당 상위 조문
- **적용 범위**: 국가·지역·대회·부·시즌·회차·선수/구단 자격 등 실제 대상
- **제정·공표와 발효 시점**: 현재 유효한 버전, 실제 공표 이력, 규정 개정의 예정 발효일
- **존속·승계·폐기 관계**: 동일 범위에서 후속 개정의 유효 여부, 구버전 규정과 역사적 적용 관계
- **관련 계약·참가 자격 및 재정 충돌**: 당사자 권리와 실제 세계 원장·시간·과거 기록

**편찬상 현재 상태:** 기존 국가대표 5조와 세계규칙 103조를 두 계층에 뒤섞어 재번호 부여하지 않는다. 현 법전 초안은 *외부 헌장*의 내용으로 해석하고, 세계 내부에서 실제로 시행할 상세 규정은 해당 권한의 존재와 시행 상태를 확인한 뒤 게임 내부 규정 원장으로 관리한다. 단, 특정 외부 조항이 현재 시행 중인 초기 세계 내 프리셋까지 직접 확정하는 경우에는 외부의 초기 설정 명령과 내부에서 향후 변경할 수 있는 범위를 분리해 추적한다.

**예외·미완:** CORE-007·TRANS-011의 2026-11-01 직접 대화 원문 열람 장애(`BLOCKED_SOURCE`), BIZ-010/BIZ-012 다구단 경영권 범위 미정(`BLOCKED_DECISION`)을 이 분류로 자동 해결하지 않는다. 본 문서는 원문 효력 전수·최종 게임 구현·정본 병합 완료 증거가 아니다.
