# 규정집 전체 구조 검토 대장 — 2026-11-08

> **검토 용도:** 기존 113개 조항의 새 위치·분야 성격·특수 구조 위험을 행별로 점검한다. 113/113 행의 재배치 검사는 완료되었으나, 401개 결정·612댓글·290PR의 최종 의미적 효력을 모두 인증한 문서는 아니다. 부재한 지적 사항이 '해당 조항은 최신 효력까지 최종 검증됨'을 의미하지 않는다.

## 편제 검토 결과

- **본칙 7장 108조**: 기존 규범 103개 + 새 국가대표 5개. 장 구성은 총칙, 기관/주체, 구단 대회, 국가대표 대회, 선수·계약, 시즌·경기, 재정·상업.
- **정본 범위 외 UI 항목 10건**: 기존 `UI-001~010`은 세계관 규칙이 아니며 별도 `docs/interface-spec/USER_EXPERIENCE_REQUIREMENTS.md`에 보존한다. 법전의 하위 규범으로 취급하지 않는다.
- **기존 ID 영구 보존**: 기존 113개 모두 전수 대응표에 1회 등장; 신규 `NAT-001~005`의 국가별 복수팀·시장 중 개최·별도 선수 등록은 새 승인.
- **정본 우선**: 이 법전 검토안은 PR #328를 변경하지 않음. 정본 소유 writer가 조항 의미 대조·최신 효력/충돌·표현 검토 후 필요 파일에 반영해야 함.

## 세계 외부·내부 효력 구분

[규범 층위](RULE_LEVELS.md)에 따라 **외부 규칙은 사용자 승인 정본**, **내부 규칙은 실제 세계에서 권한 있는 주체가 제정·공표한 시행 규정**으로 나눈다. 특정 외부 조문이 내부 규정의 제정권을 부여해도 그 조문은 외부에 남는다. [108조별 위임 감사](DELEGATION_AUDIT.md)에 각 조문의 내부 위임·처분·개별 계약 또는 상위 고정 제약 여부를 전부 매핑했다. 본 분리로 이전의 직접 승인 원문·결정권 미확정 상태가 해결된 것은 아니다. UI는 두 세계 규칙 층 모두와 별개의 제품 요구사항이다.

## 추가 편집 감사 — 헌장 고정·위임·초기 설정

- [108조 전수 판정](DELEGATION_AUDIT.md)을 단일 '외부 고정'으로 취급하지 않는다. **외부 불변, 범위 한정 위임, 초기 세계 설정, 실제 개별 처분·계약, 기타 효력 조건, 운영 권한 미정**을 각각 구별한다.
- 제9조를 별도 **외부 헌장과 내부 규정의 효력**으로 정리하고, 제7조에 실제 제정·공표 여부를 검증하는 권한 경계를 덧붙였다. 이는 미정 규칙의 제정권을 신설하지 않는 체계 설명이다.
- 제66조의 자동 변환 오류 `제69조·005`를 **제69조 및 제70조**로 교정하고, 문장부호 오류 및 시장 금지대회의 적용 범위를 명확히 했다.
- 제65조의 장기 다지역 검증 지시, 제91조의 현실시간 밴픽 입력 제한, 제99조의 주장 전용 UI 제외, 제105조의 보고·검증 지시는 **세계 법전에서 빼고** [제품 UI 명세](../interface-spec/USER_EXPERIENCE_REQUIREMENTS.md) 또는 [개발·검증 수용 조건](../implementation-spec/NON_NORMATIVE_ACCEPTANCE.md)에 보존했다.
- 제7조와 제36조의 개편 효력·사전 검증 중복을 줄였다. CAL-004의 월즈 결승 실경기 불성립 시 타 공식대회 종료 의무, MATCH-010의 무작위 퍼즈·리메이크·심판 사고 금지, MATCH-011의 주장 전용 사건 금지를 원문 대조 후 복구했다. [수용 사례 H-01~H-22](NORMATIVE_CASES.md)에는 초기 세계 설정과 장래 개정권, 세계 내부 규정의 제정 전 상태, UI 명세의 무권한 사례를 추가했다. 원본 사용자 승인 규칙의 법적 권한·의무가 달라졌는지 여부는 여전히 원문별 의미 대조가 필요하다.

## 중점 구조 판정

1. **대회 분류를 축별로 확정:** 구단 대회는 기존 공식/독립×지역/국제 네 종류, 국가대표 대회는 참가 주체 자체가 다른 정규 대회 체계. 두 체계를 억지로 네 종류에 포섭하지 않음.
2. **시계는 공유하되 규정의 적용 범위는 분리:** 시장 28일 구단 실경기 금지, 국가대표 경기 편성 가능. 구단 공식 시즌 Worlds 피날레와 국가대표 스토브리그는 양립. 이적 자체는 국가대표 명단의 소급 자동 변경 사유 아님.
3. **권한과 운영 문서 분리:** 국제·지역 사무국의 기존 권한을 국가대표 운영 주체에 자동 확대하지 않음. 국적/귀화, 대표팀별 정원, 시드·예선 수치, 소집·차출·보상, 지도자 선임 등의 미승인 상세는 별도 운영규정 미정으로 둠.
4. **사용자 결정의 효력과 편집 행위 구분:** 법전화 자체가 승인 규칙 변경 권한이 아님. 원문 최종 효력 위반, 보유 출처 미확인, 기술 구현 미완은 상태를 분리.
5. **세계관 본문과 제품 설계의 경계:** UI·클릭·알림·저장 화면·전망 화면 등은 제품 요구사항으로 이동하고, 세계 내부에서 실제 발생하는 권리·의무·사건·효력만 본칙에 유지한다.
