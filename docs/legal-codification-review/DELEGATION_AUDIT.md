# 전체 108조의 세계 외부·내부 규칙 위임 범위 검사

> **감사/편집 메타자료 · 정본 미확정.** 아래 108개 조문은 모두 세계 밖에서 제정되는 상위 정본 후보라는 전제다. **외부 정본의 모든 내용이 내부에서 변경 불가능한 영구 상수라는 뜻은 아니다.** 각 조문이 **세계 내부 기관의 유효 규정 제정·집행을 허용하거나 언급하는지**를 별도 분류한다. '내부 규정 위임 범위'는 그 조문 자체가 내부 규정이라는 뜻이 아니다. 한편 사무국의 실제 법적 처분·구단의 개별 계약은 '일반적 규정의 제정'과 다른 세계 내 행위다.

**분류상 주의:** 제51~53조의 국가대표는 새 체계와 복수팀·시장 중 개최라는 상위 방향만 확정됐다. 구체적인 대표 자격·차출 권한·주최 기관·대회 일정 값은 기존 사용자 승인 범위를 넘어 자동 확정하면 안 된다. 제7조(CORE-007)·제76조(TRANS-011)는 2026-11-01 직접 승인 원문 접근 경계를 보존한다.

## 세계관 정본 내부의 규율 성격(법적 층위 증설 아님)

이 문서의 108개 조항은 **모두 외부 정본 후보**다. 그러나 **외부 정본에 수록되었다는 이유만으로 108개 세부 제도가 전부 영구 고정되는 것은 아니다**. 개별 조문의 법적 성격을 다음 기준으로 심사한다.

- **상위 보호·금지 또는 불변:** 내부 기관은 그 보호된 내용·금지를 임의로 폐지·변경하지 못한다. 사용자가 명시적으로 정본을 개정하는 것과 내부 기관의 규정 개편은 구별한다.
- **범위 한정 내부 규정 제정권:** 헌장은 내부 기관에 *어느 범위에서 어떤 절차로* 정책을 정할 수 있는지를 부여한다. 실제 포맷·일정·정원·계수 등의 구체 값은 적법한 내부 결정이 있어야 성립한다.
- **초기 설정과 향후 개정권 구분:** 정본이 최초 세계의 상태를 지정할 수 있으나, 그 상태가 영구 불변인지 장래 개편 가능한지는 **해당 분야에 실제로 부여된 개정권**으로 판단한다. 초깃값이라는 이유만으로 임의 변경권을 창출하지 않는다.
- **개별 행위·처분·계약 구분:** 구단의 계약 체결, 사무국의 특정 라이선스 처분과 같은 사건은 내부에서 발생하지만 일반적 내부 규정의 제정·개정과 동일한 사건이 아니다.
- **상위 권리·적격성·효력 조건:** 현재 사용자 승인을 통해 세계 전반에 적용되는 요건. 조문 자체에 개정권이 명시되지 않았으면 내부 기관의 변경 재량을 **추정하지 않는다**.
- **권한 미정/세부 규정 미제정:** 국가대표의 독립·복수팀·스토브리그 개최 같은 확정 방향과, 아직 제정 주체/자격/차출/선발이 확정되지 않은 운영 세부를 섞지 않는다.

위 분류는 **감사용 해석 표시**이지 각 조문을 자동 수정하거나 새로운 위임 권한을 승인하지 않는다. 실제 제정권은 원문과 최신 사용자 승인, 헌장 전체의 관련 조문을 대조해 결정해야 한다.

## 편찬 결과

- **108/108개 외부 헌장 조문**을 모두 판정표에 남긴다. 내용상 **내부 제도·규정에 영향을 주는 위임/행정/개별 계약**과 **아무런 내부 제정권을 추가하지 않는 상위 공통 제약**을 구별한다.
- 실제로 존재하는 **세계 내부 규정의 본문과 효력은 이 표나 법전 초안에서 만들어내지 않는다.** 저장된 세계에서 실제 권한 있는 주체가 적법하게 결정한 규정과 발효 버전을 조회해야 한다.
- 한 조문에 서로 다른 제정권과 상위 금지가 섞인 경우 다음 개정 시에는 **'상위 헌장이 규정하는 권한·제약' vs '내부 기관이 실제 시행하는 가변 규정 값'**만 분리한다. 새 추상 분류를 중첩하거나 승인되지 않은 숫자를 창작하지 않는다.
- `UI-001~010`은 **세계 외부 헌장에도, 세계 내부 법규에도 포함되지 않는 제품/인터페이스 명세**로 유지한다.
- 실무 구현 수용: 내부 정책을 실제로 개정하더라도 외부 헌장 버전이 변하지 않아야 하며, 외부 헌장을 사용자가 개정한 경우에만 헌장 근거가 갱신된다. 내부 규정의 당시 효력과 확정된 계약·사건을 소급 변경하지 않도록 회귀 검사한다.
