# 외부 헌장과 내부 규정의 충돌·효력 수용 사례

> **검증 명세, 실제 엔진 테스트 아님.** 아래의 가상 시나리오는 세계 외부 헌장의 금지/위임/기록 보호와 세계 내부에서 실제 제정된 규정·계약·행정처분을 구분할 때의 기대 판정을 고정한다. 예시 일정·주최/대회 형식은 신규 정책이나 기본 세계 설정으로 승인하지 않는다.

| ID | 입력 조건 | 기대 판정 | 근거 및 검증점 |
|---|---|---|---|
| H-01 | 지역사무국이 권한·필요 승인·사전 공표·차기 시즌 발효 조건을 모두 충족하여 다음 시즌 공식 지역리그 형식을 결정 | **VALID** | 내부 포맷 결정은 외부 위임 범위의 실효 규정 |
| H-02 | 같은 지역사무국이 구단의 세계 공통 선수 시장 개장일을 임의로 옮김 | **INVALID** | 내부 기관은 외부 고정 12월 첫 화요일·28일을 변경할 수 없음 |
| H-03 | 내부 개최사가 스토브리그 통합 시장이 열린 동안 구단 독립컵 경기를 편성 | **INVALID** | 구단 4종 실제 경기 금지의 적용 범위 |
| H-04 | 국가대표 경기로 적법하게 편성된 경기를 같은 시장 기간에 개최, 구단 경기 없음 | **ALLOW_WITH_VALID_REGISTRATION** | 국가대표는 구단 경기 금지의 예외가 아닌 별도 정상 대회 체계. 대표팀 등록·주최권한은 별도 확인 |
| H-05 | 주최권과 대표팀 자격이 미확정인데 국가대표 주최자 AI가 명단·차출 권한까지 창작 | **BLOCKED_AUTHORITY** | 국가대표 체계 설립 허용 ≠ 특정 주최자·강제 차출권 즉시 부여 |
| H-06 | 국가가 복수 국가대표팀을 구성했지만 대회별 시드가 아직 정해지지 않음 | **NO_AUTOMATIC_ENTRY** | 대표팀 구성 가능성과 본선 참가권은 별개 |
| H-07 | 국가대표 선수의 구단 계약이 시장 중 변경되고 당시 적법한 대표팀 명단은 이미 확정됨 | **PRESERVE_NATIONAL_ENTRY** | 구단 계약의 변경만으로 대표 자격/명단을 소급 자동 취소하지 않음. 실제 신규 출전 적격은 확인 |
| H-08 | 사용자 감독이 승인하지 않은 최종 선발을 AI가 대신 서명·확정 | **INVALID** | 감독의 적법한 최종 의사결정권 |
| H-09 | 독립 개최사가 해당 컵 우승 팀에 공식 월즈 시드를 자동 발급 | **INVALID** | 독립 대회 성적과 공식 국제대회 시드의 법적 차이 |
| H-10 | 지역사무국이 사전 공표 없이 현재 진행 중인 대회의 타이브레이크를 결과를 본 뒤 바꿈 | **INVALID** | 사전 규정·공정성·실제 결과 비소급 |
| H-11 | 국제사무국 내부 의결로 기존 구단 공식 국제대회 일곱 개 중 하나를 저흥행만으로 폐지 | **INVALID** | 기본 7개의 정체성과 연속성에 대한 외부 보호 |
| H-12 | 세계 내부의 새 정책이 완료된 경기의 승패·당시 지급·선수 기록을 다시 계산해 변경 | **INVALID** | 외부 확정 사건·기록 불변 |
| H-13 | 지역별 이적창의 적법한 개장안은 승인·공표되었으나 발효일 이전 | **NOT_YET_EFFECTIVE** | 적법한 승인 ≠ 현재 시행 |
| H-14 | 연중 이적 허용이 없는 계약 선수의 구단 변경을 국가대표 출전만을 이유로 자동 성립시킴 | **INVALID** | 국가대표 등록은 구단 계약 양도 권한이 아님 |
| H-15 | 서로 다른 사무국이 동일 사건에 대한 지급·경기 결과를 각각 중복 확정 | **INVALID** | 세계 시계·원장의 단일 사실성 |
| H-16 | 과거 직접 승인 원문을 현재 접속할 수 없으나 기존 결정 기록이 보존됨 | **BLOCKED_SOURCE** | 원문 미열람은 승인 부재·철회를 입증하지 않음 |
| H-17 | 감독이 외부 헌장의 Fearless Draft 자체를 임의로 해제하는 지역 규정 채택 | **INVALID** | 내부 입법권의 외부 불변 제약 |
| H-18 | 유효한 대회 내 적법한 선수 명단 변경은 가능하나 이미 진행한 경기 명단까지 바꾸려 함 | **INVALID_RETROACTIVITY** | 현재 효력과 과거 기록의 법적 경계 |
| H-19 | 초기 여섯 주요 지역의 1·2부 현행 기록이 있으나 적법한 절차를 거쳐 미래 시즌 3부 신설을 의결·공표 | **VALID_FUTURE_ONLY** | 외부 헌장에 초기 설정이 기록되었다는 이유로 지역의 적법한 하부리그 신설권을 영구 박탈하지 않음 |
| H-20 | 초기 세계 설정을 근거로 세계 내부 AI가 승인·발효 절차 없이 임의의 시즌 포맷으로 변경 | **INVALID** | 초깃값의 존재가 자체적으로 임의 개정권을 부여하지 않음 |
| H-21 | 제품 UI 명세에서 구단 공식 국제대회 시드나 계약 효력을 임의 변경하라고 선언 | **NO_NORMATIVE_AUTHORITY** | UI·UX 명세는 외부 헌장도 세계 내부 시행 규정도 아니며 실제 세계 규칙을 개정할 수 없음 |
| H-22 | 권한 있는 주체가 신규 규정을 제안만 한 상태이고 승인·사전 공표·시행일이 아직 충족되지 않았는데 즉시 유효 규정으로 간주 | **NOT_ENACTED** | 규정 제정 권한·제안의 존재와 실제 유효한 내부 규범의 성립을 구분 |

## 인수 조건

- H-01/H-02: 지역사무국에 위임된 가변 포맷과 변경 불가한 세계 상수의 판정이 다른가?
- H-03/H-04/H-05: 구단 대회 실경기 금지, 국가대표 경기의 허용 가능성, 미확정 국가대표 주관 권한을 구별하는가?
- H-06/H-07/H-14: 국가·국적·구단 소속·대표팀 명단·대회 본선 출전권이 서로 다른 상태로 관리되는가?
- H-08/H-09/H-10/H-11/H-17: 권한 없는 주체·후행 대진 변경·상위 보호 규칙의 위반을 거부하는가?
- H-12/H-15/H-18: 규정 개정이나 서로 다른 엔진의 실행 경로가 확정 사건을 중복·소급 변경하지 않는가?
- H-13/H-16/H-22: 제정 전·시행 전 상태와 원문 미접근을 실제 유효·무효로 섣불리 판정하지 않는가?

- H-19/H-20: 최초 세계의 리그 상태와 유효하게 위임된 장래 개편권을 구별하는가?
- H-21: UI·UX 명세가 세계 법률의 효력을 만들지 않는가?

**실행 상태:** 이 표는 기대 수용조건일 뿐, 테스트 구현이나 Rust 이관·CI 통과를 주장하지 않는다. 대회·선수·행정·재정 엔진의 실제 테스트가 생기면 케이스 ID를 명세/회귀 파일과 일대일 연결해 상태를 기입한다.
