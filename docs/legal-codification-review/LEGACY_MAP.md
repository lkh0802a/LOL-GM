## 추적 및 최종 검증 기준

- 기존 113개 ID는 세계관 본칙 103개와 **정본 범위 외** UI·UX 제품 명세 10개로 추적한다. 국가대표 5개 신규 조문은 별도 식별한다.
- 본칙의 통합·분리·문체 수정이 종전 조항의 내용 또는 최신 승인 범위를 변경하는지 **각 조문에 대해 별도 대조**해야 한다. 특히 과거 인용된 직접 대화 원문에 접근할 수 없는 CORE-007, TRANS-011은 기존 기록을 보존하되 출처 접근 예외를 지운 것으로 간주하지 않는다.
- `BIZ-010`과 `BIZ-012`의 소유권 적용 범위 문제(I-02), 구형 PR #313/#320의 상충 규정, 숨은 OVR의 팬덤 사용 등은 `STRUCTURAL_REVIEW.md`에서 독립적인 차단/구현 항목으로 유지한다.
- UI는 세계관 정본과 **별개의 제품 명세**(`docs/interface-spec/USER_EXPERIENCE_REQUIREMENTS.md`)에 보존한다. 기술 명세가 세계관 규정의 하위 조문이나 법적 효력을 갖는 것은 아니다. 승인된 UI 기능을 폐기한 것은 아니며 개발 인수는 별도 수행한다.
