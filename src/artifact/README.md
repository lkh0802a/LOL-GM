# LOL GM Canonical Artifact Modules

The authoritative module order is `scripts/artifact-modules.mjs`. Source code is in `src/artifact/`; root `index.html` is generated by the build and must not be edited directly.

Module owners after 11.5 stage 5:

- `random.js` provides reusable deterministic RNG, hashing and math; `engine.js` simulates a single game.
- `data.js` owns reference constants and baseline templates; `champion-data.js` owns champion source/visual normalization; `system-data.js` owns item and rune source normalization.
- `draft.js` owns champion draft evaluation/state; `systems.js` owns automatic item/rune selection and its patch-aware system-meta cache.
- `patch.js` owns patch replay/calendar; `patch-balance.js` computes balance diagnosis; `patch-content.js` implements generated content lifecycle.
- `office.js` handles domestic/regional regulation; `office-international.js` handles global governance.
- `ui-market.js` handles recruitment views/dispatch; `ui-market-initial.js`, `ui-negotiations.js` and `ui-market-staff.js` own the respective specialized UI surfaces.

- `state-transaction.js` provides the shared `validate → preview → apply` command gateway; `state-player-actions.js` owns contracts/transfers/releases/options; `state-rollback.js` owns action-scoped undo and post-commit roster integrity.
- `save.js` packs persistable views; `save-migration.js` restores legacy world-v15 format-1 and format-2 saves, without overwriting malformed or unsupported records.

These remain ordered, concatenated classic JavaScript source files. Step 4 introduced incremental/bounded meta indexes, indexed item/rune evidence and an LRU for historical patch replay without discarding saved history. Step 5 consolidated foreign-slot/season-move checks and permanent roster detachment under `roster.js`, removing obsolete finance and renewal aliases. **Stage 6 UI-state consolidation remains unfinished.** Keep version-15 save migrations intact. Build and verification commands:

```bash
npm run check
npm run perf
npm run build
```

CI on `main` automatically updates the generated standalone `index.html`.
